To record a 5-second 1080p video from the camera using the specified CHI@Edge resource, follow these steps:

1. **Provision the Edge Resource**: Ensure you have provisioned an edge resource with the specifications mentioned in the EDGE RESOURCE ADVISORY context.

2. **Connect to the Instance**:
   - SSH into your Raspberry Pi 4 instance.
   
3. **Install Required Software** (if not already installed):
   - The image `ghcr.io/chameleoncloud/edge-picamera-image:latest` should have the necessary software for camera operations, including `libcamera-vid`. If it's missing, you can install it using:
     ```sh
     sudo apt-get update
     sudo apt-get install -y libcamera-tools
     ```

4. **Record Video**:
   - Use the `libcamera-vid` command to record a 5-second video at 1080p resolution.
     ```sh
     libcamera-vid --width 1920 --height 1080 --framerate 30 --timeout 5000 --inline --output video.h264
     ```
   - This command sets the width and height to 1920x1080 pixels, frames per second (fps) to 30, and records for 5 seconds. The output is saved in `video.h264` format.

5. **Verify Video**:
   - After recording, you can verify that the video file has been created by listing files or playing it back using a compatible player.
     ```sh
     ls -l video.h264
     ```

By following these steps, you should be able to record a 5-second 1080p video from the camera on your Raspberry Pi 4 instance.
