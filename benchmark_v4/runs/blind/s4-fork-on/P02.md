To reserve one Raspberry Pi 4 on CHI@Edge for 2 hours, you can follow these steps using `python-chi`:

1. Import the necessary modules and set up your authentication context:
```python
import chi

# Create an authentication context (most info automatically sourced from env)
chi.use_site('CHI@UC')
```

2. Define the lease parameters including node type, count, and duration:
```python
lease_name = "my-lease"
node_type = "raspberrypi4-64"  # Raspberry Pi 4
node_count = 1
start_date, end_date = chi.lease.lease_duration(hours=2)
```

3. Create a reservation for the node(s):
```python
reservations = []
chi.lease.add_node_reservation(reservations, count=node_count,
                               node_type=node_type)
```

4. Request the lease:
```python
lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date,
                               end_date=end_date)
```

5. Wait for the lease to become active before proceeding with further actions such as launching instances.

This process will reserve one Raspberry Pi 4 on CHI@Edge for a duration of 2 hours based on your request.
