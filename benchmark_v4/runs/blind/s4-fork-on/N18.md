To use a plain USB (UVC) webcam on a CHI@Edge Pi with OpenCV, you need to set up your container and device profile according to the following:

1. **Device Profile**: Use the `pi_libcamera` device profile. This profile supports libcamera drivers which are necessary for accessing cameras including UVC webcams.

2. **Container Setup**:
   - Machine Type: raspberrypi4-64
   - Architecture: arm64
   - Image: ghcr.io/chameleoncloud/edge-picamera-image:latest

This setup is recommended because the `raspberrypi4-64` device with the `pi_libcamera` profile supports the necessary drivers for camera access, and the specified image includes the required configurations to use a USB webcam with OpenCV.
