To reserve two Raspberry Pi 4s in one CHI@Edge lease and start an SSH-enabled container on each of them, follow these steps:

1. **Create a Lease:**
   - Use `chi` to create a lease that reserves the required resources.
   ```python
   import chi

   # Create authentication context (most info automatically sourced from env)
   chi.use_site('CHI@UC')

   reservations = []
   chi.lease.add_node_reservation(reservations, count=2, node_type="raspberrypi4-64")
   
   start_date, end_date = chi.lease.lease_duration(hours=1)  # Adjust duration as needed
   lease = chi.lease.create_lease("my-lease", reservations, start_date=start_date, end_date=end_date)
   ```

2. **Wait for the Lease to Start:**
   - Ensure that the lease is active before proceeding.
   ```python
   chi.lease.wait_for_active(lease.id)
   ```

3. **Launch SSH-enabled Containers on Each Device:**
   - Use a Jupyter notebook or another method to launch containers with SSH access enabled, as described in the CHI@Edge tutorial for creating an SSH-ready container.

4. **SSH into Each Container:**
   - Once the lease is active and the instances are up, you can SSH into each of them using the SSH-enabled container setup.
   
For detailed instructions on setting up SSH access within containers, refer to the provided Jupyter tutorial from CHI@Edge. This will guide you through creating a base container that includes an SSH server, allowing you to treat your container more like a traditional server for development purposes.

Remember to replace placeholders such as `my-lease`, `raspberrypi4-64`, and lease duration with values appropriate for your specific use case.
