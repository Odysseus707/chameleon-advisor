To get a Raspberry Pi on CHI@Edge that you can connect to using VS Code Remote-SSH, follow these steps:

1. **Access the Chameleon Cloud Portal:**
   - Log into your account at the Chameleon Cloud portal.

2. **Navigate to CHI@Edge:**
   - Go to the section for CHI@Edge resources where you will be able to request and manage edge devices.

3. **Request a Raspberry Pi 4 (64-bit) Device:**
   - Select the machine type `raspberrypi4-64` with an architecture of `arm64`.
   - Ensure that SSH access is enabled by using the image `ghcr.io/chameleoncloud/edge_ssh_image:latest`.

4. **Configure the Lease Details:**
   - Set up a lease for 1 device (`count=1`) with a duration of 8 hours (`duration_hours=8`).
   - Make sure that port 22 is exposed to allow SSH connections.

5. **Include Device Profile:**
   - Add the `pi_libcamera` profile if you plan on using the camera module, though this step is optional for just setting up SSH access.

6. **Submit Your Request:**
   - Submit your request through the portal interface or via an API call if you are familiar with that process.

7. **Wait for Allocation:**
   - Wait until Chameleon Cloud allocates a Raspberry Pi 4 to you and provides its IP address and login credentials.

8. **Connect Using VS Code Remote-SSH:**
   - Open Visual Studio Code.
   - Install the Remote-SSH extension if it is not already installed.
   - Use `Remote-SSH: Connect to Host...` from the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on macOS).
   - Enter the SSH connection string provided by Chameleon Cloud, typically in the format `username@ip_address`.

9. **Verify Connection:**
   - Once connected, you can start working with your Raspberry Pi 4 via VS Code.

By following these steps, you will have a Raspberry Pi 4 on CHI@Edge that is accessible through SSH using Visual Studio Code's Remote-SSH extension.
