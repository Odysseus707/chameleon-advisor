To upload `model.pt` into a CHI@Edge container and then download `results.csv` back out, follow these steps:

1. **SSH into the CHI@Edge Container:**
   - First, you need to obtain the SSH credentials for your CHI@Edge resource (Raspberry Pi 4 in this case). This can be done through the Chameleon Cloud interface or via API if you are automating the process.
   - Use an SSH client to connect to the Raspberry Pi. The command will look something like:
     ```
     ssh username@ip_address
     ```

2. **Upload `model.pt`:**
   - Once connected, use SCP (Secure Copy Protocol) from your local machine to upload `model.pt` to the CHI@Edge container.
     ```
     scp /path/to/local/model.pt username@ip_address:/path/to/remote/directory/
     ```

3. **Run Your Application:**
   - After uploading `model.pt`, you can run your application on the Raspberry Pi that processes this model and generates `results.csv`. This step will depend on how your application is set up, but it might look something like:
     ```
     python /path/to/your/application.py
     ```

4. **Download `results.csv`:**
   - Once your application has generated `results.csv`, you can download the file from the CHI@Edge container back to your local machine using SCP.
     ```
     scp username@ip_address:/path/to/remote/results.csv /path/to/local/directory/
     ```

These steps assume that you have SSH access and the necessary permissions to upload files, run applications, and download results. The specific paths and commands may vary based on your setup and application requirements.
