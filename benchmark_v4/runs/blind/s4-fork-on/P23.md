To list the I2C addresses from inside the container to debug the sensor bus, you can use the `i2cdetect` command. Here's how you can do it:

1. Open a terminal inside your container.
2. Run the following command:
   ```sh
   i2cdetect -y 1
   ```
This command will scan the I2C bus (bus number 1 on Raspberry Pi) and list all the addresses where devices are detected, helping you debug the sensor bus.
