To launch a container with the Sense HAT enabled on Chameleon Cloud, follow these steps:

1. **Select the Appropriate Machine Type**: Use `raspberrypi4-64` as it supports the necessary device profiles and matches the arm64 architecture.

2. **Choose the Container Image**: Utilize the image `ghcr.io/chameleoncloud/edge_sensehat_image:latest`, which is designed to work with Sense HAT.

3. **Specify Device Profiles**: Ensure that your request includes the device profiles `pi_gpio` and `pi_sensehat`.

4. **Set Lease Parameters**: Request a lease for 1 machine, specifying a duration in hours as needed (e.g., 1 hour).

Here is an example of how you might configure this using Python CHI Docs:

```python
from chi import Chi

chi = Chi()

# Define the parameters for launching the container
params = {
    'machine_type': 'raspberrypi4-64',
    'image': 'ghcr.io/chameleoncloud/edge_sensehat_image:latest',
    'device_profiles': ['pi_gpio', 'pi_sensehat'],
    'lease': {'count': 1, 'duration_hours': 1}
}

# Launch the container
instance = chi.launch_instance(**params)
```

This script will launch an instance with a Sense HAT enabled by specifying the correct machine type and device profiles. Make sure to adjust the lease duration as needed for your specific use case.
