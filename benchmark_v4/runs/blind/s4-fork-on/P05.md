To launch a basic Ubuntu container on a reserved Raspberry Pi 4 (64-bit) on CHI@Edge, follow these steps:

1. **Reserve Resources**: Reserve one Raspberry Pi 4 (64-bit) for your experiment using the Chameleon Cloud interface or API.

2. **Specify Image and Configuration**:
   - Use the image `ghcr.io/chameleoncloud/edge_ssh_image:latest`.
   - Ensure that the machine type is set to `raspberrypi4-64` with an arm64 architecture.
   - Enable SSH access by exposing port 22.

3. **Device Profile**:
   - Select the device profile `pi_libcamera`. This profile supports launching a basic Ubuntu container and includes necessary configurations for camera usage if needed.

4. **Lease Configuration**:
   - Set the lease duration to 3 hours.
   - Ensure that the platform version is set to 2, which aligns with the current CHI@Edge setup.

5. **Launch Container**:
   - Once the resources are reserved and configured as specified above, you can launch your container using SSH access provided on port 22.

By following these steps, you will have a basic Ubuntu container running on a Raspberry Pi 4 (64-bit) with SSH access available for further configuration or experimentation.
