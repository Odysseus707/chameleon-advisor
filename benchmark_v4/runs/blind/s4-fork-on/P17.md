To capture a 1080p still from the Pi Camera and download it using CHI@Edge, follow these steps:

### Step-by-Step Instructions

#### 1. Launch an Instance on CHI@Edge:
First, you need to launch an instance with the specified configuration.

```bash
chi edge lease create --machine-type raspberrypi4-64 \
                      --image ghcr.io/chameleoncloud/edge-picamera-image:latest \
                      --device-profiles pi_libcamera \
                      --lease-duration 3h
```

This command will launch a Raspberry Pi 4 instance with the necessary image and device profile for camera operations.

#### 2. SSH into the Instance:
Once your lease is active, you can SSH into the instance to run commands directly on it.

```bash
chi edge ssh <instance-id>
```
Replace `<instance-id>` with the actual ID of your leased instance.

#### 3. Capture a Still Image:
Use `libcamera-still` to capture an image in 1080p resolution (1920x1080).

```bash
libcamera-still -o image.jpg --width 1920 --height 1080
```

This command captures a still image and saves it as `image.jpg` with the specified resolution.

#### 4. Download the Image:
To download the captured image from your instance to your local machine, you can use SCP (Secure Copy).

```bash
scp <instance-username>@<instance-ip>:/path/to/image.jpg /local/path/
```
Replace `<instance-username>` and `<instance-ip>` with the appropriate username and IP address of your CHI@Edge instance. Replace `/path/to/image.jpg` with the actual path where `image.jpg` is saved on the instance, and replace `/local/path/` with the desired local directory.

### Example:
If you have an SSH connection to the instance as user `pi`, and the image is located at `/home/pi/image.jpg`, and you want to download it to your local machine's Downloads folder:

```bash
scp pi@<instance-ip>:/home/pi/image.jpg ~/Downloads/
```

This will transfer the captured 1080p still image from the Pi Camera on CHI@Edge to your local machine.
