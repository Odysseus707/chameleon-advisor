To launch a container with the Pi camera enabled on Chameleon Cloud, follow these steps:

1. **Select the Appropriate Machine Type**: Use `raspberrypi4-64` as it supports the necessary `pi_libcamera` profile for camera support and matches the arm64 architecture.

2. **Choose the Correct Image**: Utilize the image `ghcr.io/chameleoncloud/edge-picamera-image:latest`, which is designed to work with the Pi camera.

3. **Specify Device Profile**: Ensure that you include the device profile `pi_libcamera` in your request, as this enables the necessary hardware support for the Pi camera.

4. **Set Up Your Lease**: Request a lease with the following parameters:
   - Count: 1
   - Duration Hours: 3 (or any other duration based on your needs)
   - Platform Version: 2

5. **Launch the Container**:
    - Use the Chameleon Cloud interface or API to launch an instance of `raspberrypi4-64` with the specified image and device profile.
    - Ensure that you have access to the necessary credentials and permissions.

Here is a simplified example using the command line (assuming you have the appropriate tools installed):

```bash
# Example command to launch the container (syntax may vary based on your specific environment)
chameleon-cloud-launch --machine-type raspberrypi4-64 \
                       --image ghcr.io/chameleoncloud/edge-picamera-image:latest \
                       --device-profiles pi_libcamera \
                       --lease-duration 3
```

This command will launch a container with the Pi camera enabled, using the specified image and device profile on a Raspberry Pi 4 machine. Adjust the lease duration as needed for your experiment or application.

Remember to check the Chameleon Cloud documentation for any additional setup steps or specific commands required in your environment.
