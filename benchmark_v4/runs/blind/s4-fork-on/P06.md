To ensure your container stays running on CHI@Edge so you can exec into it, use an image that keeps processes alive such as `ghcr.io/chameleoncloud/edge_ssh_image:latest`. This specific image is designed to stay running and allows for SSH access.

Here are the steps to launch a container with this image:

1. **Request Resources**: Request resources on CHI@Edge specifying the machine type, architecture, image, device profiles, lease duration, etc., as recommended in your context.
   
2. **Launch Container**: Use the `chi` command-line tool or API to launch a container using the specified image (`ghcr.io/chameleoncloud/edge_ssh_image:latest`). Ensure that you expose port 22 for SSH access.

3. **Keep Running**: The `edge_ssh_image` is configured to keep running by default, which means your container will not exit immediately and will be available for exec commands or SSH sessions.

Example command using the `chi` CLI:
```bash
chi launch --image ghcr.io/chameleoncloud/edge_ssh_image:latest --expose 22
```

This setup should allow you to keep the container running and enable you to execute commands inside it via SSH.
