To convert your CHI@UC bare-metal script to run on CHI@Edge, you need to adjust several aspects since CHI@Edge is designed for edge computing with different hardware profiles compared to traditional bare metal nodes.

Here’s how you can adapt your script:

1. **Change the Site**: Update the site from `CHI@UC` to `CHI@Edge`.
2. **Adjust Node Type and Reservation Details**: Since CHI@Edge uses Raspberry Pi devices, change the node type to match the recommended edge device (`raspberrypi4-64`). Also, adjust the reservation details according to the recommendation.
3. **Image Selection**: Use an appropriate image for the Raspberry Pi, such as `ghcr.io/chameleoncloud/edge_ssh_image:latest`.

Here is your adapted script:

```python
import chi

# Change site from CHI@UC to CHI@Edge
chi.use_site('CHI@Edge')

# Request a lease for nodes (Raspberry Pi 4) for 24 hours
reservations = []
node_type = "raspberrypi4-64"  # Recommended machine type
node_count = 2                 # Number of devices to reserve

chi.lease.add_node_reservation(reservations, count=node_count,
                               node_type=node_type)

start_date, end_date = chi.lease.lease_duration(hours=24)
lease_name = "my-edge-lease"
lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date,
                               end_date=end_date)

# Wait for lease to become active
chi.lease.wait_for_active(lease.id)

# Launch instances against the lease (using SSH image for Raspberry Pi)
reservation_id = get_node_reservation(lease.id)  # Assuming this function retrieves reservation ID
image_name = "ghcr.io/chameleoncloud/edge_ssh_image:latest"  # Recommended edge image

server = create_server(server_name="my-edge-server", reservation_id=reservation_id,
                       image_name=image_name, count=node_count)
```

### Explanation:
- **Site Change**: `chi.use_site('CHI@Edge')` sets the context to CHI@Edge.
- **Node Type and Count**: Adjusted for Raspberry Pi 4 devices (`raspberrypi4-64`) with a count of 2.
- **Lease Duration**: Set to 24 hours as recommended.
- **Image Selection**: Used `ghcr.io/chameleoncloud/edge_ssh_image:latest` which is suitable for the Raspberry Pi.

This script should now work on CHI@Edge, leveraging its edge computing capabilities with Raspberry Pi devices.
