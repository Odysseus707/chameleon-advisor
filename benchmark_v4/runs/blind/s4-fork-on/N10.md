To reserve and launch a container on the `iot-rpi4-picam3` device with both a camera module and a Sense HAT, follow these steps:

1. **Reserve the Device:**
   - Use the CHI@Edge reservation system to lease the `raspberrypi4-64` machine named `iot-rpi4-picam3`. Ensure you specify that you need one device for three hours with the appropriate device profiles (`pi_libcamera`, `pi_sensehat`) and the image `ghcr.io/chameleoncloud/edge_sensehat_image:latest`.

2. **Launch a Container:**
   - Once the reservation is confirmed, launch a container using the specified image on the reserved device.

3. **Verify Camera Access:**
   - After launching the container, you can verify that the camera module is accessible by listing available cameras.
     ```bash
     v4l2-ctl --list-devices
     ```
   - This command should list `/dev/video0` or similar as a video device.

4. **Verify Sense HAT Access:**
   - To probe and verify the sensor bus, you can use Python scripts that interact with the Sense HAT.
     ```python
     from sense_hat import SenseHat

     sense = SenseHat()
     temp = sense.get_temperature()
     print("Temperature:", temp)
     ```
   - This script initializes a `SenseHat` object and retrieves temperature data to confirm the sensor is accessible.

By following these steps, you can ensure that both peripherals are correctly accessed within your container on the reserved device.
