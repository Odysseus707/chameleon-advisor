To launch an Ollama container on your existing CHI@Edge lease named `my-llm-lease` with GPU support, exposing only the Ollama API port, and giving it a public IP, follow these steps:

1. **SSH into Your Lease**: First, SSH into the device where your lease is active.

2. **Pull the Ollama Container**: Ensure you have the latest version of the Ollama container.
    ```bash
    docker pull ollama/ollama:latest
    ```

3. **Run the Ollama Container with GPU Support**:
    - Use `nvidia-docker` or `docker` with the appropriate runtime to ensure GPU support.
    - Expose only port 8000 for the Ollama API and request a public IP.

    ```bash
    docker run --gpus all -p 8000:8000 --network=host ollama/ollama:latest
    ```

4. **Configure Firewall (if necessary)**:
    If your device has firewall rules that block port 8000, you need to open this port.
    ```bash
    sudo firewall-cmd --zone=public --add-port=8000/tcp --permanent
    sudo firewall-cmd --reload
    ```

5. **Verify the Container is Running**:
    Check if the container is running and accessible on port 8000.
    ```bash
    docker ps
    curl http://localhost:8000
    ```

6. **Accessing Public IP**:
    Ensure your device has a public IP address assigned to it, which you can find in the Chameleon Cloud dashboard or by running `curl ifconfig.me` on the device.

By following these steps, you will have an Ollama container running with GPU support and accessible via its API port 8000 over a public IP.
