To reserve the Pi 5 named `nyu-rpi5-03` for exactly 2 hours using `python-chi`, and then launch the Jupyter minimal-notebook container on it with port 8888 and a public IP, follow these steps:

1. **Install python-chi**: If you haven't already installed `python-chi`, you can do so by running:
   ```bash
   pip install chi
   ```

2. **Authenticate to Chameleon Cloud**: Ensure that your environment is authenticated with the Chameleon Cloud credentials.

3. **Reserve Resources**:
    - Use `python-chi` to reserve the specific resource (`nyu-rpi5-03`) for 2 hours.
    ```python
    from chi import Chi

    # Initialize CHI client
    chi = Chi()

    # Reserve resources
    reservation = chi.reserve(
        machine_type="raspberrypi4-64",
        count=1,
        duration_hours=2,
        name="nyu-rpi5-03"
    )
    ```

4. **Launch the Jupyter Container**:
    - After reserving, launch a container with the specified image and expose port 8888.
    ```python
    # Launch instance with specific image and exposed ports
    instance = chi.launch(
        reservation_id=reservation.id,
        image="ghcr.io/chameleoncloud/edge-picamera-image:latest",
        device_profiles=["pi_libcamera"],
        exposed_ports=[8888],
        public_ip=True  # Request a public IP address
    )
    ```

5. **Access the Jupyter Notebook**:
   - Once the instance is launched, you can access the Jupyter notebook by navigating to the public IP address of the instance on port 8888.

Note: The above code snippets are illustrative and assume that `python-chi` has methods like `reserve()` and `launch()`. You should refer to the official documentation for exact method names, parameters, and usage.
