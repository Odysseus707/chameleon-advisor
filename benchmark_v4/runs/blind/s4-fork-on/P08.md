To run `ls /app` inside a running container in CHI@Edge and capture the output, you can use SSH access as described in the blog post:

1. First, ensure that your container is running on CHI@Edge.
2. Use the SSH method to connect to the running container:
   ```bash
   ssh <username>@<container-ip>
   ```
   Replace `<username>` with the appropriate username and `<container-ip>` with the IP address of the container.

3. Once connected via SSH, you can run the `ls /app` command inside the container:
   ```bash
   ls /app
   ```

4. To capture the output of this command, you can redirect it to a file or use other shell redirection techniques:
   ```bash
   ls /app > output.txt
   ```
   This will save the list of files in `/app` to `output.txt`.

By following these steps, you can access and interact with your container directly via SSH, making it easier to debug and manage your applications on CHI@Edge.
