To reserve one Raspberry Pi 4 for 10 hours starting now and launch a `python:3.9-slim` container with SSH installed and reachable from outside using the imperative style of the python-chi API, follow these steps:

1. **Import Required Modules**: Import the necessary modules from `chi`.
2. **Reserve Resources**: Reserve one Raspberry Pi 4 for 10 hours.
3. **Launch Container**: Launch a container with the specified image and expose SSH port.

Here is how you can do it:

```python
from chi import reserve, launch

# Step 1: Reserve resources
lease = reserve(
    count=1,
    duration_hours=10,
    machine_type="raspberrypi4-64",
    architecture="arm64"
)

# Step 2: Launch container with python:3.9-slim and SSH access
container = launch(
    lease_id=lease['id'],
    image="python:3.9-slim",
    exposed_ports=[22]  # Expose port 22 for SSH
)
```

This code reserves one Raspberry Pi 4 for a duration of 10 hours starting now and launches a container with the `python:3.9-slim` image, ensuring that SSH is accessible from outside by exposing port 22.

Note: Ensure you have the necessary permissions and configurations set up to use the CHI API and access the resources.
