To reserve a Raspberry Pi on CHI@Edge and get the `reservation_id` that you can pass to a container, follow these steps using the `python-chi` library:

1. Import the necessary modules from `chi`.
2. Use the site 'CHI@UC' for your reservation.
3. Define the reservations with the required node type (`raspberrypi4-64`) and count (in this case, 1).
4. Set a lease duration of 3 hours.
5. Create the lease using `chi.lease.create_lease`.
6. Wait for the lease to become active.
7. Retrieve the reservation ID from the lease.

Here is how you can do it:

```python
import chi

# Use CHI@UC site
chi.use_site('CHI@UC')

# Define reservations with Raspberry Pi 4 (raspberrypi4-64) and count=1
reservations = []
chi.lease.add_node_reservation(reservations, count=1, node_type='raspberrypi4-64')

# Set lease duration for 3 hours
start_date, end_date = chi.lease.lease_duration(hours=3)

# Create the lease
lease_name = "my-edge-lease"
lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date, end_date=end_date)

# Wait for the lease to become active
chi.lease.wait_for_active(lease.id)

# Retrieve reservation ID from the lease
reservation_id = get_node_reservation(lease.id)
```

Note: The function `get_node_reservation` is assumed to be a helper function that retrieves the node reservation ID from the lease object, which you would need to define or ensure exists in your environment. This example assumes it's available and correctly implemented.

This process will give you the `reservation_id`, which can then be used when launching containers on CHI@Edge.
