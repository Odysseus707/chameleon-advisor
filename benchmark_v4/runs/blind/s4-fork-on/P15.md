To find and reserve a Raspberry Pi 4 (64-bit) with a camera attached using CHI@Edge:

1. Identify the machine type: `raspberrypi4-64` with device profile `pi_libcamera`.
2. Use the image: `ghcr.io/chameleoncloud/edge-picamera-image:latest`, which is designed for workloads requiring a camera module.
3. Reserve one instance (`count=1`) of this machine type for up to 3 hours (`duration_hours=3`).

Here's how you can reserve it:

```python
from chi.edge import CHIEdge

chi_edge = CHIEdge()

# Define the reservation parameters
reservation_params = {
    'machine_type': 'raspberrypi4-64',
    'device_profiles': ['pi_libcamera'],
    'lease': {
        'count': 1,
        'duration_hours': 3,
        'platform_version': 2
    }
}

# Reserve the resource
reservation = chi_edge.reserve(**reservation_params)

print(reservation)
```

This script reserves one Raspberry Pi 4 (64-bit) with a camera module attached for up to 3 hours.
