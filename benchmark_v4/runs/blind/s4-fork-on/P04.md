To reserve 3 Raspberry Pis on CHI@Edge using the `raspberrypi4-64` type in one lease, follow these steps:

1. **Install and Configure Python CHI**: Ensure you have the `python-chi` package installed and configured with your Chameleon credentials.

2. **Create a Lease Request**:
   - Use the `chi.lease` module to create a lease request for 3 Raspberry Pi 4 devices (`raspberrypi4-64`). The lease should specify the image, device profiles, and duration as per your requirements.
   
3. **Specify Details**:
   - Machine Type: `raspberrypi4-64`
   - Architecture: `arm64`
   - Image: `ghcr.io/chameleoncloud/edge-picamera-image:latest`
   - Device Profiles: `['pi_libcamera']`
   - Lease Duration: 3 hours
   - Count: 3

Here is a sample code snippet to create the lease:

```python
from chi.lease import LeaseManager, LeaseRequest

# Initialize the lease manager
manager = LeaseManager()

# Define the lease request
request = LeaseRequest(
    count=3,
    duration_hours=3,
    machine_type="raspberrypi4-64",
    image="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    device_profiles=['pi_libcamera']
)

# Submit the lease request
lease = manager.create_lease(request)
print(f"Lease created with ID {lease.id}")
```

This code will create a lease for 3 Raspberry Pi 4 devices, ensuring they are all of the same type and available for your experiment within the specified duration.
