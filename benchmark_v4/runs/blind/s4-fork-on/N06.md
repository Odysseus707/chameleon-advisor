To update your old tutorial script to use the current object-oriented API, you need to replace the imperative style with the class-based approach using `lease.Lease` and `container.Container`. Here's how you can rewrite it:

```python
from chi import Lease, Container

# Set up the site and project name
chi.use_site("CHI@Edge")
chi.set("project_name", "CHI-000000")

# Create a lease object with desired specifications
lease_obj = Lease(
    name="demo-lease",
    device_type="raspberrypi4-64",
    count=1,
    duration_hours=10,
)

# Wait for the lease to become active
lease_obj.wait_for_active()

# Once the lease is active, create a container on one of the reserved devices
container_obj = Container(
    name="demo-app",
    image="python:3.9-slim",
    reservation_id=lease_obj.device_reservations[0],
    exposed_ports=[22],
    platform_version=2,
)
```

This script uses the `Lease` and `Container` classes to create a lease for one Raspberry Pi 4 device, waits until it becomes active, and then creates a container on that device. The behavior is kept identical to your original script but now follows the object-oriented API style recommended by Chameleon Cloud's current documentation.
