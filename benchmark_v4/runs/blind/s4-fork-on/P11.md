To launch an SSH-enabled container on a reserved Raspberry Pi 4 (64-bit) from Chameleon Cloud and connect to it via SSH, follow these steps:

1. **Reserve a Node:**
   - Reserve a `raspberrypi4-64` node through the Chameleon Cloud interface or using their Python library.

2. **Launch an Instance with the Specified Image:**
   - Use the image `ghcr.io/chameleoncloud/edge_ssh_image:latest`.
   - Ensure that port 22 (SSH) is exposed when launching your instance.

3. **Obtain Floating IP:**
   - Once your instance is running, associate a floating IP with it so you can connect from outside Chameleon Cloud's network.

4. **Connect via SSH:**
   - Use the following command to connect to your Raspberry Pi 4 instance:
     ```bash
     ssh -i /path/to/your/private/key cc@<your-floating-ip>
     ```
   - Replace `/path/to/your/private/key` with the path to your private key file.
   - Replace `<your-floating-ip>` with the floating IP address you obtained.

5. **Verify Connection:**
   - After connecting, you should see a terminal prompt indicating that you are connected to the instance:
     ```
     cc@my-first-instance:~$
     ```

By following these steps, you will have successfully launched an SSH-enabled container on a reserved Raspberry Pi 4 and connected to it via SSH.
