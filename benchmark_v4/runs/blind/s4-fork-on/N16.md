To run GPU-accelerated inference on a Jetson-class device on CHI@Edge, follow these steps:

1. **Reserve a Device:**
   - Use the Chameleon Cloud interface to reserve one Jetson Xavier NX device for your project.
   - Specify that you need a device with GPU capabilities and request it for at least 3 hours.

2. **Start a CUDA-Capable Container:**
   - Once the reservation is confirmed, access the device using SSH by connecting to its IP address or hostname provided in the Chameleon Cloud interface.
   - Pull the specified container image `ghcr.io/chameleoncloud/edge_ssh_image:latest` onto your Jetson Xavier NX device. This can be done with a command like:
     ```bash
     docker pull ghcr.io/chameleoncloud/edge_ssh_image:latest
     ```
   - Run the container with the NVIDIA runtime to ensure GPU access is enabled. Use a command similar to this:
     ```bash
     nvidia-docker run --rm -it --runtime=nvidia ghcr.io/chameleoncloud/edge_ssh_image:latest /bin/bash
     ```

3. **Run Your Inference Code:**
   - Inside the container, you can now execute your GPU-accelerated inference code.
   - Ensure that any CUDA or other GPU-specific libraries are installed and properly configured within the container.

By following these steps, you will have a Jetson Xavier NX device reserved on CHI@Edge with a running CUDA-capable container ready for executing GPU-accelerated tasks.
