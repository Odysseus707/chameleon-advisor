To record a 10-second 720p video at 30 fps from the Pi camera and download it to your machine, follow these steps:

1. **Provision an Edge Node:**
   - Use the `raspberrypi4-64` machine type with the `pi_libcamera` device profile.
   - Ensure you have the image `ghcr.io/chameleoncloud/edge-picamera-image:latest`.

2. **SSH into your CHI@Edge node:**
   - Connect to the Raspberry Pi 4 via SSH.

3. **Record Video:**
   - Use the `libcamera-vid` command to record a video.
     ```bash
     libcamera-vid --width 1280 --height 720 --framerate 30 --length 10 --output video.h264
     ```
   - This command records a 720p (1280x720) video at 30 fps for 10 seconds and saves it as `video.h264`.

4. **Download the Video:**
   - Use SCP or SFTP to download the recorded video file (`video.h264`) from your CHI@Edge node to your local machine.
     ```bash
     scp username@your_chameleon_edge_node_ip:/path/to/video.h264 /local/path/
     ```

5. **Convert Video (Optional):**
   - If you need the video in a different format, such as MP4, use `ffmpeg` or another tool to convert it.
     ```bash
     ffmpeg -i video.h264 -c copy video.mp4
     ```
   - You can then download the converted file using SCP.

By following these steps, you will be able to record a 10-second 720p video at 30 fps from the Pi camera and download it to your machine.
