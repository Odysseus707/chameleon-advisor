To reserve a camera-equipped Raspberry Pi from Chameleon Cloud, start the camera container, and retrofit SSH access, follow these steps:

1. **Reserve an Edge Node:**
   - Go to the Chameleon Cloud portal.
   - Navigate to the section where you can create leases for VMs or edge nodes.
   - Request a lease for one Raspberry Pi 4 (raspberrypi4-64) with ARM64 architecture and no GPU requirements. Ensure that port 22 is exposed.

2. **Launch an Instance:**
   - Once the reservation is confirmed, go to the Instances section under Compute in the navigation sidebar.
   - Click on "Launch Instance" or a similar button to start creating your instance.
   - Select the appropriate flavor for Raspberry Pi 4 (raspberrypi4-64).

3. **Configure SSH Key Pair:**
   - Go to the Key Pair tab and select an existing key pair that includes your public SSH key, or create a new one if necessary.

4. **Set Up Security Groups:**
   - Navigate to the Security Groups tab.
   - Ensure that port 22 (SSH) is open for incoming connections by configuring the security group rules accordingly.

5. **Select Network Configuration:**
   - Go to the Network tab and select your project’s private network, not ext-net.

6. **Launch Instance with Camera Image:**
   - Use the image `ghcr.io/chameleoncloud/edge-picamera-image:latest` for starting the camera service.
   - Launch the instance using this image.

7. **Retrofit SSH Access:**
   - After launching the instance, you need to retrofit SSH access into it:
     - Log in to your Chameleon Cloud account and navigate to the Instances section.
     - Find your newly created Raspberry Pi 4 instance and click on its name for more details.
     - Use the VNC interface or another method provided by Chameleon Cloud to connect to the console of this instance.
     - Once connected, you can install an SSH server if it's not already installed (`sudo apt-get update && sudo apt-get install openssh-server`).
     - Configure root login and add your public key to `/root/.ssh/authorized_keys`.

8. **Assign Floating IP (if needed):**
   - If external access is required, associate a floating IP address with the instance by selecting "Associate Floating IP" from the dropdown menu next to the instance.

9. **Verify SSH Access:**
   - Use `ssh root@<floating_ip>` or `<private_ip>` to log in as root and verify that you can run commands on the Raspberry Pi 4.
   
10. **Teammate Collaboration:**
    - Provide your teammate with the floating IP (or private IP if within the same network) and instruct them to use `ssh root@<ip_address>` to access the instance.

By following these steps, you will have a camera-equipped Raspberry Pi running on Chameleon Cloud with SSH access configured for collaboration.
