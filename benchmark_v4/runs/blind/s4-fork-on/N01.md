To reserve three `raspberrypi4-64` devices on CHI@Edge for 6 hours in one lease and launch an SSH-enabled container, follow these steps:

1. **Log into the Chameleon Cloud Portal:**
   - Go to the Chameleon Cloud portal and log in with your credentials.

2. **Access the CHI@Edge Dashboard:**
   - Navigate to the CHI@Edge dashboard from the main menu or through the project page where you have access rights.

3. **Reserve Devices:**
   - In the CHI@Edge dashboard, select the option to reserve devices.
   - Choose `raspberrypi4-64` as the machine type and specify that you want 3 of these devices.
   - Set the lease duration for 6 hours.
   - Ensure that the runtime is set appropriately (if required) and expose port 22 for SSH access.

4. **Launch an SSH-enabled Container:**
   - After reserving the devices, use the provided `ghcr.io/chameleoncloud/edge_ssh_image:latest` container image to launch a container on each of the reserved devices.
   - This image is pre-configured with an SSH server that allows you to log in as root.

5. **SSH into the Container:**
   - Once the containers are running, use SSH to connect to them by specifying the IP address and port 22 (or any other exposed port if different).
   - Log in using the `root` user credentials provided with the container image.

By following these steps, you will have three `raspberrypi4-64` devices reserved for 6 hours each, with SSH-enabled containers running on them that allow root login.
