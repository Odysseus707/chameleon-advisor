To launch an SSH-enabled container on a reserved Raspberry Pi (or any other node) and connect to it, follow these steps:

1. **Reserve the Node**: First, reserve your desired hardware through Chameleon Cloud's interface or API.

2. **Launch the Instance with Floating IP**:
   - Once you have reserved the node, launch an instance on that node.
   - Ensure that a floating IP is associated with this instance so it can be accessed from outside the network.

3. **Prepare SSH Key**: 
   - If you haven't already, generate an SSH key pair or use an existing one.
   - Add your public key to the Chameleon Cloud system during the launch process if required.

4. **Connect via SSH**:
   - Once your instance is running and has a floating IP associated with it, open a terminal on your local machine.
   - Use the following command to connect to your instance:

     ```bash
     ssh -i /path/to/your/private/key cc@<your-floating-ip>
     ```

     Replace `/path/to/your/private/key` with the path to your private key file and `<your-floating-ip>` with the floating IP address of your instance.

5. **Verify Connection**:
   - After successfully connecting, you should see a terminal prompt indicating that you are now running commands directly on the bare metal node (e.g., `cc@my-first-instance:~$`).

By following these steps, you will have launched an SSH-enabled container on a reserved Raspberry Pi and connected to it via SSH.
