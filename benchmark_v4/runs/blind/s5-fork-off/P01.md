To set up `python-chi` targeting CHI@Edge and select your project, you can use the following minimal setup:

```python
import chi

# Set the site to CHI@Edge
chi.use_site("CHI@Edge")

# Replace 'YOUR_PROJECT_NAME' with your actual Chameleon project name
chi.use_project("YOUR_PROJECT_NAME")
```

This code sets up `python-chi` to target the CHI@Edge testbed and specifies which project you are working on. Make sure to replace `"YOUR_PROJECT_NAME"` with the actual name of your Chameleon project.
