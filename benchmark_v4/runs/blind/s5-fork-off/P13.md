For SSH access on CHI@Edge, you need to ensure that:

1. You are using an image that supports SSH (most Chameleon-supported images do).
2. The instance's internal firewall allows traffic on port 22 (SSH). By default, the firewall should allow SSH.

Since there is no mention of Security Groups for CHI@Edge in the provided documentation, you don't need to configure a Security Group specifically for allowing SSH access. However, make sure that your instance has a Floating IP associated with it if necessary and that it's connected to an appropriate network (like `sharednet1`).

Remember to use the correct key pair when launching the instance and connecting via SSH.
