To reserve two Raspberry Pi 4s in one CHI@Edge lease and start an SSH-enabled container on each of them, follow these steps:

1. **Create a Lease for the Devices:**
   Use `chi` to create a lease for two Raspberry Pi 4 devices.

```python
import chi

# Create authentication context (most info automatically sourced from env)
chi.use_site('CHI@Edge')

lease_name = "raspberry-pi-lease"
node_type = "RaspberryPi4" # Assuming this is the correct node type identifier for Raspberry Pi 4 in CHI@Edge
node_count = 2

# Request a lease for nodes for 1 hour
reservations = []
chi.lease.add_node_reservation(reservations, count=node_count,
                               node_type=node_type)
start_date, end_date = chi.lease.lease_duration(hours=1)

lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date,
                               end_date=end_date)

# Wait for lease to become active
chi.lease.wait_for_active(lease.id)
```

2. **Prepare SSH-Enabled Container:**
   Follow the tutorial provided in the blog post on enabling SSH access within a container. This involves creating an SSH-ready base container that can be used as a starting point.

3. **Launch Containers on Each Device:**
   Once you have your lease and SSH-enabled container ready, launch containers on each of the reserved Raspberry Pi 4 devices using the SSH-enabled container image.

```python
reservation_id = chi.lease.get_node_reservation(lease.id)

# Assuming `image_name` is the name of your SSH-ready container image.
image_name = "ssh-ready-container-image"

server1 = create_server(server_name="raspberry-pi-1", reservation_id=reservation_id,
                        image_name=image_name, count=1)
server2 = create_server(server_name="raspberry-pi-2", reservation_id=reservation_id,
                        image_name=image_name, count=1)

# Note: `create_server` is a placeholder function. You would need to replace it with the actual method provided by CHI@Edge for launching containers.
```

4. **Access Containers via SSH:**
   After launching the containers on each device, you can access them using SSH.

```bash
ssh user@<ip_address_of_raspberry_pi_1>
ssh user@<ip_address_of_raspberry_pi_2>
```

Replace `<ip_address_of_raspberry_pi_1>` and `<ip_address_of_raspberry_pi_2>` with the actual IP addresses of your devices, which you can find in the CHI@Edge dashboard or through the API.

By following these steps, you will have reserved two Raspberry Pi 4s, launched SSH-enabled containers on each device, and be able to access them via SSH.
