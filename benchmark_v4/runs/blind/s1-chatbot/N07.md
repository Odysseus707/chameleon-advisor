Create a lease: Use the python-chi library to create a lease for two Raspberry Pi 4 nodes. You can do this by setting node_type to the type of Raspberry Pi 4 nodes available on CHI@Edge and node_count to 2.

Define the lease duration: Set the start and end dates for the lease using chi.lease.lease_duration(hours=1) to create a lease for 1 hour.

Create the lease: Use chi.lease.create_lease to create the lease with the specified name, reservations, start date, and end date.

Wait for the lease to become active: Use chi.lease.wait_for_active to wait for the lease to become active before proceeding.
