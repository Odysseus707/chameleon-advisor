To convert your CHI@UC bare-metal script to run on CHI@Edge, you need to consider the differences between bare-metal instances and container-based edge computing.

Understand the differences: CHI@UC offers bare-metal instances, which provide exclusive access to physical hardware resources. In contrast, CHI@Edge is a container-based edge computing testbed, which means it uses virtualized containers instead of bare-metal instances.

Modify the script: Since CHI@Edge uses containers, you cannot directly use the add_node_reservation and create_server functions from the python-chi library, which are designed for bare-metal instances. You need to use the CHI@Edge SDK to interact with the edge devices.

Use the CHI@Edge SDK: The CHI@Edge SDK provides a way to add devices to the testbed, deploy code to the devices, and manage the lifecycle of the code. You can use the SDK to convert your script to work with CHI@Edge.

Here's a high-level example of how you might modify your script:

import chi_edge_sdk

# Set up the CHI@Edge SDK
chi_edge_sdk.init()

# Define the device and deployment
device_name = "my-device"
deployment_name = "my-deployment"

# Create a new deployment
deployment = chi_edge_sdk.create_deployment(deployment_name)

# Add the device to the deployment
chi_edge_sdk.add_device_to_deployment(device_name, deployment.id)

# Deploy the code to the device
chi_edge_sdk.deploy_code(device_name, deployment.id, "my-code")

# Start the deployment
chi_edge_sdk.start_deployment(deployment.id)

Note that this is a simplified example and you will need to consult the CHI@Edge SDK documentation for more information on how to use the SDK and modify your script to work with CHI@Edge.

Also, keep in mind that CHI@Edge has its own set of APIs and tools, which are different from the python-chi library used for bare-metal instances. You will need to familiarize yourself with the CHI@Edge SDK and its documentation to successfully convert your script.
