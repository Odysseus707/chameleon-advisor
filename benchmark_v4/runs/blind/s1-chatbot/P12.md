To inject your public key so you can SSH in as root, you need to import your key pair into Chameleon. Here's how:

Go to the Key Pair tab.
Click the "Import Key Pair" button.
Provide a name for your imported key pair.
Paste your public key (typically found at ~/.ssh/id_rsa.pub).
Note that Chameleon only stores the public key for each SSH key pair, and you should never upload your private key. Once you've imported your key pair, you can select it when launching an instance, and it will be inserted into your virtual machine, allowing you to access the instance via SSH.
