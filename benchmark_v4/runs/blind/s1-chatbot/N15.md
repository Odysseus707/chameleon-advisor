To reserve any free Raspberry Pi 5 on CHI@Edge by machine type for 3 hours, you would use a command similar to the following in the Python CHI client:

from chi import Client

# Initialize the client
client = Client()

# Define the lease duration in seconds (3 hours = 10800 seconds)
lease_duration = 10800

# Define the machine type
machine_type = 'rpi5'

# Reserve the machine
lease = client.reserve(machine_type, lease_duration=lease_duration)

# Print the lease ID
print(lease.id)

This code snippet initializes a CHI client, defines the lease duration and the machine type you're interested in (rpi5 for Raspberry Pi 5), and then attempts to reserve the first available machine of that type for the specified duration. The lease.id is then printed out, which can be used to manage the lease (e.g., release it early if needed).

Please ensure you have the correct credentials set up and the Python CHI client installed to use this functionality.
