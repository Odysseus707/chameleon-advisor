Here's how to do it on CHI@Edge.
Using python-chi (recommended)
pythonimport chi
from chi import lease

chi.use_site("CHI@Edge")

reservations = []
lease.add_device_reservation(
    reservations,
    count=3,
    device_type="raspberrypi4-64",   # or whichever Pi model/type you want
    device_name=None                 # leave unset if you don't need specific nodes
)

start, end = lease.lease_duration(days=1)

my_lease = lease.create_lease(
    "my-3-pi-lease",
    reservations=reservations,
    start_date=start,
    end_date=end,
)

lease.wait_for_active(my_lease["id"])
Key points:

add_device_reservation with count=3 and a single device_type gets you 3 devices of the same type in one reservation, bundled into one lease.
You need the exact CHI@Edge device_type string (e.g. raspberrypi4-64, raspberrypi4-32, etc. — these vary by site inventory). You can check available types with:

pythonfrom chi import edge
edge.list_device_types()
or browse them in the Horizon GUI under Chameleon > CHI@Edge > Reservations > Host Calendar, filtering by device type.
Using the Horizon dashboard instead

Go to the CHI@Edge Horizon dashboard → Project → Reservations → Leases → "Create Lease"
Under the device reservation section, pick "Resource Properties" and filter on device_type (or arch, machine_name, etc.) matching the specific Pi model
Set "Min" and "Max" both to 3
Confirm and create — this produces one lease with a single reservation for 3 matching devices

Using the Blazar CLI
bashblazar lease-create \
  --reservation min=3,max=3,resource_type=device,resource_properties='["==","$device_type","raspberrypi4-64"]' \
  --start-date "2026-07-16 00:00" \
  --end-date "2026-07-17 00:00" \
  my-3-pi-lease
A couple things worth double-checking before you run this:

Availability — 3 free Pis of the same type may not exist right now on CHI@Edge (edge inventory is small and often heavily reserved). Check the host calendar first so the lease doesn't fail or sit pending.
device_type name — get the exact string from edge.list_device_types() rather than guessing, since CHI@Edge naming can differ slightly between sites/models.
