Here's a complete python-chi workflow to reserve nyu-rpi5-03 for 2 hours and launch a Jupyter container on it with a public IP.
pythonimport chi
from chi import container
from chi import lease
from datetime import datetime, timedelta

# --- 0. Configure your project/site ---
chi.use_site("CHI@Edge")          # Pi 5 devices live on CHI@Edge
chi.set("project_name", "YOUR_PROJECT_NAME")

# --- 1. Build a 2-hour lease for the specific device ---
start_date, end_date = lease.lease_duration(days=0, hours=2)

# device_name reservation targets the specific Pi 5 by name
device_reservation = {
    "resource_type": "device",
    "device_name": "nyu-rpi5-03",
    "min": 1,
    "max": 1,
}

lease_name = "nyu-rpi5-03-lease"

reservations = []
lease.add_device_reservation(reservations, device_name="nyu-rpi5-03", count=1)

# Also reserve a floating/public IP for the container
lease.add_fip_reservation(reservations, count=1)

my_lease = lease.create_lease(
    lease_name,
    reservations=reservations,
    start_date=start_date,
    end_date=end_date,
)

lease_id = my_lease["id"]
print(f"Lease created: {lease_id}, waiting for it to become active...")

lease.wait_for_active(lease_id)
print("Lease is active.")

# --- 2. Pull reservation IDs out of the lease ---
device_reservation_id = lease.get_device_reservation(lease_id)
fip_reservation_id = lease.get_reservation_by_type(lease_id, "floatingip")["id"]

# --- 3. Launch the Jupyter minimal-notebook container ---
container_name = "nyu-rpi5-03-jupyter"

my_container = container.create_container(
    container_name,
    image="jupyter/minimal-notebook:latest",
    reservation_id=device_reservation_id,
    exposed_ports=[8888],
    environment={"JUPYTER_TOKEN": "chameleon"},  # optional: set a fixed token
)

print(f"Container {container_name} created, waiting for it to be active...")
container.wait_for_active(my_container.uuid)

# --- 4. Associate the public IP with the container ---
public_ip = container.associate_floating_ip(my_container.uuid)
print(f"Container is up. Access Jupyter at: http://{public_ip}:8888")

# --- 5. Optional: retrieve the auto-generated Jupyter token/logs if not set manually ---
logs = container.get_logs(my_container.uuid)
print(logs)
Notes:

Site: Chameleon's Pi 5 devices are typically registered on CHI@Edge. If nyu-rpi5-03 actually lives on a different site (e.g., a custom testbed site), swap the chi.use_site(...) call accordingly.
Lease duration: lease.lease_duration(days=0, hours=2) gives you a start/end pair exactly 2 hours apart from "now."
Device targeting: Using device_name="nyu-rpi5-03" in the reservation pins the lease to that specific node rather than any Pi 5 in the pool.
Public IP: The add_fip_reservation call reserves a floating IP as part of the same lease, and associate_floating_ip attaches it to the running container so it's reachable externally on port 8888.
Token: I set a fixed JUPYTER_TOKEN env var for convenience — remove it if you'd rather fetch the auto-generated token from the container logs.
Cleanup: When you're done, call container.destroy_container(my_container.uuid) and lease.delete_lease(lease_id) to release resources before the 2-hour window ends if you don't need the full time.
