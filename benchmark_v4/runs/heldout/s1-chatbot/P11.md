To launch an SSH-enabled container on a reserved Pi and connect to it, follow these steps:

Reserve a Pi device using the lease module from the chi library.
Launch a container on the reserved device using the container module from the chi library. Make sure to specify the device_profiles parameter with the pi_ssh profile to enable SSH access.
Use the execute method of the container object to run a command that installs and starts an SSH server inside the container.
Use an SSH client to connect to the container using the IP address and port number of the container.
Here's an example code snippet that demonstrates these steps:

from chi import lease, container

# Reserve a Pi device
lease_name = "my-lease"
device_name = "iot-rpi4-picam"
lease = lease.Lease(lease_name, duration=3600)
lease.add_device_reservation(device_name=device_name)
lease.submit()

# Launch a container on the reserved device
container_name = "my-container"
image_ref = "ghcr.io/chameleoncloud/edge-picamera-image:latest"
device_profiles = ["pi_ssh"]
container = container.Container(container_name, image_ref, device_profiles=device_profiles, reservation_id=lease.device_reservations[0]["id"])
container.submit()

# Install and start an SSH server inside the container
cmd = "apt-get update && apt-get install -y openssh-server && service ssh start"
container.execute(cmd)

# Connect to the container using SSH
ip_address = container.ip_address
port = 22
ssh_cmd = f"ssh -p {port} {ip_address}"
print(ssh_cmd)
