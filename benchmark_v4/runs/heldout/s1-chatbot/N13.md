To reserve one Pi 4 for 10 hours starting now and launch python:3.9-slim on it with SSH installed and reachable from outside using the imperative python-chi API, you can use the following code:

from chi import lease, container

# Set the site and project
chi.set("site", "CHI@Edge")
chi.set("project", "your_project_name")

# Reserve a device
device_type = "raspberrypi4-64"
lease_id = lease.create_lease(duration=36000, resources=[{"type": device_type, "count": 1}])

# Get the device ID
device_id = lease.get_devices(lease_id)[0]["id"]

# Launch a container on the device
container_id = container.create_container(device_id, "python:3.9-slim", command=["sleep", "infinity"], ssh=True)

# Wait for the container to be ready
container.wait_for_container(container_id)

# Get the SSH connection details
ssh_info = container.get_ssh_info(container_id)

print("SSH connection details:")
print("Host:", ssh_info["host"])
print("Port:", ssh_info["port"])
print("Username:", ssh_info["username"])
print("Password:", ssh_info["password"])

Note: Replace "your_project_name" with your actual project name. Also, make sure you have the necessary credentials and permissions to reserve devices and launch containers on CHI@Edge.
