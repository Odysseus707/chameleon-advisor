To launch the Jupyter minimal-notebook container on your active lease 'serve-edge-vr' on a Raspberry Pi 5, give it a public IP, and find the notebook's token URL from the container logs, follow these steps:

Create a container: Use the container.create_container method from the chi library to create a new container. Specify the image as 'jupyter/minimal-notebook' and set the reservation ID to your lease ID 'serve-edge-vr'. Also, make sure to expose port 8888.

Associate a floating IP: After creating the container, use the chi.container.associate_floating_ip method to assign a floating IP address to your container. This will allow you to access the container from outside the Chameleon network.

Get the container logs: Use the chi.container.logs method to retrieve the logs of your container. The notebook's token URL will be printed in the logs.

Here's a sample code snippet that demonstrates these steps:

import chi

# Create a container
container_name = "jupyter-notebook"
image_ref = "jupyter/minimal-notebook"
reservation_id = "serve-edge-vr"  # Replace with your lease ID
exposed_ports = [8888]

my_container = chi.container.create_container(
    container_name, image_ref, exposed_ports=exposed_ports, reservation_id=reservation_id
)

# Associate a floating IP
ip_address = chi.container.associate_floating_ip(my_container.uuid)

# Get the container logs
logs = chi.container.logs(my_container.uuid)
print(logs)

# The token URL will be in the format: http://<ip_address>:8888/tree?token=<token>

Note that you'll need to replace 'serve-edge-vr' with your actual lease ID. Also, make sure to handle any exceptions that may occur during the execution of these steps.
