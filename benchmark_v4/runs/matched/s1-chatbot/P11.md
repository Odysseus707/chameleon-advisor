To launch an SSH-enabled container on a reserved Pi and connect to it, follow these steps:

Create a lease: First, create a lease for a Raspberry Pi 4 device using the CHI@Edge testbed. You can do this by selecting the "CHI@Edge" site and following the instructions for creating a lease.

Create a container: Once your lease is active, create a container using the container.create_container method from the chi library. You will need to specify the image you want to use, which in this case is an Ubuntu 22.04 image with SSH setup.

Upload your public key: Upload your RSA public key to the container using the chi.container.upload method. This will allow you to connect to the container via SSH.

Set up authorized keys: Copy your public key to the authorized keys file in the container using the chi.container.execute method. This will allow you to connect to the container without a password.

Associate a floating IP: Associate a floating IP address with your container using the chi.container.associate_floating_ip method. This will give you an IP address that you can use to connect to the container.

Connect via SSH: Finally, connect to your container via SSH using the IP address and the command ssh root@<IP_ADDRESS>.

Here is some sample code to illustrate these steps:

import chi

# Create a lease
lease_name = "ssh-lease"
machine_name = "raspberrypi4-64"
start, end = lease.lease_duration(days=1)
reservations = []
lease.add_device_reservation(reservations, count=1, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]
lease.wait_for_active(lease_id)

# Create a container
container_name = "ssh-container"
image = "ghcr.io/chameleoncloud/edge_ssh_image:latest"
my_container = container.create_container(
    container_name,
    image=image,
    workdir="/home",
    exposed_ports=[22],
    reservation_id=lease.get_device_reservation(lease_id),
    platform_version=2,
)

# Upload public key
chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")

# Set up authorized keys
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)
cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Associate a floating IP
ip_address = chi.container.associate_floating_ip(my_container.uuid)

# Connect via SSH
print("use the following command to ssh into the container: ssh root@" + ip_address)
