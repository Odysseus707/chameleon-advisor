To get a Raspberry Pi on CHI@Edge that you can access with VS Code Remote-SSH, follow these steps:

Create a lease: Use the CHI@Edge GUI or the lease module in Python to create a lease for a Raspberry Pi 4 device. You can use the lease_duration function to specify the duration of the lease.

Create a container: Use the container module in Python to create a container on the leased device. You can use the create_container function to specify the image, workdir, exposed ports, and other settings.

Add your public key to the container: Upload your RSA public key to the container and add it to the authorized keys file. You can use the upload and execute functions in Python to do this.

Associate a floating IP address: Associate a floating IP address with the container so that you can access it from outside the CHI@Edge network. You can use the associate_floating_ip function in Python to do this.

SSH into the container: Use the floating IP address and your private key to SSH into the container. You can use VS Code Remote-SSH to access the container and start working on your project.

Here's some sample Python code to get you started:

import chi
chi.use_site("CHI@Edge")
chi.set("project_name", "Chameleon")

from chi import container
from chi import lease

# Create a lease
machine_name = "raspberrypi4-64"
start, end = lease.lease_duration(days=1)
lease_name = f"ssh-{machine_name}-{start}"
reservations = []
lease.add_device_reservation(reservations, count=2, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]
lease.wait_for_active(lease_id)

# Create a container
container_name = f"tutorial-{machine_name}-ssh".replace("_","-")
my_container = container.create_container(
    container_name,
    image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
    workdir="/home",
    exposed_ports=[22],
    reservation_id=lease.get_device_reservation(lease_id),
    platform_version=2,
)

# Add your public key to the container
chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)
cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Associate a floating IP address
ip_address = chi.container.associate_floating_ip(my_container.uuid)

# SSH into the container
print("use the following command to ssh into the container: ssh root@" + ip_address)

Note that you'll need to replace the edge_user_public_key file with your own RSA public key, and update the image parameter in the create_container function to use the correct image for your project.
