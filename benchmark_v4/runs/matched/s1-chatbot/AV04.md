To print the device_name of every currently-free CHI@Edge device that supports the pi_sensehat device profile, you can use the following Python code with the python-chi library:

from chi import hardware

# Choose the CHI@Edge site
hardware.choose_site(default="CHI@Edge")

# Get available devices that support the pi_sensehat device profile
available_devices = hardware.get_devices(filter_reserved=False, device_profile="pi_sensehat")

# Print device names
for device in available_devices:
    print(device.device_name)

This code first chooses the CHI@Edge site, then retrieves a list of available devices that support the pi_sensehat device profile, and finally prints the device_name of each device.

Note: You need to have the python-chi library installed and configured to use this code. Also, make sure you have the necessary credentials to access the CHI@Edge site.
