To launch a container with the Pi camera enabled on CHI@Edge, you can use the following steps:

Choose a site and project using context.choose_site() and context.choose_project().
Create a lease for a device with a Pi camera using lease.Lease() and lease.add_device_reservation().
Launch a container with the pi_libcamera device profile using container.Container() and specify the image, reservation ID, and command.
Use the rpicam applications or the picamera2 library to capture images or videos.
Here's an example code snippet:

from chi import context, lease, container

# Choose site and project
context.choose_site(default="CHI@Edge")
context.choose_project()

# Create a lease for a device with a Pi camera
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

# Launch a container with the pi_libcamera device profile
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()

Note that you'll need to replace picamera_devs[0] with the actual device name or ID of the device with the Pi camera. Additionally, you may need to modify the image_ref and command parameters to suit your specific use case.
