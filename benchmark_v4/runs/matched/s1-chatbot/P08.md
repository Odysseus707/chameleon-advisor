To run 'ls /app' inside the running container in CHI@Edge and capture the output, you can use the execute method of the container object in Python-chi.

Here's an example of how you can do it:

from chi import container

# assuming my_container is your container object
cmd = "ls /app"
result, code = my_container.execute(cmd)
print(result)

This will execute the ls /app command inside the container and print the output. The execute method returns a tuple containing the output of the command and the exit code.

Make sure to replace my_container with the actual name of your container object.

Also, note that the execute method is a blocking call, meaning it will wait for the command to finish executing before returning the output. If you need to run commands in the background, you may need to use a different approach.
