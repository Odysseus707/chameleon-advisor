To launch a container with the Sense HAT enabled, you can use the following code:

from chi import container

# Set a name for the container. Because CHI@Edge uses Kubernetes, ensure that underscores aren't in the name
container_name = "edge-rpi-sensehat".replace("_", "-")

environment_vars = {}

my_container = container.Container(
    name=container_name,
    image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
    device_profiles=["pi_sensehat"],
    environment=environment_vars,
    reservation_id=container_lease.device_reservations[0]["id"],
    command=["-c", "sleep infinity"],
)
my_container.submit()

This code creates a container with the Sense HAT enabled and launches it. The device_profiles parameter is set to ["pi_sensehat"] to enable the Sense HAT, and the image_ref parameter is set to the latest Sense HAT image. The reservation_id parameter is set to the ID of the device reservation, which is obtained from the container_lease object. The command parameter is set to ["-c", "sleep infinity"] to keep the container running indefinitely.
