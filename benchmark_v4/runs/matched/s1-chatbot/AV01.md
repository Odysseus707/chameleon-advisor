To print the device_name of every raspberrypi4-64 device on CHI@Edge that is free to reserve right now, you can use the following Python code:

from chi import hardware

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

for device in available_devices:
    print(device.device_name)

This code will retrieve a list of available devices of type "raspberrypi4-64" on CHI@Edge, and then print the device_name of each device. The filter_reserved=True parameter ensures that only devices that are not currently reserved are included in the list.
