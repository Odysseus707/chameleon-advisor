To launch an Ollama container on an active CHI@Edge lease named 'my-llm-lease' with GPU support, exposing only the Ollama API port, and giving it a public IP, you can follow these steps in a Python environment with the chi library:

Import necessary modules and set up the CHI@Edge context:

from chi import container, context, lease
import os
context.version = "1.0" 
context.choose_project()
context.choose_site(default="CHI@Edge")

Get the lease by its name:

l = lease.get_lease('my-llm-lease')
l.show()

Create a container with the Ollama image, specifying GPU runtime and exposing the Ollama API port (11434 by default, but ensure this is the correct port for your setup):

c = container.Container(
    name="my-ollama-container", 
    reservation_id=l.device_reservations[0]["id"],
    image_ref="docker.io/ollama/ollama:latest", 
    runtime="nvidia",
    exposed_ports=[11434],
)
c.submit(idempotent=True)

Associate a floating IP with the container to give it a public IP:

c.associate_floating_ip()

Please ensure you have the necessary permissions, that the lease 'my-llm-lease' exists and is active, and that the Ollama image is correctly referenced. Also, verify the port number for the Ollama API as it might differ based on your specific setup or version of Ollama.
