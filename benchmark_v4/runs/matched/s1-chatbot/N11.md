To reserve the Pi 5 named nyu-rpi5-03 for exactly 2 hours using python-chi and launch the Jupyter minimal-notebook container on it with port 8888 and a public IP, follow these steps:

Import necessary modules and set up the context:

from chi import lease, container, context
context.choose_site(default="CHI@Edge")
context.choose_project()

Create a lease for the specific device: First, define the device details and the lease duration:

device_name = "nyu-rpi5-03"
device_uuid = "a755b236-580e-4040-874c-80501f00f954"  # UUID for nyu-rpi5-03
lease_name = "edge-lease-example"
lease_duration = 2  # in hours

Then, create the lease:

my_lease = lease.Lease(lease_name, duration=timedelta(hours=lease_duration))
my_lease.add_device_reservation(device_name=device_name, uuid=device_uuid)
my_lease.submit(idempotent=True)

Launch the Jupyter minimal-notebook container: Define the container details:

container_name = "jupyter-container-example"
image_ref = "quay.io/jupyter/minimal-notebook:latest"
exposed_ports = [8888]

Then, launch the container on the leased device:

my_container = container.Container(
    name=container_name,
    image_ref=image_ref,
    exposed_ports=exposed_ports,
    reservation_id=my_lease.device_reservations[0]["id"],
)
my_container.submit(idempotent=True)

Associate a floating IP with the container:

my_container.associate_floating_ip()

This process reserves the specified Pi 5 device for 2 hours, launches a Jupyter minimal-notebook container on it, and assigns a public IP to the container for access. Ensure you have the necessary permissions and that the device is available before attempting to reserve it.
