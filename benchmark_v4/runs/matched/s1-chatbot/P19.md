To verify that the camera is detected inside the container, you can run a simple command to see if libcamera finds your camera.

First, make sure the container has started with the "pi_libcamera" device profile. Then, you can use the rpicam-hello command with the --nopreview and --list-cameras options to list the available cameras.

Here's an example of how to do this in Python using the container.execute() method:

cmd = "rpicam-hello --nopreview --list-cameras"
result, code = my_container.execute(cmd)
print(result)

This command will output information about the detected camera, including its capabilities. If the camera is not detected, you may need to check the device profile, the container configuration, or the camera hardware itself.
