1. **Check Available Devices**: Use the Chameleon Cloud GUI or `python-chi` to check which devices are currently available and have hardware accelerators.

2. **Top Device Types**:
   - **Raspberry Pi 4 (raspberrypi4-64)**: This device is versatile and has a built-in GPU that can handle int8 operations efficiently.
   - **Jetson Nano**: Known for its efficient processing capabilities, especially with neural networks, making it suitable for running int8 models.
   - **Intel NUC**: Offers good performance and flexibility, potentially supporting various hardware accelerators depending on the specific model.

**Justification**:
- Raspberry Pi 4: It is widely available and has a built-in GPU that can handle int8 operations efficiently.

To reserve one of these devices:
1. **Login to CHI@Edge**: Use your Chameleon credentials to log in at https://chi.edge.chameleoncloud.org.
2. **Create a Lease**: Reserve the device type you need for 3 hours using the GUI or `python-chi`.
3. **Launch Container**: Start a container with the necessary dependencies and hardware access.
