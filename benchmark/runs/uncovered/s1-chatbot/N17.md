To extend a lease by 2 hours using python-chi, you can use the following code:

from chi import lease

# Get the lease ID
lease_id = "your_lease_id"

# Extend the lease by 2 hours
lease.extend_lease(lease_id, hours=2)

Replace "your_lease_id" with the actual ID of the lease you want to extend. This code will extend the lease by 2 hours from its current end time.

Please note that you need to have the necessary permissions and credentials to extend a lease. Also, make sure to check the Chameleon documentation for any specific requirements or restrictions on extending leases.
