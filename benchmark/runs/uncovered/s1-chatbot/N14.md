To record audio from a USB microphone plugged into a CHI@Edge Raspberry Pi, you would use the "pi_usb" device profile. This profile exposes the USB devices connected to the Raspberry Pi, allowing you to access the USB microphone from within your container.

To set up the container, you would follow these steps:

Create a lease for the Raspberry Pi device with the USB microphone attached.
Launch a container on the leased device with the "pi_usb" device profile.
Install the necessary dependencies for audio recording, such as alsa-utils or pulseaudio, within the container.
Use a command-line tool like arecord or ffmpeg to record audio from the USB microphone.
Here's an example of how you might launch the container using the chi library in Python:

from chi import container

# Set up the container
container_name = "audio-recording-container"
image_ref = "ghcr.io/chameleoncloud/edge-ubuntu:latest"
device_profiles = ["pi_usb"]
reservation_id = "your_reservation_id"

# Launch the container
my_container = container.Container(
    name=container_name,
    image_ref=image_ref,
    device_profiles=device_profiles,
    reservation_id=reservation_id,
    command=["sleep", "infinity"],
)
my_container.submit()

Note that you'll need to replace "your_reservation_id" with the actual ID of your lease. You can obtain this ID by creating a lease using the chi library or by looking up the lease in the CHI@Edge dashboard.
