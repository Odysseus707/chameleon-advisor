To extend your CHI@Edge lease by 2 more hours using `python-chi`, you can follow these steps:

1. **Import necessary modules**:
   ```python
   import chi
   ```

2. **Select the Chameleon site**:
   ```python
   chi.use_site("CHI@Edge")
   ```

3. **Identify your lease ID**: You need to know the UUID of the lease you want to extend.

4. **Extend the lease duration**:
   Use `chi.lease.extend_lease` with the lease ID and the new duration.
   
   ```python
   # Replace 'your-lease-id' with the actual lease ID
   chi.lease.extend_lease('your-lease-id', timedelta(hours=2))
   ```

Here is a complete example:

```python
import chi
from datetime import timedelta

# Select CHI@Edge site
chi.use_site("CHI@Edge")

# Replace 'your-lease-id' with the actual lease ID you want to extend
lease_id = "your-lease-id"

# Extend the lease by 2 hours
extended_lease = chi.lease.extend_lease(lease_id, timedelta(hours=2))

print(f"Lease {lease_id} extended successfully.")
```

This code will extend your existing CHI@Edge lease by an additional 2 hours from its current expiration time. Make sure to replace `'your-lease-id'` with the actual UUID of your lease.
