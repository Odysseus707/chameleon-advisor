Based on your requirements, here are the available devices and my top 3 recommendations for running an int8 model on any hardware accelerator using CHI@Edge:

### Available Devices:
To check what is currently available, you can use the Chameleon Cloud GUI or the `chi` command-line interface to list the available devices. Specifically, you would look at the device types that support hardware accelerators and have the necessary runtime environment for your model.

### Top 3 Device Types:
1. **raspberrypi4-64**
   - **Justification:** This device type supports ARM architecture and can run containers with the required image (`ghcr.io/chameleoncloud/edge_ssh_image:latest`). It is versatile and commonly used for edge computing tasks, including those involving hardware accelerators.

2. **iot-rpi-cm4-02**
   - **Justification:** This device type supports ARM architecture and has a Compute Module 4 (CM4) which can handle more complex workloads, potentially with better performance than the Raspberry Pi 4 for certain tasks.

3. **iot-rpi4-picam3**
   - **Justification:** While primarily used for camera modules, this device also supports ARM architecture and can be leveraged for running int8 models if it has the necessary hardware accelerators available.

### Steps to Reserve a Device:
1. **Login to CHI@Edge:**
   ```python
   import chi

   chi.context.use_site("CHI@Edge")
   chi.context.choose_project()
   ```

2. **Create a Lease for 3 Hours:**
   ```python
   from datetime import timedelta
   from chi import lease

   my_lease = lease.Lease(name="int8-model-lease", duration=timedelta(hours=3))
   my_lease.add_device_reservation(amount=1, machine_type="raspberrypi4-64")
   my_lease.submit()
   ```

3. **Launch a Container with the Required Image:**
   ```python
   from chi import container

   container_name = "int8-model-container"
   image_ref = "ghcr.io/chameleoncloud/edge_ssh_image:latest"

   my_container = container.Container(
       name=container_name,
       image_ref=image_ref,
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"]
   )
   my_container.submit()
   ```

4. **SSH into the Container (Optional):**
   ```python
   ip_address = chi.container.associate_floating_ip(my_container.uuid)
   print(f"Use SSH to connect: ssh root@{ip_address}")
   ```

5. **Run Your Int8 Model:**
   You can now run your int8 model inside the container using the appropriate commands.

6. **Cleanup:**
   ```python
   my_container.delete()
   my_lease.delete()
   ```

This setup ensures you have a device with the necessary architecture and runtime environment to execute your int8 model for 3 hours on CHI@Edge.
