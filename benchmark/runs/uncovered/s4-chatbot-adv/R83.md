Based on your requirements, here are the available devices and my top 3 recommendations for running an int8 model on any hardware accelerator using CHI@Edge:

### Available Devices:
To check what is currently available, you can use the `hardware.get_devices` function in Python-CHI to list all available devices. This will give you a real-time snapshot of the resources that are not reserved.

```python
from chi import hardware

available_devices = hardware.get_devices(filter_reserved=True)
print(available_devices)
```

### Top 3 Device Types:
1. **raspberrypi4-64**
   - **Reasoning:** This device type is versatile and supports a wide range of workloads, including those that require int8 precision on its integrated GPU.

2. **iot-rpi-cm4-02** (Waveshare Sense Hat)
   - **Reasoning:** Although primarily for sensor experiments, this device can still be used for computational tasks due to its ARM architecture and potential hardware accelerators.

3. **iot-rpi4-picam3** (Raspberry Pi Camera Module 3)
   - **Reasoning:** This device is equipped with a camera module but also has the necessary compute capabilities to run int8 models, making it suitable if you need both computational power and camera functionality.

### Recommendation:
Given your workload requirements, I recommend starting with the `raspberrypi4-64` as it provides a balanced setup for running int8 models on its hardware accelerator. You can create a lease for this device type for 3 hours using Python-CHI:

```python
from chi import lease

# Create a lease for raspberrypi4-64
lease_name = "int8-model-lease"
machine_type = "raspberrypi4-64"

container_lease = lease.Lease(name=lease_name, duration_hours=3)
container_lease.add_device_reservation(amount=1, machine_type=machine_type)
container_lease.submit()
```

This will ensure you have exclusive access to the device for your experiment.
