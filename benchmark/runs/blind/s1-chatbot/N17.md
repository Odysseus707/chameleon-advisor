To extend your CHI@Edge lease by 2 more hours using python-chi, you can follow these steps:

Import the necessary python-chi library and set up the authentication context by specifying the site as 'CHI@Edge'.
Retrieve the current lease details, including its end date.
Calculate the new end date by adding 2 hours to the current end date.
Use the chi.lease.update_lease method to extend the lease.
Here's a sample code snippet to achieve this:

import chi

# Set up authentication context for CHI@Edge
chi.use_site('CHI@Edge')

# Retrieve the current lease details
lease_id = "your_lease_id"  # Replace with your actual lease ID
lease = chi.lease.get_lease(lease_id)

# Calculate the new end date
new_end_date = lease.end_date + timedelta(hours=2)

# Extend the lease
chi.lease.update_lease(lease_id, end_date=new_end_date)

Replace "your_lease_id" with the actual ID of your lease. This code extends the lease by 2 hours from its current end date. Make sure to handle any potential errors and exceptions that may occur during the lease extension process.
