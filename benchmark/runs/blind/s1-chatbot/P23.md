To list the I2C addresses from inside the container for debugging the sensor bus, you would typically use the i2cdetect command. This command is part of the i2c-tools package, which you may need to install first if it's not already available in your container.

Here are the steps:

Install i2c-tools: If the package is not installed, you can do so by running apt-get update && apt-get install i2c-tools (for Debian-based systems) or the equivalent command for your Linux distribution.

Run i2cdetect: After installing i2c-tools, you can use the i2cdetect command to scan the I2C bus for connected devices. The basic syntax is i2cdetect -y <bus_number>, where <bus_number> is the number of the I2C bus you want to scan. For example, to scan bus 1, you would use i2cdetect -y 1.

This command will output a table showing the addresses of devices found on the specified I2C bus, which can be very helpful for debugging purposes, such as verifying that a sensor is properly connected and recognized by the system.

Remember, the specific bus number you need to scan depends on your hardware setup and how the sensor bus is configured. If you're unsure which bus to scan, you may need to consult the documentation for your specific hardware or try scanning each available bus to find the one with the devices you expect.
