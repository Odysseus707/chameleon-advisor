To run 'ls /app' inside the running container in CHI@Edge and capture the output, you can use SSH to access the container. Once you have SSH access to the container, you can run the command 'ls /app' and capture the output. The exact steps to establish SSH access are not provided in the given context, but it is mentioned that SSH access is available as an alternative to the web console in the CHI@Edge dashboard.

After establishing SSH access, you can run the command as follows:

ssh <container-ssh-access> "ls /app"

This will execute the 'ls /app' command inside the container and print the output to your local terminal. Replace <container-ssh-access> with the actual SSH access details provided by CHI@Edge for your container.
