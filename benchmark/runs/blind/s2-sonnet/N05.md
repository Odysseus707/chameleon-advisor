pythonimport chi
from chi import container

# Set your project and site context
chi.use_site("CHI@Edge")
# chi.set("project_name", "your-project-name")  # uncomment/set if needed

lease_name = "my-llm-lease"

# Get the existing lease by name
lease = container.get_lease(lease_name)

# Launch the container tied to that lease's reservation
c = container.create_container(
    name="ollama-server",
    image="ollama/ollama",
    reservation_id=lease.node_reservation_id,  # ties container to your GPU reservation
    exposed_ports=[11434],          # Ollama API port only
    device_profiles=["gpu"],        # request GPU passthrough — device must support this
)

# Wait for it to become active
container.wait_for_active(c.uuid)

# Associate a public (floating) IP
public_ip = container.associate_floating_ip(c.uuid)

print(f"Ollama container running. API reachable at http://{public_ip}:11434")
A few things worth checking before you run this:

GPU support on CHI@Edge — GPU passthrough for containers is device-specific; not every edge node exposes device_profiles=["gpu"]. If your specific device uses a different mechanism (e.g. a custom device profile name), check container.list_container_devices() or the CHI@Edge device page for the node your lease reserved.
Port exposure — exposed_ports=[11434] should be the only port opened; double check no other ports get exposed by default in your image.
Ollama GPU usage — once it's up, you'll want to docker exec in (or use the container logs) to confirm Ollama actually detects the GPU (ollama run a model and check nvidia-smi inside, if accessible).
Cleanup — remember container.destroy_container(c.uuid) and releasing the floating IP when you're done, since CHI@Edge leases/resources are billed against your allocation.
