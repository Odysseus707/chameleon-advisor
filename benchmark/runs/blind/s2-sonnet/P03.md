Here's how to do it yourself and get the reservation_id to pass into your container's --reservation flag:
Via CLI (python-chi / blazar)
bash# Authenticate first (source your CHI@Edge openrc, or use python-chi)
openstack reservation lease create \
  --reservation resource_type=device,resource_properties='["==","$machine_name","raspberrypi4-64"]',min=1,max=1 \
  --start-date "now" --end-date "2026-07-16 00:00" \
  my-edge-lease
That returns a lease object containing a reservations list — grab the id field from the device reservation entry; that's your reservation_id.
Via python-chi (common in CHI@Edge notebooks)
pythonimport chi
from chi import lease

chi.use_site("CHI@Edge")

reservations = []
lease.add_device_reservation(reservations, count=1, machine_name="raspberrypi4-64")

my_lease = lease.create_lease("my-edge-lease", reservations)
reservation_id = my_lease["reservations"][0]["id"]
print(reservation_id)
Then when launching the container:
bashopenstack appcontainer create \
  --reservation-id <reservation_id> \
  --image <your-image> \
  my-container
