Here's the minimal python-chi setup targeting CHI@Edge:
pythonimport chi

# Point python-chi at the CHI@Edge testbed
chi.use_site("CHI@Edge")

# Select your project (required — replace with your actual project name/charge code)
chi.set("project_name", "YOUR_PROJECT_NAME")
A few notes on this:

chi.use_site("CHI@Edge") configures the client to talk to the Edge testbed's endpoints (as opposed to CHI@TACC, CHI@UC, KVM@TACC, etc.).
chi.set("project_name", ...) tells Chameleon which allocation/project to bill resources against — you can find your exact project name/charge code on the Chameleon portal under your user profile or project listing.
Authentication (via python-chi's token/keystone flow) typically happens automatically if you're running in a Chameleon Jupyter environment (it picks up credentials from the environment), but outside of that you may also need:

pythonchi.set("region_name", "CHI@Edge")  # occasionally needed depending on version
