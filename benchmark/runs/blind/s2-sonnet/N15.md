Here's what I can do to help you get this done yourself:
Via the Horizon web UI:

Log into https://chi.edge.chameleoncloud.org
Go to Reservations → Leases → Create Lease
Give it a name, set start time to now and end time 3 hours later
Under Resource Properties, add a filter like machine_name == "raspberrypi5" (or select the Raspberry Pi 5 device type from the dropdown if offered)
Set the resource type to device (not "host" — CHI@Edge uses container/device leases, not full node leases like CHI@TACC/UC)
Submit, then check the lease status until it's "Active"

Via the CLI (python-chi / python-blazar client), roughly:
pythonimport chi
from chi.lease import create_lease
from chi.hardware import get_device_reservation

chi.use_site("CHI@Edge")

reservations = []
get_device_reservation(reservations, machine_name="raspberrypi5")

lease = create_lease(
    lease_name="my-rpi5-lease",
    reservations=reservations,
    start_date=None,  # now
    end_date=None,    # will need to compute now + 3 hours
)
You'd want to check current device availability first (chi.hardware.get_devices() filtered by type) since "free" ones can fill up fast, and the exact machine_name string can vary — worth double-checking against the current device list before submitting.
