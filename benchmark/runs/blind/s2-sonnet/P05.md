Here's how to launch a basic Ubuntu container on a reserved Raspberry Pi via CHI@Edge, using python-chi (typically from a Chameleon Jupyter notebook):
1. Set up context
pythonimport chi
from chi import container, lease

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")
2. Reserve a Pi device (create a lease)
pythonfrom datetime import timedelta

my_lease = lease.Lease(
    name="my-pi-lease",
    duration=timedelta(hours=3)
)
my_lease.add_device_reservation(
    amount=1,
    machine_type="raspberrypi4-64"  # or "raspberrypi5" depending on availability
)
my_lease.submit(idempotent=True)
This reserves one Pi of the specified type. You can check device types available in the CHI@Edge dashboard under Hardware Browser if you're unsure of the exact machine_type string.
3. Launch the container
Once the lease is active, use the reservation ID to launch a plain Ubuntu container:
pythonreservation_id = my_lease.device_reservations[0]["id"]

my_container = container.create_container(
    name="my-ubuntu-container",
    image="ubuntu:22.04",
    reservation_id=reservation_id,
    exposed_ports=["22"],  # optional, needed if you want SSH access
)
4. Check status / access it
pythonmy_container.show()  # prints status, IP, etc.
If you exposed port 22 and set up an SSH server/keys in the container, you can SSH in — Chameleon added a seamless SSH-into-container feature. Otherwise, you can use the web console in the CHI@Edge dashboard, or container.execute() from python-chi to run commands directly.
A few practical notes

Base Ubuntu images have no SSH server or utilities by default — they're meant to run and exit, not be logged into interactively. If you want a shell, either use the web console/execute(), or build a custom image with an SSH server baked in.
Pi devices are ARM64, so make sure whatever image or Docker image you use has an arm64/aarch64 build — ubuntu:22.04 on Docker Hub is multi-arch, so this works fine.
Reservations are billed against your allocation, so remember to lease.delete() or container.destroy_container() when done.
