I don't have direct access to Chameleon Cloud's CHI@Edge testbed (it's outside my network access and requires your project credentials), so I can't provision this for you directly — but here's a working python-chi script to do it yourself. Chameleon's APIs do change over time, so double-check against the current docs at chameleoncloud.org/docs if anything errors.
pythonimport chi
from chi import lease, container

# Configure for CHI@Edge
chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")  # replace with your project

# --- 1. Reserve 2 Raspberry Pi 4 devices in one lease ---
reservations = []
lease.add_device_reservation(
    reservations,
    count=2,
    device_type="raspberrypi4-64",   # 64-bit RPi4 device type on CHI@Edge
)

start_date, end_date = lease.lease_duration(days=1)  # adjust duration as needed

my_lease = lease.create_lease(
    "pi4-pair-lease",
    reservations=reservations,
    start_date=start_date,
    end_date=end_date,
)

lease_id = my_lease["id"]
lease.wait_for_active(lease_id)
print(f"Lease {lease_id} is active")

reservation_id = lease.get_device_reservation(lease_id)

# --- 2. Start an SSH-enabled container on each Pi ---
# Use an image with sshd baked in (Chameleon publishes edge-ssh images),
# or your own image that runs an SSH server on boot.
containers = []
for i in range(2):
    c = container.create_container(
        f"pi-ssh-container-{i+1}",
        image="ghcr.io/chameleoncloud/edge-ssh:latest",
        reservation_id=reservation_id,
        exposed_ports=[22],
    )
    containers.append(c)
    print(f"Started container {c['name']} on device")

# --- 3. Get connection info ---
for c in containers:
    ip = container.get_container(c["name"])
    print(ip)
A few notes:

Device count vs. lease: add_device_reservation(count=2, ...) puts both Pi reservations under a single lease, which is what you asked for — CHI@Edge will try to schedule two available raspberrypi4-64 devices for that same reservation.
SSH image: Chameleon publishes prebuilt edge images with SSH enabled (edge-ssh in their container registry as of my last info) — if that image name has moved, search their edge image catalog or build your own Dockerfile with sshd and your public key baked in via authorized_keys.
Getting in: once containers are running, chi.container.get_container() (or the Horizon/GUI dashboard) will show the assigned floating IP or port mapping for port 22.
Credentials: you'll need chi.set("project_name", ...) and either a clouds.yaml or the CHI@Edge auth environment variables set up beforehand (python-chi reads these the same way as other Chameleon sites).
