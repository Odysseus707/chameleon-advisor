To launch a Jupyter minimal-notebook container on your active lease 'serve-edge-vr' running on a Raspberry Pi 5 and give it a public IP, follow these steps:

1. **SSH into Your Chameleon Cloud Instance**:
   - First, SSH into your Raspberry Pi 5 instance using the credentials provided by Chameleon.

2. **Pull the Jupyter Minimal-Notebook Docker Image**:
   - Once you are logged in to your instance, pull the `quay.io/jupyter/minimal-notebook:latest` image from Docker.
     ```bash
     docker pull quay.io/jupyter/minimal-notebook:latest
     ```

3. **Run the Jupyter Container with a Public IP**:
   - Run the container and expose it on a public IP address. You will need to allocate a floating IP if you haven't already done so.
     ```bash
     docker run -d --name jupyter-minimal-notebook \
       -p <public_ip>:8888:8888/tcp \
       quay.io/jupyter/minimal-notebook:latest start-notebook.sh --NotebookApp.token=''
     ```
   - Replace `<public_ip>` with the actual public IP address you have allocated for your instance.

4. **Find the Notebook's Token URL from Container Logs**:
   - After starting the container, find the token and URL by checking the logs of the running container.
     ```bash
     docker logs jupyter-minimal-notebook
     ```
   - Look for a line similar to `http://<public_ip>:8888/?token=<your_token>` in the logs. This is your Jupyter Notebook's access URL.

5. **Access Your Jupyter Notebook**:
   - Open a web browser and navigate to the URL you found from the container logs.
     ```
     http://<public_ip>:8888
     ```

By following these steps, you will have successfully launched a Jupyter minimal-notebook container on your Raspberry Pi 5 instance with a public IP address and obtained the token URL for accessing it.
