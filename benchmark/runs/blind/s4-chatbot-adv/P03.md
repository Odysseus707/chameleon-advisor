To reserve a Raspberry Pi on CHI@Edge and get the `reservation_id` that you can pass to a container, follow these steps using the `python-chi` library:

1. Import the necessary modules:
```python
import chi
```

2. Set up your authentication context (most information is automatically sourced from environment variables):
```python
chi.use_site('CHI@Edge')
```

3. Define the reservation parameters for a Raspberry Pi (`raspberrypi4-64`), and request a lease:
```python
reservations = []
chi.lease.add_node_reservation(reservations, count=1, node_type="raspberrypi4-64")
start_date, end_date = chi.lease.lease_duration(hours=3)  # Lease duration of 3 hours
lease_name = "my-pi-reservation"
lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date, end_date=end_date)
```

4. Wait for the lease to become active:
```python
chi.lease.wait_for_active(lease.id)
```

5. Retrieve the `reservation_id` from the lease:
```python
reservation_id = get_node_reservation(lease.id)  # Note: The function name is illustrative; use the appropriate method or attribute provided by python-chi to extract the reservation ID.
```

The `reservation_id` can now be used when launching a container on CHI@Edge, ensuring that it will run on the reserved Raspberry Pi.
