To convert your CHI@UC bare-metal script to run on CHI@Edge, you need to adjust several aspects of your script since CHI@Edge is designed for edge computing and uses different resources compared to traditional bare metal nodes.

Here's a step-by-step guide:

1. **Change the Site**: Update the site from `CHI@UC` to `CHI@Edge`.

2. **Resource Type**: Instead of reserving a specific node type like `'compute_skylake'`, you will need to specify an appropriate edge device, such as `raspberrypi4-64`. This is based on the recommendation provided in the context.

3. **Image and Architecture**: Use the recommended image for CHI@Edge (`ghcr.io/chameleoncloud/edge_ssh_image:latest`) which supports ARM architecture.

Here's how you can modify your script:

```python
import chi

# Change site to CHI@Edge
chi.use_site('CHI@Edge')

# Request a lease for edge devices (Raspberry Pi 4)
reservations = []
chi.lease.add_node_reservation(reservations, count=1,
                               node_type='raspberrypi4-64')  # Use the recommended machine type

start_date, end_date = chi.lease.lease_duration(hours=3)  # Duration as per recommendation
lease_name = "my-edge-lease"
lease = chi.lease.create_lease(lease_name, reservations,
                               start_date=start_date, end_date=end_date)

# Wait for lease to become active
chi.lease.wait_for_active(lease.id)

# Launch instances against the lease using the recommended image
reservation_id = get_node_reservation(lease.id)
server_name = "my-edge-server"
image_name = "ghcr.io/chameleoncloud/edge_ssh_image:latest"  # Use the recommended image

server = create_server(server_name, reservation_id=reservation_id,
                       image_name=image_name, count=1)

# Note: The `create_server` function and `get_node_reservation` are assumed to be defined elsewhere in your script.
```

### Explanation:
- **Site Change**: Changed from `CHI@UC` to `CHI@Edge`.
- **Node Type**: Specified `'raspberrypi4-64'` as the node type, which is suitable for edge computing tasks.
- **Image**: Used the recommended image (`ghcr.io/chameleoncloud/edge_ssh_image:latest`) that supports ARM architecture and SSH access.

This script should now work on CHI@Edge with the specified Raspberry Pi 4 device.
