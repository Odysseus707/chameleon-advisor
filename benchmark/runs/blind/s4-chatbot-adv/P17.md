To capture a 1080p still image from the Pi Camera and download it, follow these steps:

1. **Provision an Edge Node**: Use CHI@Edge to provision a Raspberry Pi 4 (64-bit) with the specified image (`ghcr.io/chameleoncloud/edge-picamera-image:latest`). Ensure that the device profile includes `pi_libcamera`.

2. **SSH into the Device**: Once the node is up and running, SSH into it using the provided credentials.

3. **Capture an Image**:
   - Use the `libcamera-still` command to capture a 1080p image.
   - Run the following command in your SSH session:
     ```bash
     libcamera-still -o image.jpg --width 1920 --height 1080
     ```
   This will save an image named `image.jpg` with a resolution of 1920x1080 pixels.

4. **Download the Image**:
   - You can use SCP (Secure Copy Protocol) to download the captured image from your Raspberry Pi to your local machine.
   - Run the following command on your local machine, replacing `<username>`, `<ip_address>`, and `<local_path>` with appropriate values:
     ```bash
     scp <username>@<ip_address>:image.jpg <local_path>
     ```

By following these steps, you will be able to capture a 1080p still image from the Pi Camera and download it to your local machine.
