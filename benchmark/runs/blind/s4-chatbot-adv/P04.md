To reserve 3 Raspberry Pis of the same type on CHI@Edge in one lease, you will need to use the container-lease model specific to CHI@Edge rather than Blazar reservations. Here’s a step-by-step guide based on the provided context:

1. **Identify the Machine Type**: From the EDGE RESOURCE ADVISORY, the recommended machine type is `raspberrypi5`.

2. **Determine Lease Details**:
   - You want to lease 3 Raspberry Pis.
   - The duration of each lease should be specified (e.g., 3 hours as suggested by the advisory).

3. **Use Python CHI Module**: Since Blazar isn't used for CHI@Edge, you will use the `chi.lease` module from the `python-chi` library to create and manage leases programmatically.

4. **Create a Lease**:
   - Import necessary modules.
   - Define lease parameters (machine type, count, duration).
   - Submit the lease request.

Here is an example of how you might do this in Python:

```python
from chi import lease

# Initialize CHI client
chi_client = lease.Client()

# Define lease parameters
lease_params = {
    'machine_type': 'raspberrypi5',
    'count': 3,
    'duration_hours': 3,  # Duration of the lease in hours
}

# Create a lease request
new_lease = chi_client.create_lease(**lease_params)

print(f"Lease created with ID: {new_lease.id}")
```

This script initializes a CHI client and creates a lease for 3 Raspberry Pis (`raspberrypi5`) for a duration of 3 hours. Adjust the `duration_hours` as needed based on your experiment requirements.

Ensure you have the necessary permissions and that the resources are available at the time of reservation to avoid any issues with resource hoarding or availability conflicts.
