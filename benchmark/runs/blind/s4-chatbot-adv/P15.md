To find which Raspberry Pi devices have a camera attached and reserve one, follow these steps:

1. **Identify Pis with Cameras**: According to the context provided, you should look for devices that match the `device_profiles` of `['pi_libcamera']`. This profile indicates that the device has a camera attached.

2. **Reserve a Device**:
    - Use the Chameleon Cloud interface or API to search and reserve an available Raspberry Pi 4 (64-bit) (`machine_type: raspberrypi4-64`) with the `pi_libcamera` device profile.
    - Ensure you specify the correct image, which is `ghcr.io/chameleoncloud/edge-picamera-image:latest`.

3. **Reservation Parameters**:
    - Reserve a count of 1 device (`count=1`).
    - Set the lease duration to 3 hours (`duration_hours=3`).

Here's an example of how you might reserve such a device using the Chameleon Cloud API (assuming you have access and necessary permissions):

```python
import chi

# Initialize CHI client
client = chi.Client()

# Define reservation parameters
reservation_params = {
    'machine_type': 'raspberrypi4-64',
    'image': 'ghcr.io/chameleoncloud/edge-picamera-image:latest',
    'device_profiles': ['pi_libcamera'],
    'lease': {'count': 1, 'duration_hours': 3}
}

# Reserve the device
reservation = client.reserve(**reservation_params)

print(reservation)
```

This script initializes a CHI client and reserves one Raspberry Pi 4 with a camera attached for 3 hours using the specified image. Adjust the parameters as needed based on your specific requirements or available resources.
