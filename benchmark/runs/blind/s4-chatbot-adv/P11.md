To launch an SSH-enabled container on a reserved Raspberry Pi 4 and connect to it, follow these steps:

1. **Reserve a Node**: Reserve a `raspberrypi4-64` node through Chameleon Cloud's interface or API.

2. **Launch the Container**:
   - Use the image `ghcr.io/chameleoncloud/edge_ssh_image:latest`.
   - Ensure that port 22 (SSH) is exposed when launching the container on your reserved Raspberry Pi 4.

3. **Obtain Floating IP**: Once the instance is running, associate a floating IP with it so you can connect from outside Chameleon Cloud's network.

4. **Connect via SSH**:
   - Open a terminal.
   - Use the `ssh` command to connect to your instance using the private key associated during launch and the floating IP address of your Raspberry Pi 4.
   
     ```bash
     ssh -i /path/to/your/private/key cc@<your-floating-ip>
     ```
     
     Replace `/path/to/your/private/key` with the path to your private SSH key file, and `<your-floating-ip>` with the actual floating IP address of your instance.

5. **Verify Connection**: Once connected successfully, you should see a terminal prompt indicating that you are now running commands directly on the Raspberry Pi 4 node.

By following these steps, you will have launched an SSH-enabled container on a reserved Raspberry Pi 4 and established an SSH connection to it.
