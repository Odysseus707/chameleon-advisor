To reserve a camera-equipped Raspberry Pi, start the camera container, and retrofit SSH access into it for your teammate to log in and run captures themselves, follow these steps:

1. **Reserve the Device**:
   - Use the Chameleon Cloud interface or API to request a lease for one Raspberry Pi 4 (raspberrypi4-64) with an ARM64 architecture.
   - Ensure you specify that it should have a camera profile (`pi_libcamera`).

2. **Launch Instance with Custom Image**:
   - Use the image `ghcr.io/chameleoncloud/edge-picamera-image:latest`, which is designed for Raspberry Pi 4 and includes support for the camera.

3. **Configure SSH Access**:
   - Go to the Key Pair Tab in the Chameleon Cloud interface.
   - Select or upload your public key that will be used for root login.
   
4. **Set Up Security Groups**:
   - Navigate to the Security Groups tab.
   - Ensure port 22 (SSH) is open for incoming connections.

5. **Launch Instance**:
   - After configuring the above settings, launch the instance using the specified image and key pair.
   - Make sure you associate a floating IP address with your instance so that it can be accessed from outside the Chameleon Cloud network.

6. **Accessing the Instance**:
   - Once the instance is up and running, use SSH to connect to the Raspberry Pi 4 using the root login and your public key.
   - Example command: `ssh root@<floating_ip_address>`

7. **Start Camera Container**:
   - After logging in via SSH, start the camera container by pulling the image if necessary and then starting it with appropriate commands.

8. **Verify Setup for Teammate**:
   - Ensure your teammate has access to the floating IP address and can use their own SSH client to connect using root login and the provided public key.
   
By following these steps, you will have a camera-equipped Raspberry Pi instance ready for your teammate to log in and run captures themselves.
