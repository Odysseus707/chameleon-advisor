To record a 10-second 720p video at 30 fps from the Pi camera and download it to your machine, follow these steps:

### Step 1: Lease an Edge Device on CHI@Edge
First, lease a Raspberry Pi 4 device with the specified configuration. Use the `chi` command-line tool or the Chameleon Cloud web interface to request a device.

```bash
# Example chi command (adjust parameters as needed)
chi edge lease create --machine-type raspberrypi4-64 \
                      --image ghcr.io/chameleoncloud/edge-picamera-image:latest \
                      --device-profiles pi_libcamera \
                      --lease-duration 3h \
                      --count 1
```

### Step 2: SSH into the Leased Device
Once you have leased a device, connect to it via SSH.

```bash
ssh <username>@<device-ip>
```

### Step 3: Record Video Using `libcamera-vid`
Use the `libcamera-vid` command to record a video. The following command records a 10-second video at 720p resolution and 30 fps, saving it as `output.h264`.

```bash
libcamera-vid -t 10000 --width 1280 --height 720 --framerate 30 --inline --codec h264 -o output.h264
```

### Step 4: Download the Video to Your Machine
After recording, you can download the video file from the device to your local machine using `scp`.

```bash
scp <username>@<device-ip>:output.h264 .
```

This will transfer the recorded video (`output.h264`) to your current directory on your local machine.

### Step 5: Release the Device (Optional)
Once you are done, it is a good practice to release the device so that other users can use it. You can do this via the `chi` command-line tool or the Chameleon Cloud web interface.

```bash
# Example chi command
chi edge lease delete <lease-id>
```

Replace `<lease-id>` with your actual lease ID, which you can find in the output of the lease creation command or through the CHI@Edge dashboard.
