To reserve a specific device with a Sense HAT attached on CHI@Edge, follow these steps:

1. **Identify the Device Type and Profile**: Based on the context provided, you need to request a `raspberrypi4-64` machine type that supports the `arm64` architecture and has the `pi_sensehat` device profile.

2. **Prepare Your Reservation Request**:
    - Specify the image: Use the Docker image `ghcr.io/chameleoncloud/edge_sensehat_image:latest`.
    - Ensure you request a device with the `pi_sensehat` profile.
    - Set the lease duration to 3 hours as recommended.

3. **Submit Your Reservation Request**: You can use the Chameleon Cloud API or CLI to submit your reservation request. Below is an example using Python CHI Docs:

```python
from chi import Chi

chi = Chi()

# Define the parameters for the reservation
reservation_params = {
    'machine_type': 'raspberrypi4-64',
    'image': 'ghcr.io/chameleoncloud/edge_sensehat_image:latest',
    'device_profiles': ['pi_sensehat'],
    'lease_duration_hours': 3,
}

# Submit the reservation request
reservation = chi.reserve(**reservation_params)

print(reservation)
```

This script will help you reserve a device with the specified Sense HAT profile for your use case. Ensure that you have the necessary permissions and are authenticated to make reservations on CHI@Edge.

**Note**: The availability of devices is not guaranteed, so it's recommended to verify the availability before submitting the reservation request.
