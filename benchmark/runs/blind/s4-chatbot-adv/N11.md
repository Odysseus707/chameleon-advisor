To reserve and launch a Jupyter minimal-notebook container on the Pi 5 named `nyu-rpi5-03` for exactly 2 hours using `python-chi`, follow these steps:

1. **Install python-chi**: If you haven't already, install the `python-chi` package by running:
   ```bash
   pip install chi
   ```

2. **Authenticate with Chameleon Cloud**: Ensure that your environment is authenticated to use Chameleon resources. You can authenticate using your Chameleon credentials.

3. **Reserve Resources and Launch Instance**:
    - Use `python-chi` to reserve the Pi 5 named `nyu-rpi5-03` for exactly 2 hours.
    - Specify that you want to launch a Jupyter minimal-notebook container with port 8888 exposed and request a public IP.

Here is an example of how you can achieve this in Python:

```python
import chi

# Authenticate (replace 'your_username' and 'your_password' with your actual credentials)
chi.authenticate(username='your_username', password='your_password')

# Reserve the resource for 2 hours
reservation = chi.reservation.create(
    count=1,
    duration_hours=2,
    machine_type="raspberrypi5",
    name="nyu-rpi5-03"
)

# Launch an instance with Jupyter minimal-notebook container and expose port 8888
instance = reservation.launch_instance(
    image="quay.io/jupyter/minimal-notebook:latest",
    exposed_ports=[8888],
    public_ip=True
)
```

This script will:
- Reserve the specified Pi 5 for exactly 2 hours.
- Launch an instance with the Jupyter minimal-notebook container, exposing port 8888 and requesting a public IP.

Make sure to replace `'your_username'` and `'your_password'` with your actual Chameleon Cloud credentials. Also, ensure that `nyu-rpi5-03` is available for reservation at the time of execution.
