To update your old tutorial script using the current object-oriented API (`lease.Lease` and `container.Container`), you can follow these steps:

1. Import the necessary classes.
2. Set up the site and project name.
3. Create a lease with device reservations.
4. Wait for the lease to become active.
5. Launch a container on the reserved devices.

Here is how your script would look using the object-oriented API:

```python
from chi import Lease, Container

# Setup Chameleon Cloud environment
chi.use_site("CHI@Edge")
chi.set("project_name", "CHI-000000")

# Create a lease with device reservations
lease = Lease()
device_reservation = lease.add_device_reservation(machine_name="raspberrypi4-64", count=1)
start_date, end_date = lease.lease_duration(days=0, hours=10)
lease.create("demo-lease", start_date=start_date, end_date=end_date)

# Wait for the lease to become active
lease.wait_for_active()

# Launch a container on the reserved devices
container = Container()
my_container = container.create(
    "demo-app",
    image="python:3.9-slim",
    reservation_id=device_reservation,
    exposed_ports=[22],
    platform_version=2,
)

print(f"Container created with ID: {my_container['id']}")
```

This script uses the object-oriented API to achieve the same behavior as your old imperative style script, but in a more modern and structured way.
