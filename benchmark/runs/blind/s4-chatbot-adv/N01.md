To reserve three `raspberrypi4-64` devices on CHI@Edge for 6 hours and launch an SSH-enabled container, follow these steps:

1. **Log in to CHI@Edge**: Access your edge devices through the CHI@Edge dashboard on the Chameleon portal.

2. **Reserve Devices**:
   - Navigate to the device reservation section.
   - Select `raspberrypi4-64` as the machine type.
   - Specify that you want 3 devices for a lease duration of 6 hours.

3. **Launch SSH-enabled Container**:
   - Once your devices are reserved, proceed to launch a container on these devices using an image that supports SSH access.
   - Use the `ghcr.io/chameleoncloud/edge_ssh_image:latest` Docker image which is designed to be SSH-ready.
   
4. **Configure and Launch**:
   - Ensure that port 22 (SSH) is exposed in your container configuration.
   - Start the containers on each of the reserved devices.

5. **Access via SSH**:
   - After launching, you can log into each device as root using SSH by connecting to the IP address assigned to each device and specifying the root user.

For detailed instructions on configuring an SSH-ready container, refer to the Jupyter tutorial provided by CHI@Edge. This will guide you through setting up a base container with SSH access, allowing you to treat it like a real server for development purposes.
