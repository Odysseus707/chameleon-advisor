To reserve one Raspberry Pi 4 on CHI@Edge for 2 hours using `python-chi`, follow these steps:

1. Import the necessary modules and set up your authentication context:
```python
import chi

# Create an authentication context (most info automatically sourced from env)
chi.use_site('CHI@UC')
```

2. Define the lease parameters, including the node type (`raspberrypi4`), count of nodes to reserve (1 in this case), and duration (2 hours):
```python
lease_name = "my-lease"
node_type = "raspberrypi4"  # Specify Raspberry Pi 4 as the node type
node_count = 1              # Reserve one node

# Define start and end dates for the lease, reserving it for 2 hours from now.
start_date, end_date = chi.lease.lease_duration(hours=2)
```

3. Create a reservation list and add a node reservation to it:
```python
reservations = []
chi.lease.add_node_reservation(reservations, count=node_count,
                               node_type=node_type)
```

4. Request the lease for the specified duration with the defined reservations:
```python
lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date,
                               end_date=end_date)
```

5. Wait until the lease becomes active before proceeding to launch instances against it:
```python
chi.lease.wait_for_active(lease.id)
```

6. After ensuring that the lease is active, you can proceed with launching bare metal instances if needed (not shown here as per your request).

This process will reserve one Raspberry Pi 4 for a duration of two hours on CHI@Edge using `python-chi`.
