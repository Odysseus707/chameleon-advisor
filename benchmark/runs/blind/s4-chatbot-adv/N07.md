To reserve two Raspberry Pi 4s in one CHI@Edge lease and start an SSH-enabled container on each of them, follow these steps:

1. **Create a Lease for Two Raspberry Pi 4 Nodes**:
   - Use `chi` to create a lease that reserves two Raspberry Pi 4 nodes (raspberrypi4-64) for the desired duration.
   
2. **Launch SSH-enabled Containers on Each Node**:
   - After obtaining the lease, launch an instance of the container with the specified image (`ghcr.io/chameleoncloud/edge_ssh_image:latest`) that is pre-configured to enable SSH access.

Here's a step-by-step guide using `chi`:

1. **Set Up Authentication Context and Create Lease**:
   ```python
   import chi

   # Use CHI@UC site (or your preferred Chameleon Cloud site)
   chi.use_site('CHI@UC')

   lease_name = "raspberry-pi-lease"
   node_type = "raspberrypi4-64"  # Raspberry Pi 4
   node_count = 2

   reservations = []
   chi.lease.add_node_reservation(reservations, count=node_count,
                                  node_type=node_type)

   start_date, end_date = chi.lease.lease_duration(hours=1)  # Lease duration of 1 hour
   lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date,
                                  end_date=end_date)
   
   # Wait for the lease to become active
   chi.lease.wait_for_active(lease.id)
   ```

2. **Launch SSH-enabled Containers**:
   - Once the lease is active and you have reserved the nodes, launch instances of the container with the specified image on each node.
   
   ```python
   reservation_id = get_node_reservation(lease.id)  # Function to retrieve reservation ID

   server_name = "my-server"
   image_name = "ghcr.io/chameleoncloud/edge_ssh_image:latest"

   for i in range(node_count):
       create_server(server_name + str(i+1), reservation_id=reservation_id,
                     image_name=image_name, count=1)
   ```

**Note**: The `get_node_reservation` and `create_server` functions are placeholders. You would need to implement these based on the specific APIs provided by Chameleon Cloud for managing leases and launching instances.

By following these steps, you will have reserved two Raspberry Pi 4 nodes in a lease and started an SSH-enabled container on each of them.
