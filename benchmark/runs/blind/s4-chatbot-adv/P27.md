To find which device_profiles a device supports, you can use the `chi.hardware.Device` class from the Chameleon Cloud's Python CHI Docs. Specifically, each `Device` object has an attribute called `supported_device_profiles`, which is a list of strings representing the supported device profiles for that particular device.

Here’s how you could retrieve this information:

1. First, obtain a list of devices using the function `chi.hardware.get_devices()`. You can filter by device type if needed.
2. Iterate through the returned list of `Device` objects and access each object's `supported_device_profiles` attribute to see which profiles are supported.

Example:
```python
from chi.hardware import get_devices

# Get all devices or specify a device_type
devices = get_devices(device_type="your-device-type")

for device in devices:
    print(f"Device Name: {device.device_name}")
    print(f"Supported Device Profiles: {device.supported_device_profiles}")
```

This will list the supported device profiles for each device.
