To reserve a Raspberry Pi 4 for 10 hours and launch a container with Python 3.9-slim and SSH installed, you can follow these steps using the imperative style of the python-chi API:

1. **Import Required Modules**: Import `chi` from `python_chi`.

2. **Reserve Resources**:
   - Use `chi.reservation.request` to reserve one Raspberry Pi 4 for 10 hours.
   
3. **Launch Container**:
   - After reserving the resource, use `chi.container.launch` to launch a container with Python 3.9-slim and SSH installed.

Here is an example of how you can achieve this:

```python
import chi

# Step 1: Reserve one Raspberry Pi 4 for 10 hours
reservation = chi.reservation.request(
    count=1,
    duration_hours=10,
    machine_type="raspberrypi4-64",
)

if reservation:
    print(f"Reservation successful. Reservation ID: {reservation['id']}")
else:
    print("Failed to reserve resources.")
    exit(1)

# Step 2: Launch a container with Python 3.9-slim and SSH installed
container = chi.container.launch(
    reservation_id=reservation["id"],
    image="python:3.9-slim",
    exposed_ports=[22],  # Expose port 22 for SSH
    command=["/bin/sh", "-c", "apt-get update && apt-get install -y openssh-server && service ssh start && tail -f /dev/null"]
)

if container:
    print(f"Container launched successfully. Container ID: {container['id']}")
else:
    print("Failed to launch the container.")
```

### Explanation:

- **Reservation Request**: The `chi.reservation.request` function reserves one Raspberry Pi 4 for 10 hours.
  
- **Launching a Container**:
  - Use `chi.container.launch` with the reservation ID obtained from the previous step.
  - Specify `"python:3.9-slim"` as the image to use.
  - Expose port 22 (`exposed_ports=[22]`) for SSH access.
  - The command installs and starts an SSH server on the container.

This script will reserve a Raspberry Pi 4, launch a Python 3.9-slim container with SSH installed, and make it accessible via SSH from outside.
