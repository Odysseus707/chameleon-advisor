To get a Raspberry Pi on CHI@Edge that you can access with VS Code Remote-SSH, follow these steps:

1. **Prepare Your Environment**:
   - Ensure you have an account on CHAMELEON Cloud.
   - Install and configure the `chi` command-line tool if not already done.

2. **Create a Lease for Raspberry Pi 4 (64-bit)**:
   Use the `chi lease create` command to request a lease for a Raspberry Pi 4 with ARM architecture. The lease will expose port 22 for SSH access.
   
   ```bash
   chi lease create --machine-type raspberrypi4-64 \
                    --image ghcr.io/chameleoncloud/edge_ssh_image:latest \
                    --exposed-ports 22 \
                    --duration-hours 3
   ```

3. **Retrieve the Lease Details**:
   Once the lease is created, you will receive details about your leased device including its IP address and SSH credentials.

4. **SSH into Your Device**:
   Use the provided IP address and SSH credentials to connect to your Raspberry Pi via SSH.
   
   ```bash
   ssh <username>@<ip_address>
   ```

5. **Configure VS Code Remote-SSH**:
   - Open Visual Studio Code.
   - Install the "Remote Development" extension pack if not already installed.
   - Use `Remote-SSH: Connect to Host...` command from the Command Palette (`Ctrl+Shift+P`) and add your Raspberry Pi's SSH details.

6. **Work Remotely**:
   Once connected, you can now work on your Raspberry Pi as a remote development environment using VS Code.

Remember that the lease duration is set for 3 hours in this example; adjust it according to your needs by changing `--duration-hours` value.
