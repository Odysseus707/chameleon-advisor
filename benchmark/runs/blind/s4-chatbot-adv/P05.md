To launch a basic Ubuntu container on a reserved Raspberry Pi 4 (64-bit) on CHI@Edge, follow these steps:

1. **Reserve the Edge Device**: First, you need to reserve an edge device with the specifications mentioned in the context (`raspberrypi4-64`).

2. **Prepare Your Environment**:
   - Ensure that your environment is set up for working with CHI@Edge resources.
   - You will likely use a command-line interface (CLI) or Python SDK to interact with the CHI@Edge platform.

3. **Launch the Container**:
   - Since the context suggests using `python:3.9-slim` as an image, but you want a basic Ubuntu container, you should specify the appropriate Ubuntu image.
   
Here is how you can do it via Python SDK:

```python
from chi.edge import EdgeClient

# Initialize the client with your credentials or token
client = EdgeClient()

# Reserve one Raspberry Pi 4 (64-bit) for 3 hours
reservation = client.reserve(
    machine_type="raspberrypi4-64",
    count=1,
    duration_hours=3
)

# Once reserved, get the device information
device_info = reservation.devices[0]

# Launch a basic Ubuntu container on the reserved device
container = client.launch_container(
    device_id=device_info['id'],
    image="ubuntu:latest"  # Specify the latest Ubuntu image here
)

print(f"Container launched with ID: {container.id}")
```

This script does the following:
- Initializes an EdgeClient to interact with CHI@Edge.
- Reserves one Raspberry Pi 4 (64-bit) for a duration of 3 hours.
- Launches a basic Ubuntu container on the reserved device.

Make sure you have the necessary permissions and that your environment is correctly configured to use the `chi.edge` package. Adjust the image tag (`ubuntu:latest`) if you need a specific version of Ubuntu.
