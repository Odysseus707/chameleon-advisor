To run `ls /app` inside a running container in CHI@Edge and capture the output, you can follow these steps:

1. **SSH into the Container**: Use SSH to connect to the running container on CHI@Edge. The exact command will depend on the specific details of your setup, such as the IP address or hostname of the edge device and any necessary credentials.

2. **Run `ls /app` Command**: Once connected via SSH, you can run the `ls /app` command to list the contents of the `/app` directory inside the container.

3. **Capture Output**: Redirect the output of the `ls /app` command to a file or use another method to capture it as needed.

Here is an example sequence of commands:

```bash
# SSH into the running container (replace <hostname> and <container_id> with actual values)
ssh user@<hostname>

# Once inside, run ls /app and redirect output to a file
ls /app > output.txt

# Alternatively, you can directly capture the output in one command:
ssh user@<hostname> "docker exec <container_id> ls /app" > output.txt
```

In this example, replace `user`, `<hostname>`, and `<container_id>` with your actual username, hostname of the edge device, and container ID respectively. The second SSH command directly executes the `ls` command inside the specified container and captures its output to a file named `output.txt`.

This approach leverages SSH for direct access to the running container, providing a familiar interface for interacting with the container's filesystem.
