To extend your lease by 2 more hours on CHI@Edge using `python-chi`, you can follow these steps:

1. **Import Chi Library**: Import the necessary modules from `chi`.

2. **Use Site**: Set up the authentication context for CHI@Edge.

3. **Extend Lease Duration**: Calculate the new end date by adding 2 hours to your current lease's expiration time.

4. **Update Lease**: Use the `update_lease` function provided by `python-chi` to extend the lease duration.

Here is a sample code snippet that demonstrates how you can achieve this:

```python
import chi
from datetime import timedelta, datetime

# Use CHI@Edge site
chi.use_site('CHI@Edge')

# Get current lease details (assuming you have the lease ID)
lease_id = 'your_lease_id_here'
current_lease = chi.lease.get_lease(lease_id)

# Calculate new end date by adding 2 hours to the existing lease's expiration time
new_end_date = datetime.strptime(current_lease['end'], '%Y-%m-%dT%H:%M:%SZ') + timedelta(hours=2)
new_end_date_str = new_end_date.strftime('%Y-%m-%dT%H:%M:%SZ')

# Update the lease with the new end date
updated_lease = chi.lease.update_lease(lease_id, end=new_end_date_str)

print(f"Lease updated to expire at: {updated_lease['end']}")
```

**Note**: Replace `'your_lease_id_here'` with your actual lease ID.

This code snippet assumes you have the necessary authentication setup and that `python-chi` is correctly installed and configured in your environment.
