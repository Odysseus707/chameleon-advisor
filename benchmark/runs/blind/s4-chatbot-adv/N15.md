To reserve a free Raspberry Pi 5 on CHI@Edge for 3 hours, follow these steps:

1. **Identify the Machine Type**: The machine type you need is `raspberrypi5`.

2. **Check Availability**: Verify if there are any free Raspberry Pi 5 devices available on CHI@Edge at the moment.

3. **Reserve the Device**:
    - Use the Chameleon Cloud interface or API to request a lease for one (`count=1`) Raspberry Pi 5.
    - Specify that you want it reserved for `duration_hours=3`.

Here is an example of how you might do this using the command line with the Chameleon Cloud CLI (assuming you have access and are authenticated):

```bash
chcli edge lease create --machine-type raspberrypi5 --count 1 --duration-hours 3
```

This command requests a reservation for one Raspberry Pi 5 device for three hours. If there is no live-free device confirmed, the system will attempt to allocate one based on availability.

Please note that you need to have the necessary permissions and be authenticated with Chameleon Cloud to perform these actions.
