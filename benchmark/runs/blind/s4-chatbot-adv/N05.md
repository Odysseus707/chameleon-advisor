To launch an Ollama container on your existing CHI@Edge lease named `my-llm-lease` with GPU support, expose only the Ollama API port, and give it a public IP, follow these steps:

1. **SSH into Your Lease**: First, SSH into the device where your lease is active.
    ```bash
    ssh -i /path/to/your/private/key ubuntu@<device_ip>
    ```

2. **Install Docker**: Ensure that Docker is installed on the machine. If not, install it using:
    ```bash
    sudo apt-get update
    sudo apt-get install docker.io
    ```

3. **Install NVIDIA Container Toolkit**: To enable GPU support for Docker containers, you need to install the NVIDIA Container Toolkit.
    ```bash
    distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
    curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
    curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list
    sudo apt-get update
    sudo apt-get install -y nvidia-docker2
    sudo systemctl restart docker
    ```

4. **Pull the Ollama Docker Image**: Pull the required Ollama container image from Docker Hub or another repository.
    ```bash
    docker pull ollama/image:tag  # Replace with actual Ollama image and tag
    ```

5. **Run the Container with GPU Support**: Run the Ollama container, enabling GPU support and exposing only the necessary port (assuming the default Ollama API port is 11434).
    ```bash
    docker run --gpus all -p 11434:11434 ollama/image:tag
    ```

6. **Assign a Public IP**: Ensure that your lease has been configured with a public IP address. If not, you may need to request this through the CHI@Edge interface or documentation.

7. **Configure Firewall (if necessary)**: Make sure the firewall allows traffic on port 11434.
    ```bash
    sudo firewall-cmd --zone=public --add-port=11434/tcp --permanent
    sudo firewall-cmd --reload
    ```

8. **Access Ollama API**: You can now access the Ollama API using the public IP address of your device and port 11434.

Note: Ensure that you have the necessary permissions to perform these actions on the lease, and verify that the GPU resources are correctly allocated and accessible within the container.
