### Steps to Set Up SSH Access:
1. **Key Pair Tab:**
   - Go to the Key Pair tab and select an existing key pair or create a new one if needed.
   - Ensure your public key is added so that you can access the instance via SSH.

2. **Security Groups Tab:**
   - Navigate to the Security Groups tab.
   - Add a rule for port 22 (SSH) to allow incoming connections from your IP address or any other necessary IPs.
   
3. **Network Tab:**
   - Go to the Network tab and select the appropriate network, usually your project’s private network.

4. **Launch Instance:**
   - Click on the Launch button to start your instance.

2. **Install Docker (if not already installed):**
   ```bash
   sudo apt-get update
   ```

     ```bash
     sudo docker run --name my-camera-container [camera-image-name]
     ```

4. **Retrofit SSH Access (Root Login):**
   - Ensure root login is enabled by editing the SSH configuration file:
     ```bash
     sudo nano /etc/ssh/sshd_config
     ```
   - Change `PermitRootLogin` to `yes`.
   - Restart SSH service:
     ```bash
     sudo systemctl restart sshd
     ```

5. **Allow Teammate Access:**
   - Add your teammate’s public key to the root user's authorized_keys file:
     ```bash
     echo "your_teammate_public_key" >> /root/.ssh/authorized_keys
     ```
   
6. **Assign Floating IP (if needed):**
   - Go back to the Chameleon Cloud GUI and associate a floating IP address with your instance if you need external access.
