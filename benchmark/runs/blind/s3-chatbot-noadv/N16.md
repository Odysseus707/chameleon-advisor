To run GPU-accelerated inference on a Jetson-class device on CHI@Edge, follow these steps:

1. **Reserve a Jetson Device:**
   - Log in to your Chameleon Cloud account.
   - Navigate to the CHI@Edge section where you can see available devices.
   - Reserve a Jetson-class device for your use.

2. **Start a CUDA-capable Container:**
   - Once the device is reserved, connect to it using SSH or another preferred method.
   - Ensure that Docker is installed on the Jetson device as containers are often used to manage software environments.
   - Pull and start a CUDA-capable container from Docker Hub or your own repository. For example:
     ```bash
     docker pull nvidia/cuda:10.2-cudnn8-runtime-ubuntu18.04
     docker run --gpus all -it nvidia/cuda:10.2-cudnn8-runtime-ubuntu18.04 /bin/bash
     ```
   - This command pulls the CUDA 10.2 image with cuDNN and starts a container where you can execute your GPU-accelerated inference code.

3. **Run Your Inference Code:**
   - Inside the container, install any necessary dependencies for your inference model.
   - Load your trained model and run the inference using libraries like TensorFlow or PyTorch that support CUDA.

Note: The blog post provided does not contain specific instructions on reserving Jetson devices or starting containers but gives an overview of how CHI@Edge can be used to manage edge devices. For detailed steps, refer to the official Chameleon Cloud documentation for CHI@Edge and Docker usage with NVIDIA GPUs.
