To run `ls /app` inside a running container in CHI@Edge and capture the output, follow these steps:

1. **SSH into the Container**: Use SSH to connect to the specific container on CHI@Edge. The exact command will depend on the details provided by the CHI@Edge dashboard or your setup instructions.

   Example:
   ```sh
   ssh user@container_ip_or_hostname
   ```

2. **Run `ls /app` and Capture Output**: Once connected, you can run the `ls /app` command to list the contents of the `/app` directory inside the container. To capture the output, redirect it to a file or use other shell utilities.

   Example:
   ```sh
   ls /app > output.txt
   ```

   Or if you want to see and save the output:

   ```sh
   ls /app | tee output.txt
   ```

This will list the contents of `/app` inside your container, capturing the output in `output.txt`.
