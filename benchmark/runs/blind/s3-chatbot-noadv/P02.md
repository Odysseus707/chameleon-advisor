To reserve one Raspberry Pi 4 on CHI@Edge for 2 hours using `python-chi`, follow these steps:

1. Import the necessary modules and set up your authentication context:
```python
import chi

# Use the appropriate site (CHI@UC in this example)
chi.use_site('CHI@UC')
```

2. Define the lease parameters, including the node type (`raspberry-pi-4`), count (1), start date, and end date for 2 hours:
```python
lease_name = "my-raspberry-pi-lease"
node_type = "raspberry-pi-4"
node_count = 1

# Define lease duration of 2 hours
start_date, end_date = chi.lease.lease_duration(hours=2)
```

3. Create a reservation for the Raspberry Pi 4:
```python
reservations = []
chi.lease.add_node_reservation(reservations, count=node_count,
                               node_type=node_type)
```

4. Request the lease with the specified parameters:
```python
lease = chi.lease.create_lease(lease_name, reservations, start_date=start_date,
                               end_date=end_date)
```

5. Wait for the lease to become active before proceeding:
```python
chi.lease.wait_for_active(lease.id)
```

6. After the lease is active, you can launch instances against it if needed (this step depends on your specific use case and additional configurations such as image name, flavor ID, etc.).

Note: The example assumes that you have already set up your environment with necessary credentials and configurations for `python-chi`.
