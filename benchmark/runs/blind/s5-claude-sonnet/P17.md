Capturing the still (run inside the container, once it has camera access wired up via a device profile at container-creation time — see the camera device-profile note below):

```python
from picamera2 import Picamera2

picam2 = Picamera2()
config = picam2.create_still_configuration(main={"size": (1920, 1080)})
picam2.configure(config)
picam2.start()
picam2.capture_file("still_1080p.jpg")
picam2.stop()
```

Getting it back off the device is the part I want to be careful about: CHI@Edge containers don't come with SSH/SCP by default, and I don't have confident, specific knowledge of the exact current CLI syntax for pulling a single file out of a Zun container (it used to be a `zun cp` / `openstack appcontainer cp`-style command, but I can't guarantee that's still accurate). The approach I'm confident works, and matches how CHI@Edge containers are normally exposed, is to serve the file over HTTP from the container (which already needs a public IP) and pull it down with a normal HTTP client:

Inside the container, after capturing the photo:

```python
import http.server
import socketserver

PORT = 8000
handler = http.server.SimpleHTTPRequestHandler
with socketserver.TCPServer(("", PORT), handler) as httpd:
    print(f"Serving on port {PORT}")
    httpd.serve_forever()
```

Then from your own machine (with the container launched with `exposed_ports=[8000]` and `public_ip=True`):

```bash
curl -O http://<container-floating-ip>:8000/still_1080p.jpg
```

Notes:
- `create_still_configuration(main={"size": (1920, 1080)})` requests a 1920x1080 capture; the Pi Camera Module's actual sensor may need to support that resolution (or picamera2 will scale it), so if you need native full-sensor resolution rather than a 1080p crop/scale, check the specific camera module's supported modes.
- If your CHI@Edge site/project offers SSH-based file transfer for containers instead, that's a cleaner path than standing up an HTTP server — but I don't have confident knowledge of the current exact command for it, so I'd rather give you the HTTP approach I'm sure works than guess at CLI syntax.
