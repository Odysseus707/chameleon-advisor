```python
import chi
from chi import lease

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")

reservations = []
lease.add_device_reservation(reservations, count=1, machine_name="raspberrypi4-64")

start_date, end_date = lease.lease_duration(hours=2)

pi_lease = lease.create_lease("my-pi-lease", reservations, start_date=start_date, end_date=end_date)
lease.wait_for_active(pi_lease["id"])

# The device reservation_id is what you pass to container.create_container(reservation_id=...)
reservation_id = pi_lease["reservations"][0]["id"]
print("reservation_id:", reservation_id)
```

The lease itself has an `id`, but the container API wants the *reservation* id nested inside the lease (a lease can in principle bundle more than one reservation, e.g. a device reservation plus a floating-IP reservation, so they're not the same value). Pulling `pi_lease["reservations"][0]["id"]` after `wait_for_active` gets you the device reservation id to hand to `container.create_container(..., reservation_id=reservation_id)`.
