# Launch an SSH-enabled container on a reserved Pi and tell me how to connect

Steps: reserve a device lease, launch a container from an image that runs an SSH server on port 22, attach a floating IP to the container, then connect with a normal `ssh` client.

```python
import chi
from chi import lease, container

chi.use_site("CHI@Edge")

# 1. Reserve a device (a Raspberry Pi, in this case)
reservations = []
lease.add_device_reservation(reservations, count=1, machine_name="raspberrypi4-64")

start_date, end_date = lease.lease_duration(days=1)
edge_lease = lease.create_lease("my-ssh-lease", reservations,
                                 start_date=start_date, end_date=end_date)
lease.wait_for_active(edge_lease["id"])

device_reservation_id = lease.get_device_reservation(edge_lease["id"])

# 2. Launch a container with SSH running, port 22 exposed
my_container = container.create_container(
    name="my-ssh-container",
    image="youruser/edge-ssh:latest",   # an arm64 image with sshd installed & started
    reservation_id=device_reservation_id,
    exposed_ports=[22],
)
container.wait_for_active(my_container.uuid)

# 3. Give it a floating IP so it's reachable from outside
floating_ip = container.associate_floating_ip(my_container.uuid)
print(floating_ip)
```

To connect:

```bash
ssh root@<floating_ip>
```

A few things to have in place before this works:
- Your Docker image needs an SSH server installed and started as the container's entrypoint/CMD, listening on port 22 — CHI@Edge doesn't inject one for you.
- Public-key auth needs to be set up in the image or injected at container start (via an environment variable your entrypoint script writes to `~/.ssh/authorized_keys`), since there's no cloud-init metadata service for containers.
- Make sure the security group / port rules on the CHI@Edge network allow inbound TCP 22 to the floating IP.

If you don't already have a suitable SSH image, see the separate question on which image/port to use and how to inject your key — that's the missing piece to make this connectable.
