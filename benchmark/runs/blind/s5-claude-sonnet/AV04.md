```python
import chi
from chi import hardware

chi.use_site("CHI@Edge")

for device in hardware.get_devices():
    if device.reservable and "pi_sensehat" in device.device_profiles:
        print(device.device_name)
```

Each device record carries a `device_profiles` list describing the attached peripherals/capabilities it can expose to a container (camera, Sense HAT, etc.); `pi_sensehat` is the profile a container requests to get access to the Sense HAT. Filtering on both `reservable` and profile membership gives the currently-free devices that support it. As with the other availability questions, the concrete list can only be produced by running this against the live inventory.
