```python
import chi
from chi import hardware

chi.use_site("CHI@Edge")

count = sum(1 for d in hardware.get_devices() if d.reservable)
print(count)
```

`hardware.get_devices()` with no filter returns every device across all CHI@Edge device types (Raspberry Pi 4, Jetson boards, etc.); summing the ones with `reservable == True` gives the total currently free. Like the other availability questions, the actual number depends on live reservation state, so it has to come from running this against the API rather than from anything I can know in advance.
