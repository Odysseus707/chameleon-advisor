# Tear everything down: remove the CHI@Edge container and free the device

Two things hold resources on CHI@Edge: the running container (Zun) and the device lease (Blazar). Deleting the container alone does not release the device reservation — the lease keeps the device allocated to you until it's deleted or it naturally expires. Delete both, in that order.

```python
import chi
from chi import container, lease

chi.use_site("CHI@Edge")

container_ref = "my-container"   # name or uuid
lease_name = "my-edge-lease"     # or keep the lease_id from when you created it

# 1. Delete the container
container.destroy_container(container_ref)

# 2. Delete the lease to free the device reservation
my_lease = lease.get_lease(lease_name)
lease.delete_lease(my_lease["id"])
```

If you still have the `Lease` and container objects from your session, most python-chi versions also let you call `.delete()` directly on them (e.g. `my_lease.delete()`, `my_container.delete()`) instead of the module-level functions above — either form ends up doing the same two API calls. Also detach any floating IP you associated with the container before or as part of deleting it; if `destroy_container` doesn't automatically release it, do so explicitly with `container.remove_floating_ip(...)` (or the equivalent Neutron floating-IP release) so it doesn't stay reserved against your allocation.
