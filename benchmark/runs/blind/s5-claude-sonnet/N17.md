Extending a lease means updating its `end_date` through Blazar (the reservation service) — python-chi doesn't have a magic "add N hours" call, so you compute the new end time yourself and push it.

```python
import chi
from chi import lease
from datetime import datetime, timedelta

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")

lease_id = "YOUR_LEASE_ID"

current = lease.get_lease(lease_id)
# Blazar returns end_date as a string like "2026-08-19T18:00:00.000000"
current_end = datetime.strptime(current["end_date"], "%Y-%m-%dT%H:%M:%S.%f")
new_end = current_end + timedelta(hours=2)

lease.update_lease(
    lease_id,
    end_date=new_end.strftime("%Y-%m-%d %H:%M"),
)

# Confirm it took
print(lease.get_lease(lease_id)["end_date"])
```

If `lease.update_lease` isn't available in the python-chi version you have installed, the same change can be made directly against the underlying Blazar client:

```python
chi.blazar().lease.update(lease_id, {"end_date": new_end.strftime("%Y-%m-%d %H:%M")})
```

One important caveat: this is a reservation-based extension, not a guarantee. If another user's lease is already booked to start on that Raspberry Pi right when your current lease was due to end, Blazar will reject the extension because the device isn't free for the requested window — you'd need to grab a different device or a shorter extension. Since you're an hour out, do this now rather than waiting until the lease actually expires; once it expires the container/device is released and there's nothing to extend.
