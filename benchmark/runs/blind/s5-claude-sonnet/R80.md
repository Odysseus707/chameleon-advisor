No availability listing was provided with this request, so I cannot tell you what's currently free on CHI@Edge — check the Horizon host-calendar or `openstack reservation list --site CHI@Edge` before reserving.

Ranked best first for running an int8 model on any available hardware accelerator, 1 device for about 3 hours:

1. coral-dev — the Google Coral Dev Board's Edge TPU is purpose-built for int8-quantized (TensorFlow Lite) models; int8 is its native, best-performing precision.
2. jetson-agx-orin-devkit-64gb — Ampere tensor cores support fast INT8 inference via TensorRT, and it's the most powerful general-purpose accelerator on CHI@Edge if your model isn't TFLite-based.
3. jetson-orin-nano-devkit-nvme — the same Ampere INT8/TensorRT support as the AGX Orin in a smaller, lower-power form factor; a reasonable alternative if the AGX Orin isn't available.

jetson-xavier-nx-devkit-emmc is also a viable INT8/TensorRT option (Volta tensor cores) if none of the above are free. I would not recommend raspberrypi4-64, raspberrypi5, or jetson-nano — none offer dedicated int8 acceleration comparable to these.
