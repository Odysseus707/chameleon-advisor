```python
import chi

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")
```

That's the whole minimal setup: `use_site` points python-chi at the CHI@Edge testbed (as opposed to CHI@TACC/CHI@UC/KVM@TACC), and `chi.set("project_name", ...)` selects which Chameleon allocation/project to charge the reservation against. Everything after this — `chi.lease`, `chi.container`, etc. — will operate against CHI@Edge using that project context.

You'll also need valid Chameleon credentials available in your environment (typically via `~/.chameleon/clouds.yaml` or the `OS_*` environment variables from an OpenRC file) for authentication to actually succeed — `chi.use_site`/`chi.set` alone just configure the client, they don't authenticate you.
