```python
import chi
from chi import lease

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")

reservations = []
lease.add_device_reservation(reservations, count=3, machine_name="raspberrypi4-64")

start_date, end_date = lease.lease_duration(hours=2)

pi_lease = lease.create_lease("my-3pi-lease", reservations, start_date=start_date, end_date=end_date)
lease.wait_for_active(pi_lease["id"])

print("Lease active:", pi_lease["id"])
print("Reservation:", pi_lease["reservations"][0]["id"])
```

A single `add_device_reservation` call with `count=3` and one `machine_name` reserves three devices of the same type under one reservation (and one lease) — you don't need three separate `add_device_reservation` calls or three leases. Note that CHI@Edge's Raspberry Pi pool is small and shared, so a request for 3 identical Pis can fail or sit pending if fewer than 3 are currently free; check the CHI@Edge hardware browser for current availability before reserving if this doesn't go active quickly.
