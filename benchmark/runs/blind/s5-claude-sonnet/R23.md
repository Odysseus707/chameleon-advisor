What follows is a suitability ranking for a CPU-only MobileNet TFLite classification job (1 device, ~4 hours), not a statement of current availability.

1. raspberrypi4-64 — quad-core Cortex-A72 handles a small CPU-bound TFLite model like MobileNet comfortably, and it's the most commonly used and documented CHI@Edge device for exactly this kind of workload.
2. raspberrypi5 — faster Cortex-A76 cores than the Pi 4 give lower per-image inference latency on the same CPU-only TFLite path, if one is free.
3. jetson-nano — its CPU (quad-core Cortex-A57) is weaker than either Raspberry Pi, but it still runs TFLite fine in CPU-only mode and is a reasonable fallback if both Pi types are unavailable.

I'd avoid coral-dev for this job — its value is the Edge TPU, which a plain CPU MobileNet run doesn't use, and its CPU is comparatively weak. I'd also avoid the Jetson Xavier/Orin/AGX tiers unless nothing smaller is available — their advantage is GPU acceleration, which this CPU-only task doesn't touch, so they're bigger than the job needs.
