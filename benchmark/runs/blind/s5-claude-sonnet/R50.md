I don't have visibility into live CHI@Edge device availability from here — no availability listing was provided with this request. Check the Reservation Calendar in the Chameleon GUI (or a host/device availability query via python-chi) before reserving.

Note that not every CHI@Edge device supports CUDA: the Raspberry Pi boards have no NVIDIA GPU, and the Coral Dev Board accelerates inference via its Edge TPU (a TensorFlow Lite delegate), not CUDA — so neither is usable for this task regardless of availability. Ranked top 3 CUDA-capable devices for a real-time object-detection workload on a live camera stream:

1. jetson-orin-nano-devkit-nvme — current-generation Ampere GPU with strong CUDA/TensorRT throughput per watt, well suited to running a live-camera object-detection model in real time.
2. jetson-agx-orin-devkit-64gb — the most powerful CUDA/GPU option in the CHI@Edge Jetson lineup, giving the most headroom for a heavier detection model or higher input resolution/frame rate, at the cost of being a larger, likely more contended unit.
3. jetson-xavier-nx-devkit-emmc — an older but still solidly CUDA-capable GPU, well-trodden in the JetPack/TensorRT ecosystem for real-time video inference; a reasonable fallback if the Orin boards aren't available.

I'd avoid jetson-nano for this specific task unless nothing else is free — its older, weaker GPU and limited RAM tend to struggle with modern object-detection models at real-time frame rates, even though it is technically CUDA-capable. I'm not certain what JetPack/CUDA version is preinstalled on each device image, so confirm that matches your model/TensorRT requirements before reserving.
