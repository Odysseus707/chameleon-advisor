```python
import chi
from chi import hardware

chi.use_site("CHI@Edge")

device = hardware.get_device("iot-rpi4-picam2")
print(device.reservable)
```

`hardware.get_device(device_name)` looks up a single device by its `device_name` and returns an object whose `reservable` attribute is `True` exactly when the device has no active or upcoming lease blocking it right now. This has to be evaluated live — I can't state whether `iot-rpi4-picam2` is currently free without querying the CHI@Edge API at the moment you run it.
