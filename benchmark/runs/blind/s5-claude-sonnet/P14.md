# End-to-end: get me a Pi on CHI@Edge I can hit with VS Code Remote-SSH

This is the same lease -> container -> floating IP -> SSH pipeline as a plain SSH container, plus a couple of CHI@Edge-specific gotchas that matter for VS Code Remote-SSH specifically:

- Remote-SSH copies and runs a small Node-based server on the remote host. That server is a **glibc** binary — it will not run on musl-based images (Alpine). Use a Debian/Ubuntu arm64 base image.
- The container needs enough writable disk under `~/.vscode-server` for the server to unpack itself, and needs `curl`/`wget` or the ability for VS Code to push the tarball over the SSH connection — a truly minimal image can be too stripped down.
- Since CHI@Edge devices are arm64, make sure the Remote-SSH server matches (VS Code auto-detects arch over SSH; you don't need to do anything special beyond running the right image).

```python
import chi
from chi import lease, container

chi.use_site("CHI@Edge")

# 1. Reserve a Raspberry Pi
reservations = []
lease.add_device_reservation(reservations, count=1, machine_name="raspberrypi4-64")
start_date, end_date = lease.lease_duration(days=1)
edge_lease = lease.create_lease("vscode-lease", reservations,
                                 start_date=start_date, end_date=end_date)
lease.wait_for_active(edge_lease["id"])
device_reservation_id = lease.get_device_reservation(edge_lease["id"])

# 2. Launch a glibc-based container with sshd + your key baked/injected in
with open("/home/you/.ssh/id_rsa.pub") as f:
    pubkey = f.read().strip()

my_container = container.create_container(
    name="vscode-container",
    image="youruser/edge-ssh-debian-arm64:latest",
    reservation_id=device_reservation_id,
    exposed_ports=[22],
    environment={"SSH_AUTHORIZED_KEYS": pubkey},
)
container.wait_for_active(my_container.uuid)

# 3. Attach a floating IP
floating_ip = container.associate_floating_ip(my_container.uuid)
print(floating_ip)
```

Then add an entry to your local `~/.ssh/config`:

```
Host chi-edge-pi
    HostName <floating_ip>
    User root
    IdentityFile ~/.ssh/id_rsa
```

In VS Code: Command Palette -> "Remote-SSH: Connect to Host..." -> `chi-edge-pi`. First connect will take longer while the VS Code server installs on the Pi.

When you're done, delete the container and the lease (see the teardown question) — floating IPs and device reservations are limited/billed resources and won't free themselves until the lease ends.
