Below is a suitability ranking for serving a quantised ONNX model and benchmarking its latency (1 device, ~6 hours), based on general hardware characteristics rather than confirmed availability.

1. raspberrypi5 — newest Cortex-A76 cores give the lowest CPU inference latency among the commonly-available CHI@Edge boards, which matters directly for a latency-benchmarking task.
2. raspberrypi4-64 — well-tested ONNX Runtime arm64 support and a stable, widely-documented baseline if the Pi 5 isn't available.
3. jetson-nano — CPU is weaker than either Pi (quad-core Cortex-A57), so expect higher latency numbers, but it's a reasonable CPU-only fallback for ONNX Runtime if no Pi is free.

I'm not fully certain which ONNX Runtime version/operator set ships on each CHI@Edge image, so verify your quantised model's ops are supported on whichever device you pick before committing the full 6-hour window. I'd skip coral-dev here since its main advantage, the Edge TPU, needs an Edge-TPU-compiled model rather than a general quantised ONNX graph, and I'd skip the Jetson Xavier NX / Orin Nano / AGX Orin tiers unless nothing smaller is available — their advantage is GPU acceleration you haven't asked for, making them oversized for a CPU latency benchmark.
