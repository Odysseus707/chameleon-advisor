```python
import chi
from chi import container

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")

my_container = container.create_container(
    "my-container",
    image="ubuntu",
    reservation_id=reservation_id,
    exposed_ports=[8080],
    command=["sleep", "infinity"],  # or whatever actually serves on 8080
)

container.wait_for_active(my_container.uuid)

# Associate a public/floating IP so port 8080 is reachable from outside
ip_address = container.associate_floating_ip(my_container.uuid)
print("Public IP:", ip_address)
print(f"Reach it at http://{ip_address}:8080")
```

Two separate things have to happen: `exposed_ports=[8080]` tells Zun to open that port on the container itself, and `associate_floating_ip` is the step that actually gives the container a publicly routable address (CHI@Edge containers don't get a public IP by default — they're only reachable on the private network until you associate one). Both need to line up: exposing the port without a floating IP leaves it reachable only inside the private network, and a floating IP without exposing the port won't get traffic through to your process. Make sure whatever's actually running inside the container (your app, not just the container command) is listening on 0.0.0.0:8080, not localhost, or the exposed port won't help.
