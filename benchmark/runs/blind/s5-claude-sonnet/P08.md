```python
import chi
from chi import container

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")

result = container.execute(my_container.uuid, "ls /app")
print(result["output"])
```

`container.execute()` runs a one-off command inside an already-running container (via Zun's exec mechanism) and returns a dict that includes the captured stdout/stderr under `output` and the process's exit status. This assumes `my_container` (or its uuid) is already running — `ls /app` will only succeed if `/app` actually exists in that image; if the container exited or never reached active state, `execute` will fail rather than silently returning empty output, so it's worth confirming the container's status first if the call errors out.
