# Jupyter minimal-notebook on an already-active lease, with token from logs

Since `serve-edge-vr` is already active, you skip lease creation and just look it up, pull its device reservation ID, and launch the container against that.

```python
import chi
from chi import lease, container
import time, re

chi.use_site("CHI@Edge")
chi.set("project_name", "<your-project>")

my_lease = lease.get_lease("serve-edge-vr")
lease_id = my_lease["id"]

reservation_id = lease.get_device_reservation(lease_id)

nb_container = container.create_container(
    "serve-edge-vr-notebook",
    image="jupyter/minimal-notebook",
    reservation_id=reservation_id,
    exposed_ports=[8888],
)

container.wait_for_active(nb_container.uuid)

fip = container.associate_floating_ip(nb_container.uuid)
print("Public IP:", fip)
```

To find the notebook token, the `jupyter/minimal-notebook` entrypoint (via `start-notebook.sh`) prints something like:

```
[I ... ServerApp] Jupyter Server ... is running at:
[I ... ServerApp] http://<container-hostname>:8888/lab?token=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

to stdout/stderr on startup, which CHI@Edge captures as the container's logs. Pull and grep them:

```python
logs = container.get_logs(nb_container.uuid)
print(logs)

match = re.search(r"(https?://\S+token=\S+)", logs)
if match:
    url = match.group(1)
    # swap the container's internal hostname/port for your floating IP
    print("Rewrite host in this URL to your floating IP:", url)
    print(f"http://{fip}:8888/lab?token={url.split('token=')[-1]}")
else:
    print("Token URL not found yet — logs may need a moment; retry get_logs().")
```

Practical notes:
- Jupyter can take a few seconds to boot, so if the regex comes up empty, sleep briefly and call `container.get_logs()` again.
- The URL printed in the logs uses the container's internal hostname, not your floating IP — use the floating IP with the same port (8888) and token when connecting from outside.
- If the image requires a token but you'd rather set one explicitly, pass `environment={"JUPYTER_TOKEN": "your-token"}` in `create_container` and skip the log-scraping step entirely — that's simpler and more reliable than parsing logs.
