The deciding factor here is form factor, not compute: a Sense HAT is a Raspberry Pi HAT requiring the standard 40-pin GPIO header, and it physically stacks on a Raspberry Pi board only.

1. raspberrypi4-64 — standard 40-pin GPIO header the Sense HAT plugs into, and well-documented I2C/Sense HAT support on the CHI@Edge Pi 4 image for reading its HTS221 temperature/humidity sensor.
2. raspberrypi5 — same header and I2C bus; a fine substitute if the Pi 4 isn't free, but confirm the sense-hat library/overlay is present on the Pi 5 image since I'm less sure of parity there.

I'm not proposing a third device: none of the other CHI@Edge types (jetson-nano, jetson-xavier-nx-devkit-emmc, jetson-orin-nano-devkit-nvme, jetson-agx-orin-devkit-64gb, coral-dev) have the GPIO header a Sense HAT needs. If both Pi boards are unavailable, this task cannot be done on CHI@Edge right now.

```python
# Example: read temperature and humidity from a Sense HAT
from sense_hat import SenseHat

sense = SenseHat()
temperature = sense.get_temperature()
humidity = sense.get_humidity()
print(f"Temperature: {temperature:.1f} C, Humidity: {humidity:.1f} %")
```
