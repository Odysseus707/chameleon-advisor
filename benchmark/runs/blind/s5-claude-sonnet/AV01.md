Device availability changes constantly, so you need to query the live inventory rather than a static list. `python-chi`'s `hardware` module exposes the same device inventory backing the Hardware Browser, including whether each device is currently reservable:

```python
import chi
from chi import hardware

chi.use_site("CHI@Edge")

for device in hardware.get_devices(machine_name="raspberrypi4-64"):
    if device.reservable:
        print(device.device_name)
```

`hardware.get_devices()` returns one entry per physical device with `device_name` (the unique instance name, e.g. `iot-rpi4-01`) and `machine_name` (the hardware type, e.g. `raspberrypi4-64`) as separate fields, plus a `reservable` flag reflecting current Blazar allocation state. Filtering on `machine_name` and `reservable` gives exactly the free raspberrypi4-64 devices at the moment the script runs. Run this against the live API to get today's actual list — I can't produce the list itself from here since it depends on real-time reservation state.
