```python
import chi
from chi import lease, container

chi.use_site("CHI@Edge")

l = lease.get_lease(name="my-llm-lease")
reservation_id = lease.get_device_reservation(l["id"])

c = container.create_container(
    "ollama-server",
    image="ollama/ollama",
    reservation_id=reservation_id,
    runtime="nvidia",
    exposed_ports=[11434],
)
container.wait_for_active(c["uuid"])

container.associate_floating_ip(c["uuid"])
```

`runtime="nvidia"` is what requests GPU passthrough for the container on a GPU-capable device (e.g. a Jetson board) instead of running it as a plain CPU container. `11434` is Ollama's default API port, and it's the only port opened via `exposed_ports`, so nothing else on the container is reachable. `associate_floating_ip` is what gives it a public IP once it's active — you'd then reach the Ollama API at `http://<floating-ip>:11434`.
