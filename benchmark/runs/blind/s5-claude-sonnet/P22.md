Use the `sense_hat` Python library's `SenseHat` object — it exposes the onboard temperature, humidity, and pressure sensors directly:

```python
from sense_hat import SenseHat

sense = SenseHat()

temperature = sense.get_temperature()   # degrees Celsius
humidity = sense.get_humidity()         # percentage relative humidity
pressure = sense.get_pressure()         # millibars

print(f"Temperature: {temperature:.1f} C")
print(f"Humidity:    {humidity:.1f} %RH")
print(f"Pressure:    {pressure:.1f} mbar")
```

Notes:
- `get_temperature()` is a convenience wrapper that reads from the humidity sensor's temperature channel. The Sense HAT also has a second temperature source on the pressure sensor, readable via `sense.get_temperature_from_pressure()` — comparing the two can help sanity-check a reading, since the humidity-sensor temperature can run a bit high due to nearby CPU heat.
- This requires the `sense_hat` package (and its `RTIMULib`/I2C dependencies) to be installed in whatever container image you're running, and the container needs I2C access to the Sense HAT — on CHI@Edge that means launching with the `sense_hat` device profile.
- If `SenseHat()` raises an error about not finding the IMU/pressure/humidity chips, that's usually an I2C wiring/permission issue rather than a library bug — worth checking `i2cdetect` first to confirm the sensors are visible on the bus.
