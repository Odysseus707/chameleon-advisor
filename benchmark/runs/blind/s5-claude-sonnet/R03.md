I don't have visibility into live CHI@Edge device availability right now — you'll need to check the CHI@Edge Horizon dashboard (Reservations > Host Calendar) or list current devices via python-chi/Blazar before reserving, since inventory changes constantly and I shouldn't invent counts.

One note on the task itself: CHI@Edge provisions containers onto edge devices through Zun, so "SSH shell" access is typically an interactive container exec (similar to `docker exec`) rather than literal SSH to the bare host — worth confirming in the docs if you specifically need raw host SSH rather than a container shell.

For a plain 2-hour interactive shell with no GPU/TPU or camera requirement, here's my ranked recommendation by device type (confirm each is actually free before you lease it):

1. raspberrypi4-64 — the most broadly deployed and best-documented CHI@Edge device type; a basic shell session doesn't need more than this, so it's the safest default to try first.
2. raspberrypi5 — comparable ease of use and Linux/container support to the pi4, and being newer it may see less contention from other users' workloads.
3. jetson-nano — if both Pi types are unavailable, the entry-level Jetson still gives you a full interactive Linux shell even though its GPU sits unused for this task.

I'm not recommending the Xavier NX / Orin Jetsons or the Coral dev board for a plain SSH task — they're disproportionate to what you need, and I'd rather not guess at their current availability or lease overhead relative to the simpler boards.
