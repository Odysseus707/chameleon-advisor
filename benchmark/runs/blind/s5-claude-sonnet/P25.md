I'd rather not hand you a fixed list here, because CHI@Edge's device inventory is small and changes as Chameleon adds or retires physical units — a memorized list risks being stale. Historically the fleet has centered on Raspberry Pi 4B units (some with a Sense HAT attached) and NVIDIA Jetson boards (Xavier NX / Nano class), but I can't guarantee that's the complete current set or that all of those are presently reservable.

The reliable way to get the live, reservable list is to query it directly rather than trust a cached answer:

```python
import chi
from chi import container

chi.use_site("CHI@Edge")
chi.set("project_name", "YOUR_PROJECT_NAME")

for device_type in container.list_device_types():
    print(device_type)
```

Alternatively, use the Chameleon portal's **Hardware Browser** (Discover > Hardware Browser, filtered to the CHI@Edge site) — it shows the current device type inventory along with live availability/reservation status, which is more useful than a static list anyway since you presumably want to know what's actually free.
