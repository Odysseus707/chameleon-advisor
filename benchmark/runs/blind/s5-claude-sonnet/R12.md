The task hinges on hardware, not raw compute: a Pi camera module needs a CSI camera connector, and that's best supported on actual Raspberry Pi boards on CHI@Edge.

1. raspberrypi4-64 — native Raspberry Pi CSI camera connector, and the most common, best-documented CHI@Edge device for Pi Camera Module capture; the libcamera/picamera2 stack is well exercised there.
2. raspberrypi5 — same native CSI connector and current camera stack; a good alternative to the Pi 4 if that's not free.
3. jetson-nano — physically compatible with the same Pi Camera Module v2 (IMX219) sensor via its CSI connector, but I'm not sure the CHI@Edge Jetson Nano image is pre-configured for it, so only use this as a fallback and verify camera support first.

Any device type without a Pi-camera-compatible CSI connector simply can't do this task, no matter how available it is.

```python
# Example: capture a still with picamera2 on a Raspberry Pi (CHI@Edge)
from picamera2 import Picamera2
import time

picam2 = Picamera2()
picam2.start()
time.sleep(2)  # let auto-exposure settle
picam2.capture_file("still.jpg")
picam2.stop()
```
