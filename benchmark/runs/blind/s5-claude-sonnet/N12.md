This has to happen in two stages: get camera access into the container at launch time, then run capture + inference as a normal Python script inside it.

**Container side note:** to reach `/dev/video*` (or the Pi's CSI camera stack), you generally need to request camera hardware access when you create the container (CHI@Edge exposes selected peripherals via a device-profile mechanism rather than arbitrary privileged mode) and use a base image that has `libcamera`/`picamera2` (or `opencv`) plus `tflite-runtime` installed — either build a custom image ahead of time or `pip install` at container start. I don't have the exact current device-profile keyword memorized with full confidence, so check the CHI@Edge camera tutorial/hardware page for the precise value to pass at container creation before relying on this in production.

**Inside the container** — capture a still, then run it through a quantized MobileNet `.tflite` model:

```python
import time
import numpy as np
from PIL import Image
from picamera2 import Picamera2
import tflite_runtime.interpreter as tflite

# 1. Capture a photo with the Pi camera
picam2 = Picamera2()
picam2.configure(picam2.create_still_configuration())
picam2.start()
time.sleep(2)  # let auto-exposure/white-balance settle
picam2.capture_file("photo.jpg")
picam2.stop()

# 2. Load the quantized MobileNet TFLite model
interpreter = tflite.Interpreter(model_path="mobilenet_v1_1.0_224_quant.tflite")
interpreter.allocate_tensors()
input_details = interpreter.get_input_details()
output_details = interpreter.get_output_details()

_, height, width, _ = input_details[0]["shape"]

# 3. Preprocess: resize to model input size, keep as uint8 (quantized model)
img = Image.open("photo.jpg").convert("RGB").resize((width, height))
input_data = np.expand_dims(np.array(img, dtype=np.uint8), axis=0)

# 4. Run inference
interpreter.set_tensor(input_details[0]["index"], input_data)
interpreter.invoke()
output_data = interpreter.get_tensor(output_details[0]["index"])[0]

# 5. Decode top-5 predictions (requires the matching labels.txt for the model)
with open("labels.txt") as f:
    labels = [line.strip() for line in f]

top5 = output_data.argsort()[-5:][::-1]
for i in top5:
    score = output_data[i] / 255.0  # dequantize uint8 score to [0,1]
    print(f"{labels[i]}: {score:.3f}")
```

Notes:
- `tflite_runtime` (not full TensorFlow) is the lightweight interpreter meant for ARM/edge devices like the Pi — install with `pip install tflite-runtime`.
- The quantized model expects `uint8` input tensors and produces `uint8` output logits, so don't cast to `float32` the way you would for a float model.
- Make sure `mobilenet_v1_1.0_224_quant.tflite` and its matching `labels.txt` (1001-class ImageNet labels, index 0 = "background") are present in the container, either baked into the image or pulled down at startup.
