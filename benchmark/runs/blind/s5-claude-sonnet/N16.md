Caveat up front: I'm not fully certain what Jetson-class hardware (Nano vs. Xavier NX vs. Orin, or whether any is currently offered at all) is in the live CHI@Edge inventory — I'll use "jetson-nano" as the illustrative `machine_name` below, but confirm the actual device type and name in the CHI@Edge hardware browser before relying on this.

The reservation follows the same python-chi pattern as any other CHI@Edge device:

```python
import chi
from chi import lease, container

chi.use_site("CHI@Edge")
# chi.set("project_name", "your-project-name")  # or export OS_PROJECT_NAME

# 1. Reserve one Jetson device
reservations = []
lease.add_device_reservation(reservations, count=1, machine_name="jetson-nano")  # verify exact type string
start_date, end_date = lease.lease_duration(hours=2)

my_lease = lease.create_lease(
    "jetson-cuda-lease",
    reservations=reservations,
    start_date=start_date,
    end_date=end_date,
)
lease.wait_for_active(my_lease["id"])
reservation_id = lease.get_device_reservation(my_lease["id"])

# 2. Launch a CUDA-capable container
my_container = container.create_container(
    "jetson-cuda-infer",
    image="nvcr.io/nvidia/l4t-ml:r32.7.1-py3",  # must match the device's flashed JetPack/L4T version
    reservation_id=reservation_id,
    public_ip=True,
)
container.wait_for_active(my_container.uuid)

c = container.get_container(my_container.uuid)
print("Status:", c.status)
print("Address:", c.addresses)
```

Important detail that's easy to get wrong on Jetson: you can't just point at a generic `nvidia/cuda` Docker Hub image and expect GPU access. Jetson boards run NVIDIA's L4T (Linux for Tegra) — an arm64 build with the CUDA/cuDNN/TensorRT stack tied to a specific JetPack version baked into the OS image the board was flashed with. The container image has to be one of NVIDIA's `l4t-base`/`l4t-cuda`/`l4t-ml` family (from `nvcr.io`) tagged to match that JetPack/L4T version, or GPU access inside the container will fail even if the reservation and container both come up "active." If you're not sure which L4T version the CHI@Edge Jetson nodes are flashed with, that's something to check in the device documentation before picking an image tag.
