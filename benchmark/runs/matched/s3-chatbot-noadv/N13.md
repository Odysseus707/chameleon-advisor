To reserve one Raspberry Pi 4 for 10 hours starting now and launch `python:3.9-slim` with SSH installed, follow these steps using the imperative style of the Python CHI library:

### Step-by-Step Instructions

#### 1. Import Required Libraries:
```python
import chi
from chi import lease
from chi import container
```

#### 2. Set Up Environment and Project Name:
Ensure you are working with the correct Chameleon project name and site.
```python
PROJECT_NAME = os.getenv('OS_PROJECT_NAME') # Change this if needed
chi.use_site("CHI@Edge")
chi.set("project_name", PROJECT_NAME)
username = os.getenv('USER')
```

#### 3. Reserve a Raspberry Pi 4 for 10 Hours:
Define the lease and device reservation.
```python
NODE_TYPE = 'raspberrypi4-64'
expname = "edge-cpu"
reservations = []
lease.add_device_reservation(reservations, machine_name=NODE_TYPE, count=1)

start_date, end_date = lease.lease_duration(days=0, hours=10)
l = lease.create_lease(f"{username}-{NODE_TYPE}", reservations, start_date=start_date, end_date=end_date)
l = lease.wait_for_active(l["id"])
```

#### 4. Launch a Container on the Reserved Device:
Create and configure the container.
```python
container_name = f"{username}-{expname}".replace("_","-")
my_container = container.create_container(
    container_name,
    image="python:3.9-slim",
    reservation_id=lease.get_device_reservation(l["id"]),
    interactive=True,
    exposed_ports=[22],
    platform_version=2
)
container.wait_for_active(my_container.uuid)
```

#### 5. Attach a Floating IP and Install SSH:
Attach an IP address to the container and install the SSH server.
```python
public_ip = container.associate_floating_ip(my_container.uuid)

# Update package list and install openssh-server
container.execute(my_container.uuid, 'apt update')
container.execute(my_container.uuid, 'apt -y install openssh-server')

# Start the SSH service
container.execute(my_container.uuid, 'service ssh start')
```

#### 6. Configure SSH Access:
Ensure your key is installed on the container.
```python
!mkdir -p tmp_keys
!cp /work/.ssh/id_rsa.pub tmp_keys/authorized_keys

container.execute(my_container.uuid, 'mkdir -p /root/.ssh')
container.upload(my_container.uuid, "./tmp_keys/authorized_keys", "/root/.ssh")
container.execute(my_container.uuid, 'chown root /root/.ssh')
container.execute(my_container.uuid, 'chown root /root/.ssh/authorized_keys')
container.execute(my_container.uuid, 'chmod go-w /root')
container.execute(my_container.uuid, 'chmod 700 /root/.ssh')
container.execute(my_container.uuid, 'chmod 600 /root/.ssh/authorized_keys')

print("SSH access is now available at: ssh root@%s" % public_ip)
```
