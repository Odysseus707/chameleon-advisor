To reserve a camera-equipped Raspberry Pi device from CHI@Edge, start a container with the necessary dependencies for the camera to function, and retrofit SSH access so that a teammate can log in and run captures themselves, follow these steps:

### Step 1: Reserve a Camera-Equipped Device

First, you need to choose a site and project. Then, find an available Raspberry Pi device equipped with a camera.

```python
from chi import context, hardware, lease

# Choose the CHI@Edge site and your Chameleon project.
context.choose_site(default="CHI@Edge")
context.choose_project()

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
print([d.device_name for d in picamera_devs])

# Make a lease for one of the devices.
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)
```

### Step 2: Launch a Container with Camera Support

Next, launch a container on the reserved device. Ensure that the container has access to the necessary camera devices and dependencies.

```python
from chi import container

# Use the prebuilt image for libcamera and rpicam apps.
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],  # This profile exposes necessary devices.
)
my_container.submit()
```

### Step 3: Attach an IP Address and Configure SSH Access

To allow your teammate to access the container via SSH, you need to attach a floating IP address and configure SSH.

```python
# Attach a public IP address to the container.
public_ip = my_container.associate_floating_ip()

# Install SSH server in the container.
my_container.execute('apt update')
my_container.execute('apt -y install openssh-server')

# Upload your public key for root login.
import os

os.system("mkdir -p tmp_keys")
os.system("cp /work/.ssh/id_rsa.pub tmp_keys/authorized_keys")

my_container.execute('mkdir -p /root/.ssh')
my_container.upload("./tmp_keys/authorized_keys", "/root/.ssh/authorized_keys")
my_container.execute('chown root:root /root/.ssh')
my_container.execute('chmod 700 /root/.ssh')
my_container.execute('chmod 600 /root/.ssh/authorized_keys')

# Start the SSH server.
my_container.execute('service ssh start')
```

### Step 4: Provide Access Information to Your Teammate

Once everything is set up, provide your teammate with the public IP address and instructions on how to log in via SSH.

```python
print(f"SSH into the container using: ssh root@{public_ip}")
```

Your teammate can now use this information to access the container and run camera captures.
