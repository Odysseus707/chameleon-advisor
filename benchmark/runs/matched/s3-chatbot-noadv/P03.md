To reserve a Pi on CHI@Edge and get the reservation_id that you'll pass to a container, follow these steps:

1. **Choose the Site**: Ensure you are working with the correct Chameleon site (CHI@Edge).

    ```python
    from chi import context

    context.choose_site(default="CHI@Edge")
    ```

2. **Filter Available Devices**: Identify devices that have a Pi Camera Module attached.

    ```python
    from chi import hardware

    device_type = "raspberrypi4-64"
    available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

    picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
    ```

3. **Create a Lease**: Make a lease for one of the devices with the camera attached.

    ```python
    from chi import lease
    from datetime import timedelta

    my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
    my_lease.add_device_reservation(devices=[picamera_devs[0]])
    my_lease.submit(idempotent=True)
    ```

After executing these steps, `my_lease` will contain the reservation information for your device. The `reservation_id` can be accessed from `my_lease.device_reservations[0]["id"]`, which you'll use when launching a container to ensure it runs on the reserved device.

This process is based on the provided documentation and examples in the Jupyter notebook guide for using CHI@Edge with Raspberry Pi devices.
