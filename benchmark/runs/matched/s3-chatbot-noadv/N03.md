To give you a 12-hour lease on a camera-equipped Pi and capture a 640x480 still from it using Chameleon Cloud's CHI@Edge, follow these steps:

### Step-by-Step Guide

#### 1. Choose the Site and Project
First, ensure that your environment is set up to work with CHI@Edge.

```python
from chi import context

context.choose_site(default="CHI@Edge")
context.choose_project()
```

#### 2. Find a Camera-Equipped Device
Identify an available device with a camera attached.

```python
from chi import hardware

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
print([d.device_name for d in picamera_devs])
```

#### 3. Create a Lease
Make a lease for the camera-equipped Raspberry Pi.

```python
from chi import lease
from datetime import timedelta

my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=12))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)
```

#### 4. Launch a Container with the Required Dependencies
Launch a container that includes the necessary dependencies for using the camera.

```python
from chi import container

my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()
```

#### 5. Verify Camera Functionality
Ensure that the camera is detected and working properly.

```python
cmd = "rpicam-hello --nopreview --list-cameras"
result, code = my_container.execute(cmd)
print(result)
```

#### 6. Capture a Still Image
Capture a still image with dimensions of 640x480 pixels using the `rpicam-still` command.

```python
cmd = "rpicam-still --nopreview --output /app/test1.png --width 640 --height 480"
result, code = my_container.execute(cmd)
print(result)
```

#### 7. Download and Display the Image
Download the captured image from the container to your local environment.

```python
my_container.download("/app/test1.png", ".")
from IPython.display import Image
Image("test1.png", height=480, width=640)
```

### Cleanup

Once you are done with your experiment, clean up by deleting the lease and container to free up resources.

```python
my_container.delete()
my_lease.delete()
```

This process will give you a 12-hour lease on a camera-equipped Raspberry Pi and allow you to capture a still image of size 640x480 pixels.
