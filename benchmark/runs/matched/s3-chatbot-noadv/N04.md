To reserve the Waveshare Sense HAT (B) attached to `iot-rpi-cm4-02` and launch the sensor container with the necessary configurations for GPIO libraries, follow these steps:

1. **Authenticate to CHI@Edge**:
   ```python
   import chi

   chi.context.use_site("CHI@Edge")
   chi.context.choose_project()
   ```

2. **Create a Lease**:
   Reserve the specific device `iot-rpi-cm4-02` for your experiment.
   ```python
   from chi import lease
   import os

   machine_name = "raspberrypi4-64"
   device_name = "iot-rpi-cm4-02"

   username = os.environ.get("USER")
   lease_name = f"{username}-{device_name}"
   
   container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
   container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
   container_lease.submit()
   ```

3. **Launch the Container**:
   Configure and launch a container with the necessary environment variables to ensure GPIO libraries work despite missing devicetree info inside containers.
   ```python
   from chi import container

   container_name = "edge-waveshare-sensehat".replace("_", "-")
   
   environment_vars = {
       "RPI_LGPIO_REVISION": "0xd03140",
       "BLINKA_FORCECHIP": "BCM2XXX",
       "BLINKA_FORCEBOARD": "RASPBERRY_PI_CM4"
   }

   my_container = container.Container(
       name=container_name,
       image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
       device_profiles=["pi_gpio"],
       environment=environment_vars,
       reservation_id=container_lease.device_reservations[0]["id"],
       command=["-c", "sleep infinity"]
   )
   
   my_container.submit()
   ```

4. **List I2C Devices**:
   Use the `i2cdetect` utility to list devices on the I2C bus.
   ```python
   result, code = my_container.execute("i2cdetect -y 1")
   print(result)
   ```

This sequence of steps will reserve the device with the Waveshare Sense HAT (B), launch a container configured for GPIO library support, and display the I2C devices connected to the bus.
