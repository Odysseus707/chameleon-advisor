To rewrite the old tutorial script using the current object-oriented API (`lease.Lease` / `container.Container`), follow these steps:

1. Import necessary modules from `chi`.
2. Use `context.choose_site()` to select the site.
3. Use `context.choose_project()` to set the project name.
4. Get available devices and filter for the desired device type.
5. Create a lease with the selected device reservation.
6. Submit the lease.
7. Launch a container using the created lease.

Here is the updated script:

```python
from chi import context, hardware, lease, container

# Select CHI@Edge site and set project name
context.choose_site(default="CHI@Edge")
context.choose_project(project_name="CHI-000000")

# Get available devices of type raspberrypi4-64
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

# Filter for the specific device with camera attached (assuming it's named iot-rpi4-picam)
picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]

if picamera_devs:
    # Create a lease
    my_lease = lease.Lease("demo-lease", duration=timedelta(hours=10))
    my_lease.add_device_reservation(devices=[picamera_devs[0]])
    my_lease.submit(idempotent=True)

    # Launch container with the lease
    my_container = container.Container(
        "demo-app",
        image_ref="python:3.9-slim",
        reservation_id=my_lease.device_reservations[0]["id"],
        exposed_ports=[22],
        device_profiles=["pi_libcamera"],  # Ensure camera access
    )
    my_container.submit()
else:
    print("No suitable devices found.")
```

This script uses the object-oriented API to create a lease and launch a container, ensuring that the behavior is identical to the old imperative style but with updated methods.
