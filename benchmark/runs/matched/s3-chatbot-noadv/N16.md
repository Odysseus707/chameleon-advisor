To run GPU-accelerated inference on a Jetson-class device on CHI@Edge, follow these steps:

1. **Choose Project and Site**: Start by choosing your Chameleon project and site (default to `CHI@Edge`).

    ```python
    from chi import context

    context.version = "1.0" 
    context.choose_project()
    context.choose_site(default="CHI@Edge")
    ```

2. **Reserve a Jetson Device**: Identify the available Jetson devices and reserve one for your experiment.

    ```python
    from chi import hardware, lease
    
    # Filter for Jetson devices (assuming they have a specific naming convention)
    jetson_devices = [d for d in hardware.get_devices(filter_reserved=True) if "jetson" in d.device_name.lower()]
    
    # Choose the first available device
    chosen_device = jetson_devices[0]
    
    # Create and submit lease
    my_lease = lease.Lease("gpu-inference-lease", duration=datetime.timedelta(hours=3))
    my_lease.add_device_reservation(devices=[chosen_device])
    my_lease.submit(idempotent=True)
    ```

3. **Start a CUDA-capable Container**: Launch a container with the necessary dependencies for GPU-accelerated inference.

    ```python
    from chi import container
    
    # Define your container configuration
    cuda_container = container.Container(
        name="gpu-inference-container",
        image_ref="nvidia/cuda:12.0-base-ubuntu22.04",  # Example CUDA-capable image
        reservation_id=my_lease.device_reservations[0]["id"],
        runtime="nvidia",  # Specify the NVIDIA runtime for GPU access
        exposed_ports=[8888, 6006],  # Expose ports if needed (e.g., Jupyter notebook)
    )
    
    cuda_container.submit()
    ```

4. **SSH into Container**: SSH into the running container to perform your inference tasks.

    ```python
    from chi import context
    
    # Get floating IP and SSH into the container
    floating_ip = cuda_container.get_floating_ip()
    print(f"ssh -i ~/.ssh/id_rsa cc@{floating_ip}")
    
    # You can now use this command in a terminal to access your container.
    ```

5. **Run Inference**: Once inside the container, you can run your GPU-accelerated inference code.

6. **Cleanup**: After completing your experiment, delete the lease and container to free up resources for other users.

    ```python
    cuda_container.delete()
    my_lease.delete()
    ```

This process ensures that you have a Jetson-class device reserved on CHI@Edge with access to GPU-accelerated capabilities through a CUDA-capable container.
