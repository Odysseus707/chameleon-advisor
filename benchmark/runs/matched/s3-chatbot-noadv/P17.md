To capture a 1080p still from the Pi Camera Module 3 and download it using Chameleon Cloud's CHI@Edge, follow these steps:

### Step-by-Step Guide

#### 1. Choose Site and Project
First, ensure you are working with the correct site (CHI@Edge) and project.

```python
from chi import context

context.choose_site(default="CHI@Edge")
context.choose_project()
```

#### 2. Create a Lease for the Device
Identify an available device that has the Pi Camera Module attached, then create a lease for it.

```python
from chi import hardware, lease
from datetime import timedelta

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
display([d.device_name for d in picamera_devs])

my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)
```

#### 3. Launch a Container with the Required Dependencies
Launch a container that includes all necessary dependencies for using the Pi Camera Module.

```python
from chi import container

my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()
```

#### 4. Capture a Still Image
Use the `rpicam-still` utility to capture a still image.

```python
cmd = "rpicam-still --nopreview --output /app/test1.png --width 1920 --height 1080"
result, code = my_container.execute(cmd)
print(result)
```

#### 5. Download the Captured Image
Download the captured image from the container to your local machine.

```python
my_container.download("/app/test1.png", ".")
from IPython.display import Image
Image("test1.png", height=640, width=480)
```

### Cleanup

After you are done with the experiment, delete the lease and the container to free up resources.

```python
my_container.delete()
my_lease.delete()
```

This process will allow you to capture a 1080p still image from the Pi Camera Module using CHI@Edge and download it for further use.
