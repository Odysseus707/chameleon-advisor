To reserve one Raspberry Pi 4 on CHI@Edge for 2 hours, you can follow these steps using Python-chi:

1. Import chi and set up your context to use CHI@Edge:
```python
import chi

chi.context.use_site("CHI@Edge")
chi.context.choose_project()
```

2. Create a lease for the Raspberry Pi 4 device with a duration of 2 hours:
```python
from chi import lease
import os

# Define machine name and device name (replace 'device_name' with the actual device name)
machine_name = "raspberrypi4-64"
device_name = "<actual_device_name>"

username = os.environ.get("USER")
lease_name = f"{username}-{device_name}"
container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=2))
container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
container_lease.submit()
```

Replace `<actual_device_name>` with the specific name of the Raspberry Pi 4 device you wish to reserve. Note that in practice, you would need to know or find out the exact device name from the available devices on CHI@Edge.

This code will create a lease for one Raspberry Pi 4 device for a duration of 2 hours. Make sure you have the necessary permissions and resources (such as Service Units) allocated to your project in order to reserve the device successfully.
