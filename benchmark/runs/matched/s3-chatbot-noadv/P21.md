To launch a container with the Sense HAT enabled on Chameleon Cloud's CHI@Edge, follow these steps:

1. **Authenticate to CHI@Edge**: Use Python-CHI to authenticate and set up your environment.

    ```python
    import chi

    chi.context.use_site("CHI@Edge")
    chi.context.choose_project()
    ```

2. **Create a Lease for the Device**:
   
   Reserve a specific device that has the Sense HAT attached.
    
    ```python
    from chi import lease
    import os
    
    machine_name = "raspberrypi4-64"
    device_name = "iot-rpi-cm4-02"  # Replace with the correct device name for your setup

    username = os.environ.get("USER")
    lease_name = f"{username}-{device_name}"
    
    container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
    container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
    container_lease.submit()
    ```

3. **Launch a Container with the Sense HAT**:
   
   Use the appropriate image and specify the necessary device profiles to access the Sense HAT.

    ```python
    from chi import container

    container_name = "edge-waveshare-sensehat".replace("_", "-")
    
    environment_vars = {
        "RPI_LGPIO_REVISION": "0xd03140",
        "BLINKA_FORCECHIP": "BCM2XXX",
        "BLINKA_FORCEBOARD": "RASPBERRY_PI_CM4"
    }
    
    my_container = container.Container(
        name=container_name,
        image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
        device_profiles=["pi_gpio"],
        environment=environment_vars,
        reservation_id=container_lease.device_reservations[0]["id"],
        command=["-c", "sleep infinity"]
    )
    
    my_container.submit()
    ```

This setup will launch a container with the Sense HAT enabled, allowing you to interact with its sensors and other components. Make sure to replace `device_name` with the correct device name for your specific setup on CHI@Edge.
