To reserve 3 Raspberry Pis on CHI@Edge, you can use Python-chi to create a lease that includes multiple reservations for the same type of machine. Here is an example code snippet:

```python
from chi import lease

# Define the name and duration of your lease
lease_name = "my_lease"
duration_hours = 4

# Create a new lease object with the specified name and duration
container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=duration_hours))

# Specify the machine type (Raspberry Pi) and the number of devices you want to reserve
machine_type = "raspberrypi4-64"
amount_to_reserve = 3

# Add a device reservation for the specified machine type and amount
container_lease.add_device_reservation(amount=amount_to_reserve, machine_type=machine_type)

# Submit your lease request
container_lease.submit()

print("Done!")
```

This code will create a lease named `my_lease` that reserves 3 Raspberry Pi devices of the same type for 4 hours. Adjust the `duration_hours`, `machine_type`, and `amount_to_reserve` variables as needed to fit your specific requirements.
