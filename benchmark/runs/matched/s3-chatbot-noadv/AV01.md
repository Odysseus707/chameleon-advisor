To print the `device_name` of every available `raspberrypi4-64` device on CHI@Edge that is free to reserve right now, you can follow these steps:

1. Choose the site as CHI@Edge and select your project.
2. Get a list of devices with type `raspberrypi4-64`.
3. Filter out only those devices which are not reserved (i.e., available for reservation).
4. Print each device's name.

Here is how you can do it in Python using the Chameleon Cloud library:

```python
from chi import context, hardware

# Step 1: Choose CHI@Edge and your project
context.choose_site(default="CHI@Edge")
context.choose_project()

# Step 2: Get a list of available raspberrypi4-64 devices
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

# Step 3 and 4: Print the names of each available device
for device in available_devices:
    print(device.device_name)
```

This script will list all `raspberrypi4-64` devices that are currently free to reserve on CHI@Edge.
