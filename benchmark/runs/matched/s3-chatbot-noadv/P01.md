To target CHI@Edge and select your project using Python-CHI, follow these minimal setup steps:

1. **Install Python-CHI**: Ensure you have the `python-chi` library installed in your environment.

2. **Choose Site and Project**:
   - Import the necessary modules from `chi`.
   - Use `context.choose_site()` to target CHI@Edge.
   - Select your project using `context.choose_project()`.

Here is a minimal Python code snippet:

```python
from chi import context

# Choose the site (CHI@Edge)
context.choose_site(default="CHI@Edge")

# Choose your project
context.choose_project()
```

This setup will configure your environment to interact with resources on CHI@Edge under your specified Chameleon Cloud project.
