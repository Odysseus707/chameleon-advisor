To launch a Jupyter minimal-notebook container on an already active lease named 'serve-edge-vr' on a Raspberry Pi 5 and give it a public IP, follow these steps:

1. **Ensure you are in the correct project and site**:
   - Use the Chameleon Jupyter environment to run the following code snippet to ensure your context is set correctly for CHI@Edge.
   
   ```python
   from chi import container, context, lease
   import os
   import chi

   context.version = "1.0" 
   context.choose_project()
   context.choose_site(default="CHI@Edge")
   ```

2. **Get the active lease**:
   - Replace `serve-edge-vr` with your actual lease name in the following code snippet to retrieve and display details of your lease.
   
   ```python
   l = lease.get_lease("serve-edge-vr") 
   l.show()
   ```

3. **Launch a container on the edge device**:
   - Use the `container.Container` class to launch a Jupyter minimal-notebook container on the reserved Raspberry Pi 5, and associate it with a floating IP.
   
   ```python
   username = os.getenv('USER') # exp resources will have this suffix
   c = container.Container(
       name=f"node-serve-edge-{username}".replace('_', '-'),
       reservation_id=l.device_reservations[0]["id"],
       image_ref="quay.io/jupyter/minimal-notebook:latest", 
       exposed_ports=[8888]
   )
   c.submit(idempotent=True, wait_timeout=1200)
   c.associate_floating_ip()
   ```

4. **Retrieve the container logs to find the Jupyter token URL**:
   - After launching and associating a floating IP with your container, you can retrieve its logs to locate the Jupyter notebook's token URL.
   
   ```python
   print(chi.container.get_logs(c.id))
   ```
   
   Look for a line in the output that resembles `http://127.0.0.1:8888/lab?token=XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX`. Replace `127.0.0.1` with the floating IP address assigned to your container, which you noted earlier when associating the floating IP.

By following these steps, you will have launched a Jupyter minimal-notebook container on your Raspberry Pi 5 edge device and obtained the URL needed to access it from your browser.
