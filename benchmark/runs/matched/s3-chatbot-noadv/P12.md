To inject your public key so that you can SSH into a CHI@Edge container as root, follow these steps:

1. **Prepare Your Public Key**: Ensure you have an RSA public key ready to be used for SSH access.

2. **Create a Lease and Container**:
    - Select the Chameleon site `CHI@Edge`.
    - Create a lease with the desired duration.
    - Start a container using the Docker image that supports SSH (e.g., `ghcr.io/chameleoncloud/edge_ssh_image:latest`).

3. **Upload Public Key to Container**: Use the CHI Python library to upload your public key file into the container.

4. **Set Permissions and Append Key**:
    - Set appropriate permissions for the authorized keys file.
    - Append your public key to the `authorized_keys` file within the container.

5. **Associate Floating IP Address**: Obtain a floating IP address for the container so you can SSH into it from outside the network.

Here is an example of how these steps might look in code:

```python
import chi

# Select CHI@Edge site and set project name
chi.use_site("CHI@Edge")
chi.set("project_name", "Chameleon")

from chi import container, lease

# Create a 1-day lease for a Raspberry Pi 4 device
machine_name = "raspberrypi4-64"
start, end = lease.lease_duration(days=1)
lease_name = f"ssh-{machine_name}-{start}"
reservations = []
lease.add_device_reservation(reservations, count=2, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]
print(f"created lease with name {lease_name} and uuid {lease_id}, waiting for it to start.")
lease.wait_for_active(lease_id)

# Start the container
container_name = f"tutorial-{machine_name}-ssh".replace("_","-")
my_container = container.create_container(
    container_name,
    image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
    workdir="/home",
    exposed_ports=[22],
    reservation_id=lease.get_device_reservation(lease_id),
    platform_version=2
)

# Upload your public key to the container and set permissions
chi.container.upload(my_container.uuid, "./path/to/your/public_key", "/root/.ssh/")
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)
cmd = "/bin/bash -c \"cat /root/.ssh/your_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Associate floating IP address
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print(f"Use the following command to SSH into the container: ssh root@{ip_address}")
```

Replace `./path/to/your/public_key` with the path to your RSA public key file and ensure that the filename matches what you use in the script.

By following these steps, you will be able to inject your public key into a CHI@Edge container and SSH into it as root.
