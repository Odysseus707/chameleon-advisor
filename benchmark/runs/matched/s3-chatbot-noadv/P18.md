To record a 5-second 1080p video from the camera on CHI@Edge, follow these steps:

1. **Choose the Site and Project:**
   ```python
   from chi import context

   context.choose_site(default="CHI@Edge")
   context.choose_project()
   ```

2. **Create a Lease for the Device with Camera:**
   - Identify devices that have the camera attached.
   - Make a lease for one of these devices.

   ```python
   from chi import hardware, lease
   from datetime import timedelta

   device_type = "raspberrypi4-64"
   available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

   picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
   
   my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
   my_lease.add_device_reservation(devices=[picamera_devs[0]])
   my_lease.submit(idempotent=True)
   ```

3. **Launch a Container with the Required Dependencies:**
   - Use the prebuilt container image `ghcr.io/chameleoncloud/edge-picamera-image:latest` and ensure it has access to the necessary device profiles.

   ```python
   from chi import container

   my_container = container.Container(
       "rpi4-camera-test-01",
       image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
       exposed_ports=[],
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"],
       device_profiles=["pi_libcamera"],
   )
   my_container.submit()
   ```

4. **Capture the Video Using `rpicam-vid`:**
   - Use the `rpicam-vid` utility to capture a 5-second video at 1080p resolution and 30 fps.

   ```python
   cmd = "rpicam-vid --nopreview -t 5000 --output /app/video1.mp4 --width 1920 --height 1080 --framerate 30"
   result, code = my_container.execute(cmd)
   print(result)
   ```

5. **Download the Video:**
   - Download the captured video from the container to your local machine.

   ```python
   my_container.download("/app/video1.mp4", ".")
   ```

6. **Cleanup:**
   - Delete the lease and container once you are done with the experiment.

   ```python
   my_container.delete()
   my_lease.delete()
   ```

This process will allow you to record a 5-second video at 1080p resolution using the camera on CHI@Edge.
