To make your container stay running so you can exec into it later, you need to ensure that the container has a long-running process. In the provided context, this is achieved by using a command like `sleep infinity` which keeps the container alive indefinitely.

Here's how you can modify or create a container with such a command:

```python
from chi import container

my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],  # This keeps the container running
    device_profiles=["pi_libcamera"],
)
my_container.submit()
```

This will launch a container that stays alive, allowing you to exec into it later for further interaction.
