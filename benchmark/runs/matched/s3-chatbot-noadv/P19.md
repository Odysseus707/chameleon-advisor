To verify that the camera is detected inside the container, you can run a simple command within the container. This command will check if libcamera finds the attached camera module. Here's how to do it:

1. Ensure your container has been launched with the `pi_libcamera` device profile, which exposes all necessary `/dev` devices required for camera support.

2. Run the following command inside the container:
   ```python
   cmd = "rpicam-hello --nopreview --list-cameras"
   result, code = my_container.execute(cmd)
   print(result)
   ```

This command will list available cameras if they are detected by libcamera. If everything is set up correctly and the camera is attached to your device, this command should return information about the connected camera module.

If you encounter any issues or errors, it might be due to missing permissions, incorrect configuration in `/boot/config.txt`, or an outdated OS version that does not support auto-detection of the Pi Camera Module 3.
