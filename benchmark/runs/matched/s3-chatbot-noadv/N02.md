To record a 10-second 720p video at 30 fps from the Pi camera and download it to your machine using Chameleon Cloud's CHI@Edge, follow these steps:

### Step-by-Step Guide

#### 1. Choose the Site and Project
First, ensure you are working with the correct site (CHI@Edge) and project.

```python
from chi import context

context.choose_site(default="CHI@Edge")
context.choose_project()
```

#### 2. Create a Lease for the Device
Identify an available device that has the Pi Camera Module attached, then create a lease for it.

```python
from chi import hardware, lease
from datetime import timedelta

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
display([d.device_name for d in picamera_devs])

my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)
```

#### 3. Launch a Container with the Required Dependencies
Launch a container that includes the necessary dependencies for using the Pi Camera Module.

```python
from chi import container

my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()
```

#### 4. Capture the Video
Use `rpicam-vid` to capture a 10-second video at 720p resolution and 30 fps.

```python
cmd = "rpicam-vid --nopreview -t 10000 --output /app/video1.mp4 --width 1280 --height 720 --framerate 30"
result, code = my_container.execute(cmd)
print(result)
```

#### 5. Download the Video
Download the captured video from the container to your local machine.

```python
my_container.download("/app/video1.mp4", ".")
```

### Cleanup

Once you are done with the experiment, clean up by deleting the lease and the container.

```python
my_container.delete()
my_lease.delete()
```

This process will allow you to capture a 720p video at 30 fps from the Pi Camera Module attached to a Raspberry Pi device in CHI@Edge and download it to your local machine.
