Based on the provided documentation, here are the available Sense HAT devices for reading temperature and humidity:

1. **Raspberry Pi Sense Hat** - This is a well-documented sensor that can be used to capture both temperature and humidity data using the `sense-hat` library in Python.

2. **Waveshare Sense Hat (B)** - Another option, which includes sensors for temperature and humidity as well as other environmental measurements. It requires specific dependencies like `adafruit-blinka`, `rpi-lgpio`, and CircuitPython libraries to interact with the sensors.

To reserve a device for about 3 hours on CHI@Edge, here are my top three recommendations:

1. **iot-rpi4-picam2** - This is a Raspberry Pi 4 device that can be used with the RPi Sense Hat. It's well-supported and has clear documentation for setting up and using the sensors.
   
   *Justification*: The RPi Sense Hat is straightforward to use with Python libraries, making it easy to get started quickly.

2. **iot-rpi4-picam3** - Another Raspberry Pi 4 device that can be used similarly to `iot-rpi4-picam2`.

   *Justification*: This option provides redundancy and ensures you have a backup if the first device is unavailable.

   *Justification*: The Waveshare Sense Hat offers a broader range of sensor capabilities if you need more than just temperature and humidity data in future experiments.
