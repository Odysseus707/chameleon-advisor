To launch an Ollama container on a GPU-capable device with your active CHI@Edge lease named 'my-llm-lease', follow these steps:

1. **Ensure you have access to JupyterHub**: Since the instructions involve using notebooks, ensure that you are logged into Chameleon's JupyterHub environment.

2. **Open `start_edge_llm.ipynb` Notebook**:
   - Open the notebook named `start_edge_llm.ipynb`. This notebook is designed for deploying LLMs on edge devices (CHI@Edge).

3. **Set Up Lease and Container Configuration**:

    ```python
    from chi import container, context, lease
    import os

    # Set up Chameleon environment
    context.version = "1.0" 
    context.choose_project()
    context.choose_site(default="CHI@Edge")

    # Use the existing lease name
    l = lease.get_lease("my-llm-lease")  # Specify your lease name here

    username = os.getenv('USER')  # This will be used as a suffix for resource names
    c = container.Container(
        name=f"ollama-container-{username}",  # Container name with unique identifier
        reservation_id=l.device_reservations[0]["id"],
        image_ref="docker.io/ollama/ollama:latest", 
        runtime="nvidia",
        exposed_ports=[11434],  # Expose only the Ollama API port
    )
    c.submit(idempotent=True)
    ```

4. **Associate Floating IP**:
   - To make your container accessible from outside, associate a floating IP with it.

    ```python
    c.associate_floating_ip()
    ```

5. **Run the Container**:

    After associating the floating IP and ensuring that the container is running on the GPU-capable device, you can run the Ollama container by executing commands inside the container if necessary (e.g., starting a specific model).

6. **Accessing the API**:
   - Once the container is up and running with the associated public IP, you should be able to access the Ollama API on port 11434 using the floating IP address.

Remember that all these steps are performed within the Jupyter notebook environment provided by Chameleon Cloud. Ensure that your lease has sufficient resources allocated for GPU usage and that the container is properly configured with the necessary runtime settings (e.g., `runtime="nvidia"`).
