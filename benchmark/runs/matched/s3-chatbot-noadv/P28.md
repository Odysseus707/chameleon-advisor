To convert a script that creates bare-metal instances on CHI@UC to run containers on CHI@Edge, follow these steps:

1. **Switch to CHI@Edge**: First, you need to switch your environment from CHI@UC (which uses bare metal) to CHI@Edge (which uses Kubernetes for container orchestration).

2. **Create a Lease**: Instead of reserving nodes directly, create a lease on CHI@Edge that reserves the necessary resources.

3. **Launch Containers**: Use the `chi.container.create_container` method to launch containers instead of creating servers.

Here is an example script based on your requirements:

```python
import chi

# Switch to CHI@Edge site
chi.use_site("CHI@Edge")

# Set project name (if needed)
chi.set("project_name", "Chameleon")

from chi import container, lease

# Define the machine type and lease duration for CHI@Edge
machine_name = "raspberrypi4-64"  # Example device type on CHI@Edge
start, end = lease.lease_duration(days=1)  # Duration of the lease

# Create a unique name for the lease
lease_name = f"ssh-{machine_name}-{start}"

reservations = []
lease.add_device_reservation(reservations, count=2, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]

print(f"Created lease with name {lease_name} and uuid {lease_id}, waiting for it to start. This can take up to 60s.")
lease.wait_for_active(lease_id)
print("Done!")

# Create a container
container_name = f"tutorial-{machine_name}-ssh".replace("_","-")

try:
    my_container = container.create_container(
        container_name,
        image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
        workdir="/home",
        exposed_ports=[22],
        reservation_id=lease.get_device_reservation(lease_id),
        platform_version=2,
    )
except RuntimeError as ex:
    print(ex)
    print(f"Please stop and/or delete {container_name} and try again")
else:
    print(f"Successfully created container: {container_name}!")

# Add your public key to the authorized keys within the container
chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)
cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Get the floating IP address for SSH access
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print("Use the following command to ssh into the container: ssh root@" + ip_address)

# Destroying the container after use (optional but recommended)
# chi.container.destroy_container(my_container.uuid)
```

This script switches from bare-metal node reservation and server creation on CHI@UC to creating a lease and launching containers on CHI@Edge. It also sets up SSH access for the container, similar to how you would set up SSH keys for a bare-metal instance.

Remember to replace `"raspberrypi4-64"` with the appropriate device type available in your CHI@Edge environment and ensure that `edge_user_public_key` contains your RSA public key.
