To read temperature, humidity, and pressure from the Sense HAT on Chameleon Cloud's CHI@Edge, you can follow these steps:

1. **Authenticate to CHI@Edge**: Use Python-CHI to authenticate your session.

2. **Create a Lease for the Device**: Reserve a specific device that has the Sense Hat attached.

3. **Launch a Container with Required Libraries**:
   - For the Raspberry Pi Sense HAT, use an image that includes the `sense-hat` library.
   - For the Waveshare Sense HAT (B), use an image that includes Adafruit Blinka and CircuitPython libraries for interacting with sensors.

4. **Access Sensors**: Use Python scripts to read sensor data from the Sense Hat.

Here is a step-by-step example using the RPi Official Sense Hat:

### Step 1: Authenticate
```python
import chi

chi.context.use_site("CHI@Edge")
chi.context.choose_project()
```

### Step 2: Create a Lease for the Device
```python
from chi import lease
import os

machine_name = "raspberrypi4-64"
device_name = "iot-rpi4-picam3" # RPI sense hat device name

username = os.environ.get("USER")
lease_name = f"{username}-{device_name}"
container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
container_lease.submit()
```

### Step 3: Launch a Container
```python
from chi import container

container_name = "edge-rpi-sensehat".replace("_", "-")
environment_vars = {}

my_container = container.Container(
    name=container_name,
    image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
    device_profiles=["pi_sensehat"],
    environment=environment_vars,
    reservation_id=container_lease.device_reservations[0]["id"],
    command=["-c", "sleep infinity"]
)
my_container.submit()
```

### Step 4: Access Sensors
```python
cmd_str = """
from sense_hat import SenseHat

sense = SenseHat()
sense.clear()

pressure = sense.get_pressure()
temperature_pressure = sense.get_temperature_from_pressure()
humidity = sense.get_humidity()
temperature_humidity = sense.get_temperature_from_humidity()

print(
    "Pressure: {:.1f} mbar, Temperature (from pres): {:.1f} C,  Relative Humidity: {:.1f} %, Temperature (from hum): {:.1f} C".format(
        pressure, temperature_pressure, humidity, temperature_humidity
    )
)
"""

stdout, resultcode = my_container.execute(f"python3 -c '{cmd_str}'")
print(stdout)
```

This script will print out the readings from the Sense Hat's sensors. Make sure to clean up by deleting the container and lease when you're done:

```python
my_container.delete()
container_lease.delete()
```

For the Waveshare Sense HAT (B), follow similar steps but use the appropriate image and libraries as specified in the documentation for that specific device.
