To expose port `8080` on a CHI@Edge container and give it a public IP address, follow these steps:

1. **Create a Lease**: First, create a lease for your device as shown in the tutorial.

2. **Start the Container with Exposed Port 8080**:
   - When creating the container using `chi.container.create_container`, specify that port `8080` should be exposed.
   
   ```python
   my_container = container.create_container(
       container_name,
       image="your_image",
       workdir="/home",
       exposed_ports=[22, 8080], # Expose both SSH and your desired port
       reservation_id=lease.get_device_reservation(lease_id),
       platform_version=2,
   )
   ```

3. **Associate a Floating IP**:
   - After the container is created, associate a floating IP to it so that you can access it from outside.

   ```python
   ip_address = chi.container.associate_floating_ip(my_container.uuid)
   print(f"Container accessible at: {ip_address}")
   ```

By following these steps, your CHI@Edge container will have port `8080` exposed and a public IP address associated with it for external access.
