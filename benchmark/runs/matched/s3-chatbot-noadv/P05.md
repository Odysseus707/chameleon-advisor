To launch a basic Ubuntu container on a reserved Raspberry Pi device on CHI@Edge, follow these steps:

1. **Choose the Site**: Ensure you are working with the `CHI@Edge` site.

2. **Create a Lease for the Device**:
   - Identify and reserve a Raspberry Pi 4 device that has the camera module attached.
   
3. **Launch the Container**:
   - Use the Python CHI library to launch a container image of your choice (e.g., Ubuntu) on the reserved device.

Here is an example code snippet demonstrating these steps:

```python
from chi import context, hardware, lease, container

# Step 1: Choose the site and project
context.choose_site(default="CHI@Edge")
context.choose_project()

# Step 2: Create a Lease for the Device
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
display([d.device_name for d in picamera_devs])

my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

# Step 3: Launch the Container
ubuntu_container = container.Container(
    "basic-ubuntu-container",
    image_ref="ubuntu:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
)
ubuntu_container.submit()
```

This code will:
1. Set up your environment to work with `CHI@Edge`.
2. Reserve a Raspberry Pi 4 device that has the camera module attached.
3. Launch an Ubuntu container on the reserved device.

Make sure you have the necessary permissions and resources available in your project for these operations.
