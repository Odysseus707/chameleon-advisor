To check whether a given device is free right now before reserving it on CHI@Edge, you would typically use the Chameleon Cloud's API or command-line tools provided by Python-CHI. Based on the context provided, here’s how you can do this programmatically:

1. **Import Necessary Libraries**: Import the `chi` library which provides programmatic interaction with Chameleon resources.

2. **Choose Site and Project**: Use the `context.choose_site()` function to select CHI@Edge as your site and `context.choose_project()` to specify your project.

3. **Get Available Devices**: Utilize the `hardware.get_devices()` method to list available devices, filtering by device type if necessary. This will give you a list of devices that are currently free (not reserved).

Here is an example code snippet:

```python
from chi import context, hardware

# Choose CHI@Edge as your site and select your project
context.choose_site(default="CHI@Edge")
context.choose_project()

# Get available devices. You can filter by device type if needed.
available_devices = hardware.get_devices(filter_reserved=True)

# Print the names of available devices
for device in available_devices:
    print(device.device_name)
```

This code will list all currently free devices on CHI@Edge, allowing you to check availability before making a reservation.
