To get a Raspberry Pi on CHI@Edge that you can access with VS Code Remote-SSH, follow these steps:

1. **Login to Chameleon Cloud**:
   - Go to https://chi.edge.chameleoncloud.org and log in using your credentials or federated login.

2. **Set Up Your Environment**:
   - Ensure you have the `python-chi` library installed. You can install it via pip if necessary: 
     ```bash
     pip install python-chi
     ```

3. **Create a Lease for Raspberry Pi 4 Device**:
   - Use Python to create a lease and reserve a Raspberry Pi 4 device.
   
   ```python
   import chi

   # Select the CHI@Edge site
   chi.use_site("CHI@Edge")

   # Set your project name (replace with your actual project name)
   chi.set("project_name", "YourProjectName")

   from chi import lease, container

   machine_name = "raspberrypi4-64"
   start, end = lease.lease_duration(days=1)  # Create a 1-day lease
   lease_name = f"ssh-{machine_name}-{start}"
   
   reservations = []
   lease.add_device_reservation(reservations, count=2, machine_name=machine_name)
   container_lease = lease.create_lease(lease_name, reservations)
   lease_id = container_lease["id"]

   print(f"Created lease with name {lease_name} and uuid {lease_id}, waiting for it to start. This can take up to 60s.")
   lease.wait_for_active(lease_id)
   print("Done!")
   ```

4. **Start the Container**:
   - Use a Docker image that has SSH enabled, such as `ghcr.io/chameleoncloud/edge_ssh_image:latest`.

   ```python
   container_name = f"tutorial-{machine_name}-ssh".replace("_","-")

   try:
       my_container = container.create_container(
           container_name,
           image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
           workdir="/home",
           exposed_ports=[22],
           reservation_id=lease.get_device_reservation(lease_id),
           platform_version=2,
       )
   except RuntimeError as ex:
       print(ex)
       print(f"Please stop and/or delete {container_name} and try again")
   else:
       print(f"Successfully created container: {container_name}!")
   ```

5. **Add Your Public Key to the Container**:
   - Upload your RSA public key to the container's authorized keys file.

   ```python
   chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")
   
   cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
   chi.container.execute(my_container.uuid, cmd)
   
   cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
   chi.container.execute(my_container.uuid, cmd)
   ```

6. **Associate Floating IP and SSH into the Container**:
   - Get the floating IP address for your container.

   ```python
   ip_address = chi.container.associate_floating_ip(my_container.uuid)

   print("Use the following command to ssh into the container: ssh root@" + ip_address)
   ```

7. **Configure VS Code Remote-SSH**:
   - In VS Code, install the Remote-SSH extension.
   - Add your Raspberry Pi 4 device's IP address and SSH credentials in the `~/.ssh/config` file.

   ```plaintext
   Host chameleon-pi
       HostName <ip_address>
       User root
       IdentityFile ~/.ssh/id_rsa
   ```

8. **Connect to Your Container**:
   - Use VS Code Remote-SSH to connect to your container by selecting the `chameleon-pi` host.

9. **Destroy the Container After Use**:
   - Once you're done, destroy the container to free up resources.

   ```python
   chi.container.destroy_container(my_container.uuid)
   ```

By following these steps, you will have a Raspberry Pi 4 device on CHI@Edge that is accessible via SSH from VS Code.
