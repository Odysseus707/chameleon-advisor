To launch a basic Ubuntu container on a reserved Raspberry Pi 4 device on CHI@Edge, follow these steps:

1. **Choose the Site and Project**:
   Ensure you are working with the correct Chameleon site (CHI@Edge) and project.

   ```python
   from chi import context

   context.choose_site(default="CHI@Edge")
   context.choose_project()
   ```

2. **Find Available Devices**:
   Identify available Raspberry Pi 4 devices that can be reserved for your experiment.

   ```python
   from chi import hardware

   device_type = "raspberrypi4-64"
   available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

   picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
   display([d.device_name for d in picamera_devs])
   ```

3. **Create a Lease**:
   Reserve one of the identified devices for your experiment.

   ```python
   from chi import lease
   from datetime import timedelta

   my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
   my_lease.add_device_reservation(devices=[picamera_devs[0]])
   my_lease.submit(idempotent=True)
   ```

4. **Launch a Container**:
   Launch a container with the desired image (Ubuntu in this case) on the reserved device.

   ```python
   from chi import container

   # Replace 'ubuntu:latest' with your specific Ubuntu version if needed.
   my_container = container.Container(
       "rpi4-ubuntu-test",
       image_ref="ubuntu:latest",
       exposed_ports=[],
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"]
   )
   my_container.submit()
   ```

5. **Verify the Container**:
   Ensure that the container is running and accessible.

6. **Cleanup**:
   After your experiment, delete the lease and container to free up resources for others.

   ```python
   my_container.delete()
   my_lease.delete()
   ```

This process will allow you to launch a basic Ubuntu container on a reserved Raspberry Pi 4 device in CHI@Edge.
