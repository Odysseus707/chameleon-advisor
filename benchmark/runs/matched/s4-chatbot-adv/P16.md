To launch a container with the Pi camera enabled on CHI@Edge, follow these steps:

1. **Choose the Site and Project**:
   ```python
   from chi import context

   context.choose_site(default="CHI@Edge")
   context.choose_project()
   ```

2. **Create a Lease for the Device**:
   - Identify devices with the Pi Camera Module attached.
   - Make a lease for one of these devices.

   ```python
   from chi import hardware, lease
   from datetime import timedelta

   device_type = "raspberrypi4-64"
   available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

   picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
   
   my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
   my_lease.add_device_reservation(devices=[picamera_devs[0]])
   my_lease.submit(idempotent=True)
   ```

3. **Launch a Container with the Pi Camera Enabled**:
   - Use the `ghcr.io/chameleoncloud/edge-picamera-image:latest` image.
   - Ensure the container has access to the necessary device profiles (`pi_libcamera`).

   ```python
   from chi import container

   my_container = container.Container(
       "rpi4-camera-test-01",
       image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
       exposed_ports=[],
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"],
       device_profiles=["pi_libcamera"],
   )
   my_container.submit()
   ```

4. **Verify Camera Functionality**:
   - Run a simple command to check if the camera is detected.

   ```python
   cmd = "rpicam-hello --nopreview --list-cameras"
   result, code = my_container.execute(cmd)
   print(result)
   ```

5. **Capture an Image or Video** (Optional):
   - Use `rpicam-still` to capture a still image.
   - Use `rpicam-vid` to record video.

6. **Cleanup**:
   - Delete the container and lease when done.

   ```python
   my_container.delete()
   my_lease.delete()
   ```

This process ensures that you have access to the Pi Camera Module on a Raspberry Pi 4 device in CHI@Edge, with all necessary dependencies and device profiles configured.
