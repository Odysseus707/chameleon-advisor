To capture a photo with the Pi camera and classify it using the quantized MobileNet TFLite model inside the same container, follow these steps:

1. **Provision Resources**:
   - Reserve an edge device (Raspberry Pi 4) on CHI@Edge.
   - Launch a container with the `ghcr.io/chameleoncloud/edge-picamera-image:latest` image.

2. **Capture Photo**:
   - Use the `rpicam-still` command to capture a photo and save it in the container's filesystem.

3. **Install Dependencies for Model Inference**:
   - Install necessary Python libraries (`tflite-runtime`, `Pillow`) inside the container.
   
4. **Upload Model Files**:
   - Upload your pre-trained model, labels file, and any test images to the container.

5. **Run Inference**:
   - Use the provided script or a similar one to run inference on the captured image using the quantized MobileNet TFLite model.

Here is how you can do it step-by-step:

### Step 1: Provision Resources

```python
import chi
from chi import lease, container

chi.use_site("CHI@Edge")
chi.set("project_name", os.getenv('OS_PROJECT_NAME'))

device_type = "raspberrypi4-64"
available_devices = chi.hardware.get_devices(filter_reserved=True, device_type=device_type)
picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]

my_lease = lease.Lease("rpi4-camera-lease", duration=datetime.timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

container_image = "ghcr.io/chameleoncloud/edge-picamera-image:latest"
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref=container_image,
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()
```

### Step 2: Capture Photo

```python
cmd = "rpicam-still --nopreview --output /app/test1.png --width 1920 --height 1080"
result, code = my_container.execute(cmd)
print(result)
```

### Step 3: Install Dependencies for Model Inference

```python
container.execute(my_container.uuid, 'pip install tflite-runtime Pillow')
```

### Step 4: Upload Model Files

Upload your model files (model file, labels file) and the captured image to the container:

```python
# Assuming you have these files in a local directory named `image_model`
local_image_model_dir = "./image_model"
container.upload(my_container.uuid, local_image_model_dir, "/root/")
```

### Step 5: Run Inference

Run inference on the captured image using the provided script or similar:

```python
cmd = 'python /root/image_model/model.py --model mobilenet_v2_1.0_224_quantized_1_default_1.tflite --label imagenet_labels.txt --image test1.png'
result, code = my_container.execute(cmd)
print(result['output'])
```

This will capture a photo with the Pi camera and classify it using the quantized MobileNet TFLite model inside the same container.
