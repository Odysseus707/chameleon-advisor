To reserve the Waveshare Sense HAT (B) attached to `iot-rpi-cm4-02` and launch a container configured for GPIO libraries despite missing devicetree info inside containers, follow these steps:

1. **Authenticate to CHI@Edge**:
   ```python
   import chi

   chi.context.use_site("CHI@Edge")
   chi.context.choose_project()  # Comment this line if running outside of JupyterHub.
   ```

2. **Create a Lease for the Device**:
   ```python
   from chi import lease
   import os

   machine_name = "raspberrypi4-64"
   device_name = "iot-rpi-cm4-02"  # Waveshare Sense Hat

   username = os.environ.get("USER")
   lease_name = f"{username}-{device_name}"
   
   container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
   container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
   container_lease.submit()
   print("Done!")
   ```

3. **Launch a Container with Required Environment Variables**:
   ```python
   from chi import container

   container_name = "edge-waveshare-sensehat".replace("_", "-")

   environment_vars = {
       "RPI_LGPIO_REVISION": "0xd03140",
       "BLINKA_FORCECHIP": "BCM2XXX",
       "BLINKA_FORCEBOARD": "RASPBERRY_PI_CM4"
   }

   my_container = container.Container(
       name=container_name,
       image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
       device_profiles=["pi_gpio"],
       environment=environment_vars,
       reservation_id=container_lease.device_reservations[0]["id"],
       command=["-c", "sleep infinity"]
   )
   my_container.submit()
   ```

4. **Display the I2C Sensor Map**:
   ```python
   result, code = my_container.execute("i2cdetect -y 1")
   print(result)
   ```

This will authenticate to CHI@Edge, create a lease for the specified device with the Waveshare Sense HAT (B), launch a container configured with necessary environment variables to work around missing devicetree info inside containers, and display the I2C sensor map.
