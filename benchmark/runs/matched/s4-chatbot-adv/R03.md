To get an interactive SSH shell on an edge device on CHI@Edge for about 2 hours, you can follow these steps:

1. **Select and Reserve a Device**: Choose one of the following devices based on your needs:
   - **raspberrypi4-64**: This is a versatile ARM-based device with good performance for general-purpose computing tasks.
   - **jetson-nano**: Offers better GPU capabilities if you need to run inference or other compute-intensive tasks that benefit from GPU acceleration.
   - **rockpi-4a**: Provides another ARM-based option, suitable for tasks requiring more memory and storage.

2. **Create a Lease**: Create a 2-hour lease for the chosen device type using the Chameleon Cloud interface or via the Python CHI library.

3. **Start a Container**: Use the provided Docker image (`ghcr.io/chameleoncloud/edge_ssh_image:latest`) to start a container on the reserved device.

4. **Upload SSH Key**: Upload your public RSA key to the authorized keys file within the running container.

5. **Associate Floating IP and SSH In**: Associate a floating IP address with the container and use `ssh root@<ip_address>` to connect to it.

Here are the top 3 device types for reservation, in order of preference:
1. **raspberrypi4-64**: Best suited for general-purpose tasks due to its balanced performance.
2. **jetson-nano**: Ideal if you need GPU acceleration for inference or other compute-intensive tasks.
3. **rockpi-4a**: A good alternative ARM-based device with more memory and storage options.

These steps will allow you to get an interactive SSH shell on a CHI@Edge device efficiently.
