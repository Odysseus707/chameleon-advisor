To convert your CHI@UC bare-metal script to run on CHI@Edge, you need to adapt it to use containers and Kubernetes instead of bare metal instances. Here's a step-by-step guide:

1. **Set Up Environment**:
   - Import necessary modules from `chi`.
   - Select the appropriate Chameleon site (`CHI@Edge`).

2. **Create Lease**:
   - Define the lease duration.
   - Add device reservations for CHI@Edge devices.

3. **Start Container**:
   - Use a Docker image that is compatible with CHI@Edge (e.g., `ghcr.io/chameleoncloud/edge_ssh_image:latest`).
   - Expose necessary ports (e.g., SSH port 22).

4. **Upload Public Key and Configure SSH Access**:
   - Upload your public key to the container.
   - Set appropriate permissions for the authorized keys file.

5. **SSH into Container**:
   - Associate a floating IP address with the container.
   - Use the provided IP address to SSH into the container.

6. **Destroy Container** (Optional):
   - Clean up resources by destroying the container after use.

Here is an example script that follows these steps:

```python
import chi

# Step 1: Set Up Environment
chi.use_site("CHI@Edge")

# Step 2: Create Lease
machine_name = "raspberrypi4-64"
start, end = lease.lease_duration(hours=3)  # Adjust duration as needed
lease_name = f"ssh-{machine_name}-{start}"
reservations = []
lease.add_device_reservation(reservations, count=1, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]
print(f"Created lease with name {lease_name} and uuid {lease_id}, waiting for it to start.")
lease.wait_for_active(lease_id)
print("Done!")

# Step 3: Start Container
container_name = f"tutorial-{machine_name}-ssh".replace("_", "-")
try:
    my_container = container.create_container(
        container_name,
        image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
        workdir="/home",
        exposed_ports=[22],
        reservation_id=lease.get_device_reservation(lease_id),
        platform_version=2,
    )
except RuntimeError as ex:
    print(ex)
    print(f"Please stop and/or delete {container_name} and try again")
else:
    print(f"Successfully created container: {container_name}!")

# Step 4: Upload Public Key and Configure SSH Access
chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)
cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Step 5: SSH into Container
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print("Use the following command to ssh into the container: ssh root@" + ip_address)

# Step 6: Destroy Container (Optional)
# chi.container.destroy_container(my_container.uuid)
```

This script sets up a lease, starts a container with SSH access, and provides instructions for SSHing into the container. Adjust the lease duration and other parameters as needed for your specific use case.
