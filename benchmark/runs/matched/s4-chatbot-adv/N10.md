To reserve and launch a container that can access both the camera module and the Sense HAT attached to the `iot-rpi4-picam3` device, follow these steps:

1. **Authenticate and Choose Project**:
   ```python
   import chi

   chi.context.use_site("CHI@Edge")
   chi.context.choose_project()
   ```

2. **Create a Lease for the Device**:
   Reserve `iot-rpi4-picam3` with the appropriate device type.
   ```python
   from chi import lease, hardware
   import os

   # Define machine name and username
   machine_name = "raspberrypi4-64"
   username = os.environ.get("USER")

   # Get available devices
   available_devices = hardware.get_devices(filter_reserved=True, device_type=machine_name)

   # Filter for the specific device with Sense HAT and camera module
   picamera_devs = [d for d in available_devices if d.device_name == "iot-rpi4-picam3"]

   # Create a lease name based on username and device name
   lease_name = f"{username}-sensehat-camera-lease"

   # Define the lease duration (e.g., 3 hours)
   container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=3))
   
   # Add reservation for the specific device
   container_lease.add_device_reservation(
       amount=1,
       machine_type=machine_name,
       device_name="iot-rpi4-picam3"
   )
   
   # Submit the lease request
   container_lease.submit()
   ```

3. **Launch a Container with Required Device Profiles and Dependencies**:
   Use an image that supports both libcamera for camera access and sense-hat libraries.
   ```python
   from chi import container

   # Define container name (ensure underscores are replaced)
   container_name = "edge-sensehat-camera".replace("_", "-")

   # Environment variables if needed
   environment_vars = {
       "RPI_LGPIO_REVISION": "0xd03140",
       "BLINKA_FORCECHIP": "BCM2XXX",
       "BLINKA_FORCEBOARD": "RASPBERRY_PI_CM4"
   }

   my_container = container.Container(
       name=container_name,
       image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",  # Use the appropriate image
       device_profiles=["pi_libcamera", "pi_gpio"],  # Include both profiles for camera and GPIO access
       environment=environment_vars,
       reservation_id=container_lease.device_reservations[0]["id"],
       command=["-c", "sleep infinity"]
   )
   
   my_container.submit()
   ```

4. **Verify Camera Access**:
   Run a simple command to list cameras.
   ```python
   cmd = "rpicam-hello --nopreview --list-cameras"
   result, code = my_container.execute(cmd)
   print(result)
   ```

5. **Probe the I2C Bus for Sensors**:
   Use `i2cdetect` to verify that sensors are detected.
   ```python
   cmd = "i2cdetect -y 1"
   result, code = my_container.execute(cmd)
   print(result)
   ```

6. **Cleanup**:
   Delete the container and lease when done.
   ```python
   my_container.delete()
   container_lease.delete()
   ```

This setup ensures that you have a container running on `iot-rpi4-picam3` with access to both the camera module and the Sense HAT, allowing you to interact with both peripherals as needed.
