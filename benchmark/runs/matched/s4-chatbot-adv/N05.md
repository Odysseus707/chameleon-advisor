To launch an Ollama container on your existing CHI@Edge lease named 'my-llm-lease' with GPU support, expose only the Ollama API port (11434), and give it a public IP address, follow these steps:

### Step 1: Import Required Libraries

Ensure you have access to the necessary libraries in your Jupyter notebook environment.

```python
from chi import container, context, lease
import os
```

### Step 2: Set Up Context and Lease

Set up the Chameleon Cloud context and retrieve the existing lease named 'my-llm-lease'.

```python
context.version = "1.0" 
context.choose_project()
context.choose_site(default="CHI@Edge")

# Use the lease name that was specified
l = lease.get_lease("my-llm-lease")  # Specify the lease name
```

### Step 3: Create and Submit Container

Create a container with GPU support, expose port 11434 for the Ollama API, and associate it with the lease.

```python
username = os.getenv('USER')  # exp resources will have this suffix
c = container.Container(
    name=f"ollama-container-{username}",  # The container name can only have alphanumeric and '-' in it!
    reservation_id=l.device_reservations[0]["id"],
    image_ref="docker.io/ollama/ollama:latest", 
    runtime="nvidia",
    exposed_ports=[11434],  # Expose the Ollama API port
)
c.submit(idempotent=True)  # Submit the container for creation
```

### Step 4: Associate Floating IP

Associate a floating (public) IP address with the container to make it accessible over the internet.

```python
c.associate_floating_ip()
```

### Step 5: Verify and Access Container

Once the container is up and running, you can verify its status and access it via SSH or through the exposed port for the Ollama API.

To check if the container has been successfully created and to get the floating IP address:

```python
c.show()
```

This will display details about your container including the assigned floating IP address. You can use this IP along with the exposed port (11434) to access the Ollama service running inside the container.

### Step 6: Clean Up

When you are done, remember to delete the resources to free up Chameleon Cloud for other users:

```python
c.delete()
l.delete()
```

This will remove both the container and the lease from your project.
