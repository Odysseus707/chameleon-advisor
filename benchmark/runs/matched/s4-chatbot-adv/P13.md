For SSH on CHI@Edge, you need to use the Docker image `ghcr.io/chameleoncloud/edge_ssh_image:latest` and expose port 22.

Here is a summary of the steps:

1. **Image**: Use the Docker image `ghcr.io/chameleoncloud/edge_ssh_image:latest`.
2. **Exposed Port**: Expose port 22 for SSH access.

These settings are configured in the provided Dockerfile and used in the tutorial notebook to create an SSH-enabled container on CHI@Edge.
