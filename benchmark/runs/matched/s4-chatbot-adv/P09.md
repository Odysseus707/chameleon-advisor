To upload `model.pt` into a CHI@Edge container and then download `results.csv` back out, follow these steps:

1. **Choose Site and Project**:
   ```python
   from chi import context

   context.choose_site(default="CHI@Edge")
   context.choose_project()
   ```

2. **Create a Lease for the Device**:
   First, find an available device with the camera attached.
   ```python
   from chi import hardware

   device_type = "raspberrypi4-64"
   available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

   picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
   display([d.device_name for d in picamera_devs])
   ```

3. **Make a Lease**:
   ```python
   from chi import lease
   from datetime import timedelta

   my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
   my_lease.add_device_reservation(devices=[picamera_devs[0]])
   my_lease.submit(idempotent=True)
   ```

4. **Launch a Container**:
   Use the prebuilt container image with necessary dependencies.
   ```python
   from chi import container

   my_container = container.Container(
       "rpi4-camera-test-01",
       image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
       exposed_ports=[],
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"],
       device_profiles=["pi_libcamera"],
   )
   my_container.submit()
   ```

5. **Upload `model.pt` to the Container**:
   ```python
   import os

   cwd = os.getcwd()  # Get current working directory
   model_path = f"{cwd}/model.pt"  # Path to your local model file
   my_container.upload(model_path, "/app/")
   ```

6. **Run Your Experiment in the Container**:
   Execute any necessary commands inside the container to process `model.pt` and generate `results.csv`. For example:
   ```python
   cmd = "your_command_here"
   result, code = my_container.execute(cmd)
   print(result)
   ```

7. **Download `results.csv` from the Container**:
   ```python
   my_container.download("/app/results.csv", ".")
   ```

8. **Cleanup**:
   Delete the container and lease when done.
   ```python
   my_container.delete()
   my_lease.delete()
   ```

This process ensures that you can upload your model, run it in a CHI@Edge container, and retrieve the results efficiently.
