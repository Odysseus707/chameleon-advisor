To target CHI@Edge and select your project using Python CHI, you can follow these minimal setup steps:

1. **Import the necessary modules**:
   ```python
   from chi import context
   ```

2. **Choose the site (CHI@Edge)**:
   ```python
   context.choose_site(default="CHI@Edge")
   ```

3. **Select your project**:
   ```python
   context.choose_project()
   ```

These steps will configure Python CHI to interact with resources at CHI@Edge and ensure that the operations are performed within your selected Chameleon Cloud project.
