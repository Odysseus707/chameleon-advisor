To reserve a specific device that has the Sense HAT attached in CHI@Edge, you can follow these steps:

1. **Authenticate to CHI@Edge**: Use Python-CHI to authenticate and set up your environment.

2. **Create a Lease for the Device**:
   - Specify the machine type (`raspberrypi4-64`).
   - Choose the specific device name that has the Sense HAT attached (e.g., `iot-rpi-cm4-02` for Waveshare Sense Hat).

Here is an example code snippet to reserve a device with a Sense HAT:

```python
import chi

chi.context.use_site("CHI@Edge")
chi.context.choose_project()  # Comment this line if running outside of JupyterHub.

from chi import lease
import os

# Machine name refers to the "type" of device.
machine_name = "raspberrypi4-64"

# Reserving the specific device with the Sense Hat attached.
device_name = "iot-rpi-cm4-02"  # Example for Waveshare Sense Hat.

# Make a unique lease name.
username = os.environ.get("USER")
lease_name = f"{username}-{device_name}"

container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
container_lease.add_device_reservation(
    amount=1,
    machine_type=machine_name,
    device_name=device_name
)
container_lease.submit()

print("Done!")
```

This code will create a lease for the specified device with the Sense HAT attached. Ensure you replace `device_name` with the correct name of your specific device if it differs from the example provided.

After reserving the device, you can proceed to launch containers and access the sensors as described in the documentation.
