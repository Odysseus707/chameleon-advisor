To reserve a Raspberry Pi 5 named `nyu-rpi5-03` for exactly 2 hours and launch a Jupyter minimal-notebook container on it with port 8888 and a public IP using Python CHI, follow these steps:

1. **Set up the environment**:
   - Import necessary modules from `chi`.
   - Set the context to use the correct project and site.

2. **Create a lease for the specific device**:
   - Use the UUID of the Raspberry Pi 5 (`nyu-rpi5-03`).

3. **Launch the container on the reserved device**:
   - Specify the image, exposed ports, and request a floating IP to access it publicly.

Here is how you can do this:

```python
from chi import context, lease, container

# Set up the environment
context.version = "1.0"
context.choose_project()
context.choose_site(default="CHI@Edge")

# Create a lease for nyu-rpi5-03 (UUID: a755b236-580e-4040-874c-80501f00f954)
device_uuid = "a755b236-580e-4040-874c-80501f00f954"
my_lease = lease.Lease("rpi5-lease", duration_hours=2, device_type="raspberrypi5")
my_lease.add_device_reservation(device_uuid=device_uuid)
my_lease.submit(idempotent=True)

# Launch the container on the reserved device
c = container.Container(
    name=f"jupyter-minimal-{device_uuid}",
    reservation_id=my_lease.device_reservations[0]["id"],
    image_ref="quay.io/jupyter/minimal-notebook:latest",
    exposed_ports=[8888],
)
c.submit(idempotent=True, wait_timeout=1200)

# Associate a floating IP with the container
c.associate_floating_ip()

print(f"Container launched at {c.floating_ips[0]}")
```

This script will:
- Set up the context to use Python CHI.
- Create and submit a lease for `nyu-rpi5-03` for 2 hours.
- Launch a container with the Jupyter minimal-notebook image on this device, exposing port 8888.
- Associate a floating IP with the container so it can be accessed publicly.

Make sure to replace placeholders like `device_uuid` and lease names as needed.
