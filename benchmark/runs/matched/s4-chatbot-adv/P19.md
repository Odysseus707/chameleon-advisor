To verify that the camera is detected inside the container, you can run a simple command using `rpicam-hello` with the `--list-cameras` option. This will help identify if the camera and drivers are working correctly.

Here's how to do it:

1. **Ensure your lease and container are set up**:
   - Make sure you have created a lease for a device that has the Pi Camera Module attached.
   - Launch a container with the `ghcr.io/chameleoncloud/edge-picamera-image:latest` image, which includes all necessary dependencies.

2. **Run the verification command**:
   ```python
   cmd = "rpicam-hello --nopreview --list-cameras"
   result, code = my_container.execute(cmd)
   print(result)
   ```

This command will list available cameras if they are detected by `libcamera`. If everything is set up correctly and the camera is attached to the device, you should see output indicating that a camera has been found.
