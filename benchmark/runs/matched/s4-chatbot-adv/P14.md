To get a Raspberry Pi 4 on CHI@Edge that you can access with VS Code Remote-SSH, follow these steps:

1. **Set Up Your Environment**:
   - Ensure you have Python and the `chi` package installed.
   - Import the necessary modules from the `chi` library.

2. **Select Chameleon Site**:
   ```python
   import chi
   chi.use_site("CHI@Edge")
   ```

3. **Set Project Name**:
   ```python
   chi.set("project_name", "Chameleon")
   ```

4. **Create a Lease for the Device**:
   - Define the machine type and lease duration.
   - Create a unique name for the lease.
   - Add device reservations to the lease.

   ```python
   from chi import container, lease

   # Machine name refers to the "type" of device
   machine_name = "raspberrypi4-64"

   # Get dates for lease start and end
   start, end = lease.lease_duration(days=1)

   # Make a unique name for the lease
   lease_name = f"ssh-{machine_name}-{start}"

   reservations = []
   lease.add_device_reservation(reservations, count=2, machine_name=machine_name)
   container_lease = lease.create_lease(lease_name, reservations)
   lease_id = container_lease["id"]

   print(f"Created lease with name {lease_name} and uuid {lease_id}, waiting for it to start. This can take up to 60s.")
   lease.wait_for_active(lease_id)
   print("Done!")
   ```

5. **Start the Container**:
   - Use a Docker image that has SSH enabled.
   - Expose port 22 (SSH) and set other necessary parameters.

   ```python
   # Set a name for the container. Ensure underscores aren't in the name
   container_name = f"tutorial-{machine_name}-ssh".replace("_","-")

   try:
       my_container = container.create_container(
           container_name,
           image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
           workdir="/home",
           exposed_ports=[22],
           reservation_id=lease.get_device_reservation(lease_id),
           platform_version=2,
       )
   except RuntimeError as ex:
       print(ex)
       print(f"Please stop and/or delete {container_name} and try again")
   else:
       print(f"Successfully created container: {container_name}!")
   ```

6. **Add Your Public Key to the Container**:
   - Upload your RSA public key to the container.
   - Set appropriate permissions for the authorized keys file.

   ```python
   # Place your RSA public key in one line in the 'edge_user_public_key' text file
   chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")

   cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
   chi.container.execute(my_container.uuid, cmd)

   cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
   chi.container.execute(my_container.uuid, cmd)
   ```

7. **Associate Floating IP and SSH into the Container**:
   ```python
   ip_address = chi.container.associate_floating_ip(my_container.uuid)

   print("Use the following command to ssh into the container: ssh root@" + ip_address)
   ```

8. **Configure VS Code Remote-SSH**:
   - In VS Code, install the Remote-SSH extension.
   - Add your SSH configuration in `~/.ssh/config` or use the command directly from the terminal.

9. **Destroy the Container After Use** (Optional):
   ```python
   chi.container.destroy_container(my_container.uuid)
   ```

By following these steps, you will have a Raspberry Pi 4 running on CHI@Edge with SSH access configured for VS Code Remote-SSH.
