To reserve a free Raspberry Pi 5 on CHI@Edge for 3 hours, you can follow these steps using Python CHI:

1. **Set up your environment**:
   - Ensure that you have the `python-chi` library installed and configured with your Chameleon credentials.

2. **Choose the site and project**:
   ```python
   from chi import context

   context.choose_site(default="CHI@Edge")
   context.choose_project()
   ```

3. **Find available Raspberry Pi 5 devices**:
   - Use the `hardware.get_devices` method to list all available devices of type "raspberrypi4-64" (which includes Raspberry Pi 5).

4. **Create a lease for one device**:
   ```python
   from chi import hardware, lease

   # Get available devices
   available_devices = hardware.get_devices(filter_reserved=True, device_type="raspberrypi4-64")

   if not available_devices:
       print("No Raspberry Pi 5 devices are currently available.")
   else:
       # Select the first available device
       selected_device = available_devices[0]

       # Create a lease for 3 hours
       my_lease = lease.Lease("raspberry_pi_5_lease", duration=timedelta(hours=3))
       my_lease.add_device_reservation(devices=[selected_device])
       my_lease.submit(idempotent=True)
   ```

This code will:
- Set the context to CHI@Edge and choose your project.
- List all available Raspberry Pi 5 devices that are not currently reserved.
- Create a lease for one of these devices for a duration of 3 hours.

Make sure you have the necessary permissions and SUs (Service Units) in your Chameleon account to reserve the device.
