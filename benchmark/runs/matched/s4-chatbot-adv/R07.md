Based on the available documentation and context, here are the steps to capture stills from an attached Pi camera module on CHI@Edge for about 3 hours:

1. **Choose a Device**: Use the `raspberrypi4-64` device type as it is known to support the Pi Camera Module 3 with the libcamera drivers.

2. **Create a Lease**:
   ```python
   from chi import lease, hardware

   # Filter available devices for raspberrypi4-64 and those with picamera attached.
   available_devices = hardware.get_devices(filter_reserved=True, device_type="raspberrypi4-64")
   picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]

   # Make a lease for one of the devices
   my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
   my_lease.add_device_reservation(devices=[picamera_devs[0]])
   my_lease.submit(idempotent=True)
   ```

3. **Launch a Container**:
   ```python
   from chi import container

   # Launch the prebuilt container image with libcamera and rpicam-apps.
   my_container = container.Container(
       "rpi4-camera-test-01",
       image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
       exposed_ports=[],
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"],
       device_profiles=["pi_libcamera"],
   )
   my_container.submit()
   ```

4. **Capture a Still Image**:
   ```python
   cmd = "rpicam-still --nopreview --output /app/test1.png --width 1920 --height 1080"
   result, code = my_container.execute(cmd)
   print(result)

   # Download the captured image from the container.
   my_container.download("/app/test1.png", ".")
   ```

5. **Cleanup**:
   ```python
   my_container.delete()
   my_lease.delete()
   ```

### Top 3 Device Types to Reserve

1. **raspberrypi4-64**: Best for capturing high-resolution images due to its support for the Pi Camera Module 3 and libcamera drivers.
2. **iot-rpi4-picam**: Specifically designed with a camera module attached, ensuring compatibility and ease of use.
3. **raspberrypi3b+**: A fallback option if raspberrypi4-64 devices are not available; it also supports the Pi Camera Module but may have less powerful hardware.

These device types ensure you can capture high-quality images with minimal setup complexity.
