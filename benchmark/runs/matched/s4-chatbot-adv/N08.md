To launch a Jupyter minimal-notebook container on your active lease named `serve-edge-vr` and give it a public IP, follow these steps:

1. **Ensure you are in the correct Chameleon environment**:
   - Log into the Chameleon portal.
   - Ensure that the project drop-down menu near the top left shows the correct project associated with your lease.

2. **Launch the container using `python-chi` API**:
   - Open a Jupyter notebook on Chameleon and run the following code to launch the container:

```python
from chi import context, lease, container

context.version = "1.0"
context.choose_project()
context.choose_site(default="CHI@Edge")

# Get your active lease
l = lease.get_lease("serve-edge-vr")
l.show()

# Launch a Jupyter minimal-notebook container on the edge device
c = container.Container(
    name=f"node-serve-edge-{os.getenv('USER')}".replace('_', '-'),
    reservation_id=l.device_reservations[0]["id"],
    image_ref="quay.io/jupyter/minimal-notebook:latest",
    exposed_ports=[8888]
)
c.submit(idempotent=True, wait_timeout=1200)

# Associate a floating IP with the container
c.associate_floating_ip()
```

3. **Retrieve the Jupyter notebook token URL from the container logs**:
   - After launching and associating the floating IP, you can retrieve the container logs to find the Jupyter notebook's token URL:

```python
print(chi.container.get_logs(c.id))
```

Look for a line in the output that resembles this format:

```
http://127.0.0.1:8888/lab?token=XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

Replace `127.0.0.1` with the floating IP address assigned to your container, which you noted earlier when associating the floating IP.

4. **Access the Jupyter notebook**:
   - Open a browser and navigate to the URL obtained from the logs, substituting the floating IP for `127.0.0.1`.

This will allow you to access the Jupyter environment running on your Raspberry Pi 5 edge device through the container.
