To read temperature, humidity, and pressure from a Sense HAT on CHI@Edge, you can follow these steps:

1. **Authenticate to CHI@Edge**:
   Use Python-CHI to authenticate and connect to the CHI@Edge site.

2. **Create a Lease for the Device**:
   Reserve a specific device that has the Sense Hat attached to it by creating a lease.

3. **Launch a Container with Required Libraries**:
   Launch a container with the necessary libraries pre-installed, such as `sense-hat` and other dependencies required for interacting with the sensors.

4. **Access Sensors Using Python Code**:
   Use the `sense_hat` library to read temperature, humidity, and pressure from the Sense Hat.

Here is an example of how you can achieve this:

### Step 1: Authenticate to CHI@Edge
```python
import chi

chi.context.use_site("CHI@Edge")
chi.context.choose_project()
```

### Step 2: Create a Lease for the Device
```python
from chi import lease
import os

machine_name = "raspberrypi4-64"
device_name = "iot-rpi4-picam3" # RPI sense hat device name example

username = os.environ.get("USER")
lease_name = f"{username}-{device_name}"
container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
container_lease.submit()
print("Done!")
```

### Step 3: Launch a Container with Required Libraries
```python
from chi import container

container_name = "edge-rpi-sensehat".replace("_", "-")

environment_vars = {}

my_container = container.Container(
    name=container_name,
    image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
    device_profiles=["pi_sensehat"],
    environment=environment_vars,
    reservation_id=container_lease.device_reservations[0]["id"],
    command=["-c", "sleep infinity"],
)
my_container.submit()
```

### Step 4: Access Sensors Using Python Code
```python
cmd_str = """
from sense_hat import SenseHat

sense = SenseHat()
sense.clear()

# Returns the pressure in Millibars
pressure = sense.get_pressure()

# Returns the temperature in Celsius from the pressure sensor
temperature_pressure = sense.get_temperature_from_pressure()

# Returns the percentage of relative humidity
humidity = sense.get_humidity()

print(
    "Pressure: {:.1f} mbar, Temperature (from pres): {:.1f} C,  Relative Humidity: {:.1f} %".format(
        pressure, temperature_pressure, humidity
    )
)
"""

stdout, resultcode = my_container.execute(f"python3 -c '{cmd_str}'")
print(stdout)
```

### Step 5: Clean Up
```python
my_container.delete()
container_lease.delete()
```

This code will authenticate to CHI@Edge, reserve a device with the Sense Hat attached, launch a container with necessary libraries, and read temperature, humidity, and pressure from the Sense Hat. Finally, it cleans up by deleting the container and lease.
