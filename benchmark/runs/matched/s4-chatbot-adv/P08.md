To run `ls /app` inside the running container in CHI@Edge and capture the output, you can use the `execute` method provided by the Chameleon Cloud Python client for containers. Here's how you can do it:

```python
result, code = my_container.execute("ls /app")
print(result)
```

This command will execute `ls /app` inside your container and print out the contents of the `/app` directory. Make sure that `my_container` is already defined and running as per the previous steps in the tutorial.
