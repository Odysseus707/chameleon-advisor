To reserve one Raspberry Pi 4 on CHI@Edge for 2 hours, you can follow these steps:

1. **Authenticate to CHI@Edge**: Use Python-CHI to authenticate and set up your environment.

```python
import chi

chi.context.use_site("CHI@Edge")
chi.context.choose_project() # comment this line if running outside of jupyterhub
```

2. **Create a Lease for the Device**:
   - Specify the machine type as `raspberrypi4-64`.
   - Set the duration to 2 hours.
   
```python
from chi import lease
import os

# Define the machine name and device name
machine_name = "raspberrypi4-64"
device_name = "iot-rpi4-picam3" # Example device name for Raspberry Pi Sense Hat, adjust as needed.

# Create a unique lease name
username = os.environ.get("USER")
lease_name = f"{username}-{device_name}"

container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=2))
container_lease.add_device_reservation(
    amount=1,
    machine_type=machine_name,
    device_name=device_name
)
container_lease.submit()
print("Done!")
```

This code will create a lease for one Raspberry Pi 4 on CHI@Edge with the specified duration of 2 hours. Adjust `device_name` as needed based on the specific device you want to reserve.

If you encounter any issues or need further customization, refer to the Chameleon Cloud documentation and Python-CHI library details provided in the context for additional guidance.
