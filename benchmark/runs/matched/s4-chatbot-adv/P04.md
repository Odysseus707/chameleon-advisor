To reserve 3 Raspberry Pi devices on CHI@Edge in one lease, you can follow these steps using Python-chi:

1. **Authenticate to CHI@Edge**: Ensure that your environment is authenticated with CHI@Edge.

2. **Create a Lease**: Define the lease for reserving multiple Raspberry Pi devices of the same type.

Here's how you can do it in code:

```python
import chi

# Authenticate and set up context
chi.context.use_site("CHI@Edge")
chi.context.choose_project()  # Comment this line if running outside JupyterHub

from chi import lease
import os

# Define machine name (type of device)
machine_name = "raspberrypi4-64"

# Make a unique name for the lease
username = os.environ.get("USER", "default_user")
lease_name = f"{username}-multiple-rpis"
container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))

# Add device reservations (3 Raspberry Pi devices)
for i in range(3):
    container_lease.add_device_reservation(
        amount=1,
        machine_type=machine_name
    )

# Submit the lease request
container_lease.submit()
print("Done!")
```

This code will create a lease named after your username and reserve 3 Raspberry Pi devices of type `raspberrypi4-64` for 4 hours. Adjust the duration as needed.

Ensure you have the necessary permissions and sufficient resources in your project to make this reservation.
