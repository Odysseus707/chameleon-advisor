To check whether a given device is free right now on CHI@Edge, you can use the `hardware.get_devices` method provided by the Python CHI library. This method allows you to filter and list available devices based on specific criteria such as device type.

Here's how you can do it:

1. **Import the necessary modules**:
   ```python
   from chi import hardware
   ```

2. **Filter for available devices of a specific type** (e.g., `raspberrypi4-64`):
   ```python
   device_type = "raspberrypi4-64"
   available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)
   ```

3. **Check the availability**:
   - The `filter_reserved=True` parameter ensures that only devices not currently reserved are listed.
   - You can then inspect the `available_devices` list to see if any devices of your desired type are free.

Here is a complete example:

```python
from chi import hardware

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

if available_devices:
    print(f"Available {device_type} devices:")
    for device in available_devices:
        print(device.device_name)
else:
    print(f"No {device_type} devices are currently available.")
```

This script will list the names of any `raspberrypi4-64` devices that are not reserved, indicating they are free to be used.
