To launch a container with the Sense HAT enabled on CHI@Edge, follow these steps:

1. **Authenticate to CHI@Edge**:
   ```python
   import chi

   chi.context.use_site("CHI@Edge")
   chi.context.choose_project()  # Comment this line if running outside of JupyterHub.
   ```

2. **Create a Lease for the Device**:
   Reserve a specific device that has the Sense Hat attached to it.

   ```python
   from chi import lease
   import os

   machine_name = "raspberrypi4-64"
   device_name = "iot-rpi4-picam3"  # Replace with the correct device name for your setup.
   
   username = os.environ.get("USER")
   lease_name = f"{username}-{device_name}"
   
   container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=4))
   container_lease.add_device_reservation(amount=1, machine_type=machine_name, device_name=device_name)
   container_lease.submit()
   print("Done!")
   ```

3. **Launch a Container with the Sense Hat Enabled**:
   
   ```python
   from chi import container

   # Set a name for the container.
   container_name = "edge-rpi-sensehat".replace("_", "-")

   environment_vars = {}

   my_container = container.Container(
       name=container_name,
       image_ref="ghcr.io/chameleoncloud/edge_sensehat_image:latest",
       device_profiles=["pi_sensehat"],
       environment=environment_vars,
       reservation_id=container_lease.device_reservations[0]["id"],
       command=["-c", "sleep infinity"]
   )
   
   my_container.submit()
   ```

This will launch a container with the Sense HAT enabled, using the specified image and device profiles. The `pi_sensehat` profile ensures that all necessary devices and dependencies are included for interacting with the Sense Hat sensors.

If you need to use the Waveshare Sense Hat instead of the Raspberry Pi Sense Hat, ensure you adjust the `device_name`, `image_ref`, and `device_profiles` accordingly as described in the documentation.
