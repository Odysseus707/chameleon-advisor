To print the `device_name` of every available `raspberrypi4-64` device on CHI@Edge, you can use the following Python code snippet:

```python
from chi import hardware

# Filter for raspberrypi4-64 devices that are not reserved.
available_devices = hardware.get_devices(filter_reserved=True, device_type="raspberrypi4-64")

# Print each available device's name.
for device in available_devices:
    print(device.device_name)
```

This code will list the `device_name` of every free `raspberrypi4-64` device currently available for reservation on CHI@Edge.
