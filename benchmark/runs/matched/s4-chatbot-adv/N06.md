1. Import necessary modules.
2. Set up the site and project context.
3. Create a lease for the desired device type.
4. Launch a container with the specified image and configurations.

Here is how you can do it:

```python
from chi import context, hardware, lease, container

# Set up the Chameleon Cloud environment to use CHI@Edge
context.choose_site(default="CHI@Edge")
context.choose_project()

# Get available devices of type raspberrypi4-64
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

# Select the first available device with a camera attached (assuming it's named appropriately)
picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
device_to_reserve = picamera_devs[0]

# Create and submit a lease
my_lease = lease.Lease("demo-lease", duration=timedelta(hours=10))
my_lease.add_device_reservation(devices=[device_to_reserve])
my_lease.submit(idempotent=True)

# Launch the container with the specified image and device profile
my_container = container.Container(
    "demo-app",
    image_ref="python:3.9-slim",
    reservation_id=my_lease.device_reservations[0]["id"],
    exposed_ports=[22],
    device_profiles=["pi_libcamera"],  # Ensure this matches your setup if needed
)
my_container.submit()
```

This script sets up the environment, creates a lease for a Raspberry Pi 4 with a camera attached, and launches a container using the specified image. The `device_profiles` parameter is included to ensure that all necessary devices are exposed inside the container for the camera to function correctly.

Note: Ensure you have the correct device name pattern (`iot-rpi4-picam`) and adjust it if your setup uses different naming conventions.
