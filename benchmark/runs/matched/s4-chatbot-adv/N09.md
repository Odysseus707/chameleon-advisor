To reserve a camera-equipped Raspberry Pi, start the camera container, and retrofit SSH access into it so that your teammate can log in and run captures themselves, follow these steps:

### Step 1: Reserve a Camera-Equipped Device

First, you need to choose a site and project, then create a lease for a device with a camera.

```python
from chi import context, hardware, lease

# Choose the CHI@Edge site and your Chameleon project.
context.choose_site(default="CHI@Edge")
context.choose_project()

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
print([d.device_name for d in picamera_devs])

# Create a lease for one of the devices.
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)
```

### Step 2: Launch the Camera Container

Next, launch a container with the necessary dependencies for camera support.

```python
from chi import container

# Define the container.
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()
```

### Step 3: Attach an IP Address and SSH Access

To allow your teammate to access the container via SSH, you need to attach a floating IP address and configure SSH.

```python
# Attach a public IP.
public_ip = container.associate_floating_ip(my_container.uuid)

# Install SSH server on the container.
container.execute(my_container.uuid, 'apt update')
container.execute(my_container.uuid, 'apt -y install openssh-server')

# Upload your public key to the container and configure it for root login.
!mkdir -p tmp_keys
!cp /work/.ssh/id_rsa.pub tmp_keys/authorized_keys

container.execute(my_container.uuid, 'mkdir -p /root/.ssh')
container.upload(my_container.uuid, "./tmp_keys/authorized_keys", "/root/.ssh")
container.execute(my_container.uuid, 'chown root /root/.ssh')
container.execute(my_container.uuid, 'chown root /root/.ssh/authorized_keys')
container.execute(my_container.uuid, 'chmod go-w /root')
container.execute(my_container.uuid, 'chmod 700 /root/.ssh')
container.execute(my_container.uuid, 'chmod 600 /root/.ssh/authorized_keys')

# Start the SSH server.
container.execute(my_container.uuid, 'service ssh start')
container.execute(my_container.uuid, 'service ssh status')
```

### Step 4: Provide SSH Access Information to Your Teammate

Your teammate can now access the container via SSH using the following command:

```bash
ssh root@<public_ip>
```

Replace `<public_ip>` with the actual public IP address obtained from `container.associate_floating_ip(my_container.uuid)`.

Once your experiment is complete, you can clean up by deleting the container and lease to free resources for others:

```python
my_container.delete()
```
