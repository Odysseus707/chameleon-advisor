To reserve one Raspberry Pi 4 for 10 hours starting now and launch a `python:3.9-slim` container with SSH installed, follow these steps using the imperative style of the Python CHI library:

### Step-by-Step Instructions

#### 1. Import Required Libraries
```python
import chi
from chi import lease
```

#### 2. Set Up Environment and Project Name
Ensure you have your project name set up correctly.
```python
PROJECT_NAME = os.getenv('OS_PROJECT_NAME') # change this if needed
chi.use_site("CHI@Edge")
chi.set("project_name", PROJECT_NAME)
username = os.getenv('USER')
```

#### 3. Reserve the Edge Device (Raspberry Pi 4)
Reserve a Raspberry Pi 4 for 10 hours starting now.
```python
NODE_TYPE = 'raspberrypi4-64'
reservations = []
lease.add_device_reservation(reservations, machine_name=NODE_TYPE, count=1)

start_date, end_date = lease.lease_duration(days=0, hours=10)
l = lease.create_lease(f"{username}-{NODE_TYPE}", reservations, start_date=start_date, end_date=end_date)
l = lease.wait_for_active(l["id"])
```

#### 4. Launch the Container
Create a container on the reserved device with SSH installed.
```python
container_name = f"{username}-edge-cpu".replace("_", "-")
my_container = chi.container.create_container(
    name=container_name,
    image="python:3.9-slim",
    reservation_id=lease.get_device_reservation(l["id"]),
    interactive=True,
    exposed_ports=[22],
    platform_version=2
)
chi.container.wait_for_active(my_container.uuid)
```

#### 5. Attach Floating IP and Install SSH Server
Attach a floating IP to the container and install an SSH server.
```python
public_ip = chi.container.associate_floating_ip(my_container.uuid)

# Update package list and install openssh-server
chi.container.execute(my_container.uuid, 'apt update')
chi.container.execute(my_container.uuid, 'apt -y install openssh-server')

# Start the SSH service
chi.container.execute(my_container.uuid, 'service ssh start')
```

#### 6. Configure SSH Access
Ensure your SSH key is installed and configured properly.
```python
!mkdir -p tmp_keys
!cp /work/.ssh/id_rsa.pub tmp_keys/authorized_keys

chi.container.execute(my_container.uuid, 'mkdir -p /root/.ssh')
chi.container.upload(my_container.uuid, "./tmp_keys/authorized_keys", "/root/.ssh")
chi.container.execute(my_container.uuid, 'chown root /root/.ssh')
chi.container.execute(my_container.uuid, 'chown root /root/.ssh/authorized_keys')
chi.container.execute(my_container.uuid, 'chmod go-w /root')
chi.container.execute(my_container.uuid, 'chmod 700 /root/.ssh')
chi.container.execute(my_container.uuid, 'chmod 600 /root/.ssh/authorized_keys')

# Start the SSH service
chi.container.execute(my_container.uuid, 'service ssh status')
```

#### 7. Access Container via SSH
You can now access your container over SSH using:
```python
print("ssh root@%s" % public_ip)
```

### Summary
This setup reserves a Raspberry Pi 4 for 10 hours and launches a `python:3.9-slim` container with SSH installed, making it accessible from outside the Chameleon environment.
