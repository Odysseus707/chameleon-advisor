To inject your public key so you can SSH in as root into a container on CHI@Edge, follow these steps:

1. **Prepare Your Public Key**: Ensure that your RSA public key is placed in one line within the `edge_user_public_key` file.

2. **Create a Lease and Container**:
    - Select the Chameleon site (`CHI@Edge`) using `chi.use_site("CHI@Edge")`.
    - Set up your project name with `chi.set("project_name", "Chameleon")`.
    - Create a lease for the desired device (e.g., `raspberrypi4-64`).
    - Start a container using the Docker image (`ghcr.io/chameleoncloud/edge_ssh_image:latest`) that has SSH enabled.

3. **Upload and Configure Public Key**:
    - Upload your public key to the running container.
    - Set appropriate permissions for the `authorized_keys` file.
    - Append your public key to the `authorized_keys` file within the container.

4. **SSH into the Container**:
    - Associate a floating IP address with the container.
    - Use SSH to connect as root using the provided IP address.

Here is an example of how you can do this in Python:

```python
import chi

# Select CHI@Edge site and set project name
chi.use_site("CHI@Edge")
chi.set("project_name", "Chameleon")

from chi import container, lease

# Create a 1-day lease for a Raspberry Pi 4 device
machine_name = "raspberrypi4-64"
start, end = lease.lease_duration(days=1)
lease_name = f"ssh-{machine_name}-{start}"
reservations = []
lease.add_device_reservation(reservations, count=2, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]
print(f"created lease with name {lease_name} and uuid {lease_id}, waiting for it to start.")
lease.wait_for_active(lease_id)
print("Done!")

# Start the container
container_name = f"tutorial-{machine_name}-ssh".replace("_","-")
try:
    my_container = container.create_container(
        container_name,
        image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
        workdir="/home",
        exposed_ports=[22],
        reservation_id=lease.get_device_reservation(lease_id),
        platform_version=2,
    )
except RuntimeError as ex:
    print(ex)
    print(f"please stop and/or delete {container_name} and try again")
else:
    print(f"Successfully created container: {container_name}!")

# Upload your public key to the container
chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")

# Set permissions for authorized_keys file
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Append your public key to the authorized_keys file
cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Get IP address for SSH access
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print("use the following command to ssh into the container: ssh root@" + ip_address)
```

This script will create a lease and container on CHI@Edge, upload your public key, configure it properly within the container, and provide you with an IP address for SSH access.
