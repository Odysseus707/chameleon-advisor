To reserve a Raspberry Pi on CHI@Edge and get the reservation_id to pass to a container, you can follow these steps:

1. **Choose the Site**: Ensure that you are working with the correct Chameleon site (CHI@Edge).

2. **Get Available Devices**: Filter for available devices of type `raspberrypi4-64` which have the Pi Camera Module attached.

3. **Create a Lease**: Reserve one of these devices by creating and submitting a lease request.

Here is how you can do it programmatically using Python CHI:

```python
from chi import context, hardware, lease

# Step 1: Choose the site (CHI@Edge)
context.choose_site(default="CHI@Edge")
context.choose_project()

# Step 2: Get available devices with Pi Camera Module attached
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]
print([d.device_name for d in picamera_devs])

# Step 3: Create and submit a lease
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

reservation_id = my_lease.device_reservations[0]["id"]
print(f"Reservation ID: {reservation_id}")
```

This script will:
- Set the context to CHI@Edge.
- Filter and list available Raspberry Pi 4 devices with a camera module attached.
- Reserve one of these devices for 3 hours and print out the reservation ID.

You can then use this `reservation_id` when launching your container.
