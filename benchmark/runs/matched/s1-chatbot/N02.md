To record a 10-second 720p video at 30 fps from the Pi camera and download it to your machine, you can follow these steps:

Launch a container with the pi_libcamera device profile and the edge-picamera-image image. This will provide access to the necessary devices for the camera to function.

Use the rpicam-vid utility to capture a 10-second 720p video at 30 fps. You can do this by executing the following command inside the container:

rpicam-vid --nopreview -t 10000 --output /app/video.mp4 --width 1280 --height 720 --framerate 30

Download the captured video from the container to your machine using the container.download() utility.

Here's a sample code snippet that demonstrates these steps:

from chi import container
from chi import lease

# Create a lease for a device with the Pi camera
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=1))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

# Launch a container with the pi_libcamera device profile
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()

# Capture a 10-second 720p video at 30 fps
cmd = "rpicam-vid --nopreview -t 10000 --output /app/video.mp4 --width 1280 --height 720 --framerate 30"
result, code = my_container.execute(cmd)
print(result)

# Download the captured video
my_container.download("/app/video.mp4", ".")

# Clean up
my_container.delete()
my_lease.delete()

Note that you'll need to replace picamera_devs[0] with the actual device name or ID of the device with the Pi camera. Also, make sure to adjust the video capture parameters (e.g., resolution, framerate) according to your needs.
