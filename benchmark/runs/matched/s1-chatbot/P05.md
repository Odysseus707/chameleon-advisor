To launch a basic Ubuntu container on a reserved Pi on CHI@Edge, you can follow these steps:

Reserve a Pi device on CHI@Edge using the lease module from the chi library. You can do this by creating a lease and adding a device reservation for a Raspberry Pi.
Launch a container on the reserved device using the container module from the chi library. You can specify the image, command, and device profiles for the container.
Here's an example code snippet that demonstrates how to launch a basic Ubuntu container on a reserved Pi:

from chi import context, lease, container

# Choose the CHI@Edge site
context.choose_site(default="CHI@Edge")

# Create a lease and add a device reservation for a Raspberry Pi
my_lease = lease.Lease("ubuntu-container-lease", duration=timedelta(hours=1))
my_lease.add_device_reservation(devices=[{"device_type": "raspberrypi4-64"}])
my_lease.submit(idempotent=True)

# Launch a container on the reserved device
my_container = container.Container(
    "ubuntu-container",
    image_ref="ubuntu:latest",
    command=["sleep", "infinity"],
    reservation_id=my_lease.device_reservations[0]["id"],
)
my_container.submit()

Note that you'll need to replace the image_ref parameter with the actual image reference for the Ubuntu image you want to use. Additionally, you may need to specify additional device profiles or configuration options depending on your specific use case.
