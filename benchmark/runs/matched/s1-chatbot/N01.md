To reserve three raspberrypi4-64 devices on CHI@Edge for 6 hours in one lease and launch an SSH-enabled container on the lease, follow these steps:

Create a lease: Use the lease module from the chi library to create a lease for 6 hours with three raspberrypi4-64 devices.
undefined

from chi import lease machine_name = "raspberrypi4-64" start, end = lease.lease_duration(hours=6) lease_name = f"ssh-{machine_name}-{start}" reservations = [] lease.add_device_reservation(reservations, count=3, machine_name=machine_name) container_lease = lease.create_lease(lease_name, reservations) lease_id = container_lease["id"] lease.wait_for_active(lease_id)

2. **Launch an SSH-enabled container**: Use the `container` module from the `chi` library to launch a container on the lease. You will need to use an SSH-enabled image, such as the one described in the reference material.
   ```python
from chi import container
container_name = f"tutorial-{machine_name}-ssh".replace("_","-")
my_container = container.create_container(
    container_name,
    image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
    workdir="/home",
    exposed_ports=[22],
    reservation_id=lease.get_device_reservation(lease_id),
    platform_version=2,
)

Add your public key to the container: Upload your public key to the container and add it to the authorized keys file.
undefined

chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/") cmd = "/bin/bash -c "chmod 600 /root/.ssh/authorized_keys"" chi.container.execute(my_container.uuid, cmd) cmd = "/bin/bash -c "cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys"" chi.container.execute(my_container.uuid, cmd)

4. **Associate a floating IP with the container**: Associate a floating IP with the container to access it via SSH.
   ```python
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print("use the following command to ssh into the container: ssh root@" + ip_address)

Now you can log in to the container as root using the SSH command printed in the last step. Remember to destroy the container when you are finished with it to free up resources.

chi.container.destroy_container(my_container.uuid)
