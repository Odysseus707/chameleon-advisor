To capture a 1080p still from the Pi Camera and download it, you can follow these steps:

Create a lease for a device with a Pi Camera attached. You can use the lease module from the chi library to create a lease.
Launch a container with the pi_libcamera device profile, which exposes the necessary devices for the camera to work. You can use the container module from the chi library to launch a container.
Use the rpicam-still command to capture a 1920x1080 still image. You can execute this command inside the container using the execute method.
Download the captured image from the container using the download method.
Here's some sample code to achieve this:

from chi import context, lease, container

# Create a lease for a device with a Pi Camera attached
context.choose_site(default="CHI@Edge")
context.choose_project()
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

# Launch a container with the pi_libcamera device profile
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()

# Capture a 1920x1080 still image
cmd = "rpicam-still  --nopreview  --output /app/test1.png --width 1920 --height 1080"
result, code = my_container.execute(cmd)
print(result)

# Download the captured image
my_container.download("/app/test1.png", ".")

Note that you'll need to replace picamera_devs[0] with the actual device name of the Pi Camera device you want to use. You can find this by listing the available devices using the hardware.get_devices method.
