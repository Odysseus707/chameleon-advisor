To convert your CHI@UC bare-metal script to run on CHI@Edge, you need to make significant changes because CHI@Edge is a container-based edge computing testbed, whereas CHI@UC is a bare-metal cloud.

Here's a step-by-step guide to help you convert your script:

Create a lease: On CHI@Edge, you need to create a lease for the devices you want to use. You can do this using the lease module in the chi library. Specify the device type, start and end dates, and the number of devices you need.

Create a container: Instead of launching a bare-metal instance, you'll create a container on CHI@Edge. You can use the container module in the chi library to create a container from a Docker image. You'll need to specify the image, the device reservation, and any other required parameters.

Configure the container: You may need to configure the container by uploading files, setting environment variables, or executing commands inside the container. You can use the chi.container module to perform these actions.

Associate a floating IP: To access your container from outside the CHI@Edge network, you'll need to associate a floating IP with your container. You can do this using the chi.container.associate_floating_ip function.

SSH into the container: Once you have the floating IP, you can SSH into your container using the IP address and the credentials you specified when creating the container.

Here's some sample code to get you started:

import chi

# Create a lease
chi.use_site("CHI@Edge")
lease_name = "my-lease"
start, end = lease.lease_duration(days=1)
reservations = []
lease.add_device_reservation(reservations, count=1, machine_name="raspberrypi4-64")
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]
lease.wait_for_active(lease_id)

# Create a container
container_name = "my-container"
image = "ghcr.io/chameleoncloud/edge_ssh_image:latest"
my_container = container.create_container(
    container_name,
    image=image,
    workdir="/home",
    exposed_ports=[22],
    reservation_id=lease.get_device_reservation(lease_id),
    platform_version=2,
)

# Configure the container
chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")
cmd = "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)
cmd = "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\""
chi.container.execute(my_container.uuid, cmd)

# Associate a floating IP
ip_address = chi.container.associate_floating_ip(my_container.uuid)

# SSH into the container
print("use the following command to ssh into the container: ssh root@" + ip_address)
