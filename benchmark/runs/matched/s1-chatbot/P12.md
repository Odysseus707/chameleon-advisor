To inject your public key so you can SSH in as root, follow these steps:

Place your RSA public key in one line in the 'edge_user_public_key' text file.
Upload the file to the running container using the command: chi.container.upload(my_container.uuid, "./edge_user_public_key", "/root/.ssh/")
Set the appropriate permissions for the authorized keys file using the command: chi.container.execute(my_container.uuid, "/bin/bash -c \"chmod 600 /root/.ssh/authorized_keys\"")
Copy the public key to the authorized keys file using the command: chi.container.execute(my_container.uuid, "/bin/bash -c \"cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys\"")
After completing these steps, you should be able to SSH into the container as root using the IP address associated with the container. You can obtain the IP address using the command: chi.container.associate_floating_ip(my_container.uuid)
