To keep your container running on CHI@Edge so you can exec into it, you can use the command parameter when creating the container.

Instead of using a command that finishes immediately, use a command that keeps the container running, such as sleep infinity or tail -f /dev/null.

Here's an example:

from chi import container

my_container = container.Container(
    "my-container",
    image_ref="my-image",
    exposed_ports=[],
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],  # Keep the container running
    device_profiles=["pi_libcamera"],
)
my_container.submit()

This will keep the container running indefinitely, allowing you to exec into it and perform any necessary tasks. When you're finished, you can delete the container using my_container.delete().
