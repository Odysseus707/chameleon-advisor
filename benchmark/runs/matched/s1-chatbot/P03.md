To reserve a Pi on CHI@Edge and get the reservation_id to pass to a container, you can follow these steps based on the provided Python CHI documentation and the picamera_tutorial.ipynb example:

Choose the Site and Project: First, ensure you are working with the CHI@Edge site and have selected your project.

from chi import context
context.choose_site(default="CHI@Edge")
context.choose_project()

Find Available Devices: Identify the Raspberry Pi devices available for reservation. In this case, we're looking for devices with the camera attached.

from chi import hardware
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)
picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]

Create a Lease: Make a lease for one of the identified devices. This step reserves the device for your use.

from chi import lease
from datetime import timedelta
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)

Get the Reservation ID: After submitting the lease, you can retrieve the reservation ID, which you will need to pass to your container.

reservation_id = my_lease.device_reservations[0]["id"]

Launch Your Container: Use the reservation ID when launching your container to ensure it is deployed on the reserved device.

from chi import container
my_container = container.Container(
    "rpi4-camera-test-01",
    image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    exposed_ports=[],
    reservation_id=reservation_id,
    command=["sleep", "infinity"],
    device_profiles=["pi_libcamera"],
)
my_container.submit()

By following these steps, you can reserve a Raspberry Pi on CHI@Edge, obtain the reservation ID, and then use this ID to launch a container on the reserved device, ensuring that your container has access to the camera and other necessary resources.
