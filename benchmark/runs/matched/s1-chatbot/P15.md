To find which Raspberry Pis have a camera attached and reserve one, you can use the following steps based on the provided Python CHI documentation and the picamera_tutorial.ipynb example:

Choose the site: Select CHI@Edge as the site to work with, as it is the edge computing testbed where cameras are attached to Raspberry Pis.

Choose the project: Select the project you want to work under. This is necessary because resources and leases are project-specific.

Find available devices with cameras: Use the hardware.get_devices function to find devices that match the criteria for having a camera. In the example provided, devices with names starting with "iot-rpi4-picam" are identified as having cameras.

Create a lease for the device: Once you've identified a device with a camera, create a lease for that device using the lease.Lease class. Specify the duration of the lease and add the device to the lease.

Submit the lease: Submit the lease to reserve the device. This ensures that the device is allocated to your project for the specified duration.

Here's a simplified example based on the picamera_tutorial.ipynb:

from chi import context
from chi import hardware
from chi import lease
from datetime import timedelta

# Step 1 & 2: Choose site and project
context.choose_site(default="CHI@Edge")
context.choose_project()

# Step 3: Find available devices with cameras
device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)
picamera_devs = [d for d in available_devices if d.device_name.startswith("iot-rpi4-picam")]

# Step 4 & 5: Create and submit a lease for the device
my_lease = lease.Lease("rpi4-camera-lease", duration=timedelta(hours=3))
my_lease.add_device_reservation(devices=[picamera_devs[0]])
my_lease.submit(idempotent=True)
