To list the I2C addresses and debug the sensor bus from inside the container, you can use the i2cdetect command from the i2c-tools utility.

Here is an example of how to do this:

result, code = my_container.execute("i2cdetect -y 1")
print(result)

This will display the current detected I2C devices and their addresses, allowing you to verify that the sensors are properly connected and configured.
