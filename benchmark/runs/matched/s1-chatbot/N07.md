To reserve two Raspberry Pi 4s in one CHI@Edge lease and start an SSH-enabled container on each of them, follow these steps:

Create a lease: Use the lease module from the chi library to create a lease for two Raspberry Pi 4 devices. Set the lease duration to 1 day.
undefined

from chi import lease machine_name = "raspberrypi4-64" start, end = lease.lease_duration(days=1) lease_name = f"ssh-{machine_name}-{start}" reservations = [] lease.add_device_reservation(reservations, count=2, machine_name=machine_name) container_lease = lease.create_lease(lease_name, reservations) lease_id = container_lease["id"] lease.wait_for_active(lease_id)

2. **Start an SSH-enabled container on each device**: Use the `container` module from the `chi` library to start an SSH-enabled container on each device. You will need to provide the image name, workdir, exposed ports, and reservation ID.
   ```python
from chi import container
container_name1 = f"tutorial-{machine_name}-ssh-1".replace("_","-")
container_name2 = f"tutorial-{machine_name}-ssh-2".replace("_","-")
try:
    my_container1 = container.create_container(
        container_name1,
        image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
        workdir="/home",
        exposed_ports=[22],
        reservation_id=lease.get_device_reservation(lease_id),
        platform_version=2,
    )
    my_container2 = container.create_container(
        container_name2,
        image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
        workdir="/home",
        exposed_ports=[22],
        reservation_id=lease.get_device_reservation(lease_id),
        platform_version=2,
    )
except RuntimeError as ex:
    print(ex)
    print(f"please stop and/or delete {container_name1} and {container_name2} and try again")
else:
    print(f"Successfully created containers: {container_name1} and {container_name2}!")

Add your public key to the authorized keys within each container: Upload your public key to each container and copy it to the authorized keys file.

chi.container.upload(my_container1.uuid, "./edge_user_public_key", "/root/.ssh/") chi.container.upload(my_container2.uuid, "./edge_user_public_key", "/root/.ssh/") cmd = "/bin/bash -c "chmod 600 /root/.ssh/authorized_keys"" chi.container.execute(my_container1.uuid, cmd) chi.container.execute(my_container2.uuid, cmd) cmd = "/bin/bash -c "cat /root/.ssh/edge_user_public_key >> /root/.ssh/authorized_keys"" chi.container.execute(my_container1.uuid, cmd) chi.container.execute(my_container2.uuid, cmd)

4. **SSH into each container**: Associate a floating IP address with each container and use it to SSH into the container.
   ```python
ip_address1 = chi.container.associate_floating_ip(my_container1.uuid)
ip_address2 = chi.container.associate_floating_ip(my_container2.uuid)
print("use the following command to ssh into the containers: ssh root@" + ip_address1)
print("use the following command to ssh into the containers: ssh root@" + ip_address2)

Remember to replace edge_user_public_key with the path to your actual public key file. Also, make sure to destroy the containers when you're done with them to free up resources.

chi.container.destroy_container(my_container1.uuid)
chi.container.destroy_container(my_container2.uuid)
