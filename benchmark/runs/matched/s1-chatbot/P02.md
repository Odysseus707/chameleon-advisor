To reserve one Raspberry Pi 4 on CHI@Edge for 2 hours, you can use the following Python code with the chi library:

from chi import lease
import os

# Set the site and project
import chi
chi.context.use_site("CHI@Edge")
chi.context.choose_project()

# Set the machine type and device name
machine_name = "raspberrypi4-64"
device_name = "iot-rpi4-picam2"  # Replace with the actual device name you want to reserve

# Create a unique lease name
username = os.environ.get("USER")
lease_name = f"{username}-{device_name}"

# Create a lease for 2 hours
container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=2))

# Add a device reservation to the lease
container_lease.add_device_reservation(
    amount=1, machine_type=machine_name, device_name=device_name
)

# Submit the lease
container_lease.submit()
print("Lease submitted successfully.")

Please replace "iot-rpi4-picam2" with the actual device name you want to reserve. You can find the available device names in the CHI@Edge device catalog or by using the chi library to query the available devices.

Note: Make sure you have the chi library installed and configured properly before running this code. Also, be aware that reserving a device will allocate it exclusively for your use for the specified duration, and you will be charged for the reservation time.
