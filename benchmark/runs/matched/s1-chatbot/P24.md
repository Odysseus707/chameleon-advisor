For Sense HAT / GPIO work on CHI@Edge, you should use the "pi_sensehat" device profile and the "ghcr.io/chameleoncloud/edge_sensehat_image:latest" image for the Raspberry Pi Sense Hat, or the "pi_gpio" device profile and the "ghcr.io/chameleoncloud/edge_sensehat_image:latest" image for the Waveshare Sense Hat.
