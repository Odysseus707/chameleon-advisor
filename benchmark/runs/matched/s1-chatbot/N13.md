To reserve one Pi 4 for 10 hours starting now and launch python:3.9-slim on it with SSH installed and reachable from outside using the classic imperative python-chi API, you can follow these steps:

Reserve a Raspberry Pi 4 device on CHI@Edge for 10 hours:
import chi
from chi import lease

# Set up the Chameleon site and project
chi.use_site("CHI@Edge")
PROJECT_NAME = os.getenv('OS_PROJECT_NAME')
chi.set("project_name", PROJECT_NAME)

# Reserve a Raspberry Pi 4 device
NODE_TYPE = 'raspberrypi4-64'
start_date, end_date = lease.lease_duration(days=0, hours=10)
res = []
lease.add_device_reservation(res, machine_name=NODE_TYPE, count=1)
l = lease.create_lease(f"{os.getenv('USER')}-{NODE_TYPE}", res, start_date=start_date, end_date=end_date)
lease_id = l["id"]

Launch a container on the reserved device with the python:3.9-slim image:
from chi import container

# Set up the container
image = "python:3.9-slim"
container_name = f"{os.getenv('USER')}-edge-cpu"
my_container = container.create_container(
    container_name,
    image=image,
    reservation_id=lease.get_device_reservation(lease_id),
    interactive=True,
    exposed_ports=[22],
    platform_version=2,
)

Install SSH on the container and make it reachable from outside:
# Install SSH on the container
container.execute(my_container.uuid, 'apt update')
container.execute(my_container.uuid, 'apt -y install openssh-server')

# Associate a floating IP with the container
public_ip = container.associate_floating_ip(my_container.uuid)

# Configure SSH to use the floating IP
container.execute(my_container.uuid, 'service ssh start')
container.execute(my_container.uuid, 'service ssh status')

# Print the SSH command to access the container
print("ssh root@%s" % public_ip)

Note: These steps assume that you have already set up your Chameleon environment and have the necessary credentials to reserve devices and launch containers. Additionally, these steps are based on the provided reference material and may need to be modified to fit your specific use case.
