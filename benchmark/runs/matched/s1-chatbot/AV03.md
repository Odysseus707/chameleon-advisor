To find out how many CHI@Edge devices are free to reserve right now, across all device types, you would need to use the hardware.get_devices() function from the Python CHI library, specifying the site as "CHI@Edge" and filtering for available devices.

Here's a step-by-step example:

Choose the CHI@Edge site using context.choose_site(default="CHI@Edge").
Get a list of available devices using hardware.get_devices(filter_reserved=False). This will return all devices that are not currently reserved.
The length of the list of devices returned in step 2 will give you the total number of devices available for reservation across all device types.
Here is the code snippet that accomplishes this:

from chi import context
from chi import hardware

# Choose the CHI@Edge site
context.choose_site(default="CHI@Edge")

# Get a list of available devices
available_devices = hardware.get_devices(filter_reserved=False)

# Print the number of available devices
print(len(available_devices))

This code will output the number of CHI@Edge devices that are currently available for reservation. Note that device availability can change rapidly, so this number may not be accurate for long.
