To determine if a device is free to reserve, you would need to check the availability of the device. Here's a step-by-step approach using Python CHI:

Choose the site: Select CHI@Edge as the site.
Get available devices: Use the hardware.get_devices() function to retrieve a list of available devices that match your requirements (e.g., device type).
Filter devices: Filter the list to find the specific device you're interested in (e.g., iot-rpi4-picam2).
Check reservation status: Verify if the device is currently reserved or available.
Here's some sample Python code to achieve this:

from chi import context
from chi import hardware

# Choose the site
context.choose_site(default="CHI@Edge")

# Get available devices
available_devices = hardware.get_devices(filter_reserved=True, device_type="raspberrypi4-64")

# Filter devices to find the specific one
device = next((d for d in available_devices if d.device_name == "iot-rpi4-picam2"), None)

# Check if the device is available
if device and not device.reserved:
    print(True)
else:
    print(False)

This code checks if the device iot-rpi4-picam2 is available and not currently reserved. If it is, the code prints True; otherwise, it prints False.
