To check whether a given device is free right now on CHI@Edge before reserving it, you can use the hardware.get_devices() function from the Python CHI library. This function returns a list of available devices that match the specified filter criteria.

Here's an example of how you can use this function to check if a device is free:

from chi import hardware

device_type = "raspberrypi4-64"
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

if available_devices:
    print("Devices are available")
else:
    print("No devices are available")

In this example, we're filtering for devices of type raspberrypi4-64 and checking if there are any available devices. If there are, we print a message indicating that devices are available. If not, we print a message indicating that no devices are available.

You can also use the hardware.get_devices() function to get more information about the available devices, such as their device names, statuses, and reservation statuses.

Note that the filter_reserved=True parameter is used to filter out devices that are already reserved by other users. By setting this parameter to True, we can get a list of devices that are currently available for reservation.
