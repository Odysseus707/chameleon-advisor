To reserve any free Raspberry Pi 5 on CHI@Edge by machine type for 3 hours, follow these steps:

Log in to the CHI@Edge GUI at https://chi.edge.chameleoncloud.org.
Click on "Reservations" > "Leases" and then click on "Create Lease".
Set the "Name" to a descriptive name for your lease, such as "rpi5-reservation".
Set the start date and time to the current time or a future time when you want the reservation to start.
Set the lease length to 3 hours.
Click on "Next".
On the "Devices" tab, check the "Reserve devices" box.
Leave the "Minimum number of hosts" and "Maximum number of hosts" at 1.
In "Resource properties", specify the machine type as "Raspberry Pi 5".
Click on "Create".
Alternatively, you can use the Python CHI library to reserve a device programmatically. Here's an example code snippet:

from chi import lease
from datetime import timedelta

# Set the lease name and duration
lease_name = "rpi5-reservation"
lease_duration = timedelta(hours=3)

# Create a new lease
l = lease.Lease(lease_name, duration=lease_duration)

# Add a device reservation for a Raspberry Pi 5
l.add_device_reservation(device_type="Raspberry Pi 5", amount=1)

# Submit the lease
l.submit()
