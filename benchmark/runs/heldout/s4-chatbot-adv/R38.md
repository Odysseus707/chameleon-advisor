To get started with your Jupyter notebook server on CHI@Edge, you can follow these steps:

1. **Choose Site**:
   ```python
   chi.use_site("CHI@Edge")
   ```

2. **Set Project Name**:
   ```python
   chi.set("project_name", "Chameleon")
   ```

3. **Create a Lease**:
   ```python
   machine_name = "raspberrypi4-64"
   start, end = lease.lease_duration(hours=4)
   lease_name = f"jupyter-{machine_name}-{start}"
   reservations = []
   lease.add_device_reservation(reservations, count=1, machine_name=machine_name)
   container_lease = lease.create_lease(lease_name, reservations)
   lease_id = container_lease["id"]
   lease.wait_for_active(lease_id)
   ```

4. **Start the Container**:
   ```python
   container_name = f"jupyter-{machine_name}".replace("_", "-")
   my_container = container.create_container(
       container_name,
       image="ghcr.io/chameleoncloud/edge_ssh_image:latest",
       workdir="/home",
       exposed_ports=[22],
       reservation_id=lease.get_device_reservation(lease_id),
       platform_version=2
   )
   ```

5. **SSH into the Container**:
   ```python
   ip_address = chi.container.associate_floating_ip(my_container.uuid)
   print("Use the following command to ssh into the container: ssh root@" + ip_address)
   ```

6. **Run Jupyter Notebook Server**:
   Once you SSH into the container, start your Jupyter notebook server.

7. **Cleanup**:
   After use, destroy the container and lease.
   ```python
   chi.container.destroy_container(my_container.uuid)
   my_lease.delete()
   ```

This setup will allow you to interactively work with a Jupyter notebook on CHI@Edge for approximately 4 hours using one Raspberry Pi 4 device.
