For SSH access on CHI@Edge, you need to use a specific image that supports SSH and expose port 22 for SSH communication.

Based on the supplementary context provided:

- **Image**: You should use an image that is designed to support SSH access. Although not explicitly named in the primary documentation, the supplementary blog post suggests using a container image that has been configured for SSH access.
  
- **Exposed Port**: Expose port `22` which is the default port used by SSH.

Here's how you can set up an SSH-accessible container on CHI@Edge:

1. Choose or build an appropriate Docker image with SSH support (e.g., a custom image based on `ghcr.io/chameleoncloud/edge-picamera-image:latest`, but modified to include SSH).
2. When creating the container, ensure that port 22 is exposed.

Example code snippet for setting up such a container:

```python
from chi import container

my_container = container.Container(
    "rpi4-ssh-test",
    image_ref="your_ssh_enabled_image:latest", # Replace with your SSH-enabled image
    exposed_ports=[22],  # Expose port 22 for SSH access
    reservation_id=my_lease.device_reservations[0]["id"],
    command=["sleep", "infinity"],  # Keep the container running
)
my_container.submit()
```

This setup will allow you to SSH into your container on CHI@Edge using a standard SSH client.
