To get an interactive SSH shell on an edge device on CHI@Edge for about 2 hours, you can follow these steps:

1. **Login to CHI@Edge**: Go to https://chi.edge.chameleoncloud.org and log in with your Chameleon credentials.
   
2. **Choose a Device Type**: Based on the available resources and your needs, here are my top three device types for reservation:
   - **raspberrypi4-64 (arm64)**: This is recommended because it supports the latest camera module and has sufficient processing power for most edge computing tasks.
   - **iot-rpi-cm4-02**: Suitable if you need a device with a Waveshare Sense Hat, which provides various sensors for environmental monitoring.
   - **iot-rpi4-picam3**: Recommended if your experiment specifically requires the Pi Camera Module 3.

3. **Create a Lease**:
   ```python
   from chi import lease

   my_lease = lease.Lease("my-ssh-session", duration=timedelta(hours=2))
   my_lease.add_device_reservation(device_type="raspberrypi4-64")
   my_lease.submit(idempotent=True)
   ```

4. **Launch a Container**:
   ```python
   from chi import container

   my_container = container.Container(
       "my-ssh-container",
       image_ref="ghcr.io/chameleoncloud/edge-picamera-image:latest",
       reservation_id=my_lease.device_reservations[0]["id"],
       command=["sleep", "infinity"],
       device_profiles=["pi_libcamera"]
   )
   my_container.submit()
   ```

5. **Access the Container via SSH**:
   - Use the SSH access method provided by CHI@Edge to connect to your container.

Justification for top 3 devices:

1. **raspberrypi4-64 (arm64)**: Best overall device with good processing power and camera support.
2. **iot-rpi-cm4-02**: Ideal if you need a variety of sensors for environmental monitoring.
3. **iot-rpi4-picam3**: Optimal choice if your experiment specifically requires the Pi Camera Module 3.

Please verify the availability of these devices before proceeding with reservations.
