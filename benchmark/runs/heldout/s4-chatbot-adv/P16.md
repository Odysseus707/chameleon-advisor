To launch a container with the Pi camera enabled on CHI@Edge, you need to follow these steps:

1. **Select the appropriate machine type and image**: For working with the Raspberry Pi Camera, you should use the `raspberrypi4-64` machine type and an image that supports the Pi camera.

2. **Create a lease**: You will first create a lease for the device to reserve it for your experiment.

3. **Launch the container**: Use the appropriate Docker image that includes support for the Raspberry Pi Camera.

Here is how you can do this using Python with `chi`:

### Step 1: Import and Initialize

```python
import chi
from chi import lease, container

# Select CHI@Edge site
chi.use_site("CHI@Edge")
```

### Step 2: Create a Lease

```python
machine_name = "raspberrypi4-64"
start, end = lease.lease_duration(hours=3) # Adjust duration as needed
lease_name = f"camera-{machine_name}-{start}"

reservations = []
lease.add_device_reservation(reservations, count=1, machine_name=machine_name)
container_lease = lease.create_lease(lease_name, reservations)
lease_id = container_lease["id"]

print(f"Created lease with name {lease_name} and uuid {lease_id}, waiting for it to start.")
lease.wait_for_active(lease_id)
print("Done!")
```

### Step 3: Launch the Container

```python
container_name = f"camera-{machine_name}".replace("_", "-")

# Use an image that supports the Pi camera, e.g., edge-picamera-image
my_container = container.create_container(
    name=container_name,
    image="ghcr.io/chameleoncloud/edge-picamera-image:latest",
    workdir="/home",
    exposed_ports=[22],
    reservation_id=lease.get_device_reservation(lease_id),
    platform_version=2,
)

print(f"Successfully created container: {my_container.name}!")
```

### Step 4: Access the Container

You can now access the container via SSH or use it to run your experiment.

```python
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print("Use the following command to ssh into the container: ssh root@" + ip_address)
```

This setup will allow you to work with the Raspberry Pi Camera on a CHI@Edge device using a container that supports it.
