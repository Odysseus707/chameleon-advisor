To launch an Ollama container on your existing CHI@Edge lease named 'my-llm-lease' with GPU support, exposing only the Ollama API port (typically 8000), and giving it a public IP address, follow these steps:

1. **Ensure you have the necessary environment set up**:
   - Import the `chi` module.
   - Set your project name if not already done.

2. **Identify the lease ID** for 'my-llm-lease'.

3. **Launch the Ollama container with GPU support and expose port 8000**:
   - Use a Docker image that supports Ollama and has GPU capabilities.
   - Expose only the necessary ports (in this case, port 8000 for the Ollama API).
   - Request a floating IP address to make the container accessible from outside.

Here is an example of how you can do it in Python:

```python
import chi

# Ensure you are using CHI@Edge site and set your project name if needed.
chi.use_site("CHI@Edge")
chi.set("project_name", "Chameleon")

from chi import lease, container

# Identify the lease ID for 'my-llm-lease'
leases = lease.list_leases()
target_lease = next((l for l in leases if l['name'] == 'my-llm-lease'), None)
if target_lease is None:
    raise ValueError("Lease 'my-llm-lease' not found.")
lease_id = target_lease["id"]

# Launch the Ollama container with GPU support and expose port 8000
container_name = "ollama-container"
image_ref = "ghcr.io/chameleoncloud/edge_ssh_image:latest" # Replace this with a suitable image that supports Ollama and has GPU capabilities

try:
    my_container = container.create_container(
        name=container_name,
        image=image_ref,
        exposed_ports=[8000],
        reservation_id=target_lease["device_reservations"][0]["id"],
        platform_version=2,  # Ensure this matches the lease's platform version
        device_profiles=["gpu"],  # Specify GPU profile if needed
    )
except RuntimeError as ex:
    print(ex)
else:
    print(f"Successfully created container: {container_name}!")

# Associate a floating IP address to make it accessible from outside
ip_address = chi.container.associate_floating_ip(my_container.uuid)

print("Container is now accessible at:", ip_address, "on port 8000")
```

**Note**: Replace `ghcr.io/chameleoncloud/edge_ssh_image:latest` with a Docker image that supports Ollama and has GPU capabilities if necessary.

This script will:
- Ensure you are working within the CHI@Edge environment.
- Identify your lease named 'my-llm-lease'.
- Launch an Ollama container on this lease, exposing port 8000 for the API.
- Assign a floating IP address to make the container accessible from outside.
