To run GPU-accelerated inference on a Jetson-class device on CHI@Edge, you need to follow these steps:

1. **Reserve a Jetson Device**:
   - Log in to the Chameleon portal and navigate to the CHI@Edge site.
   - Create a lease for a Jetson-class device (e.g., `jetson-xavier-nx` or similar). Ensure that you specify the GPU flavor if available.

2. **Start a CUDA-capable Container**:
   - Use Jupyter Notebook or another method to interact with CHI@Edge and launch a container.
   - Select an appropriate image that supports CUDA, such as one based on NVIDIA's JetPack or a similar Docker image that includes CUDA libraries.

Here is a step-by-step guide using Python and the `chi` library:

1. **Log in to CHI@Edge**:
    ```python
    import chi

    # Authenticate with your Chameleon credentials
    chi.context.use_site("CHI@Edge")
    chi.context.choose_project()
    ```

2. **Create a Lease for a Jetson Device**:
    ```python
    from chi import lease, hardware

    device_type = "jetson-xavier-nx"  # Replace with the actual machine type of your target Jetson device
    available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)

    if not available_devices:
        raise Exception("No free devices found for this reservation")

    jetson_device = available_devices[0]

    lease_name = f"gpu-inference-lease-{jetson_device.device_id}"
    container_lease = lease.Lease(name=lease_name, duration=lease.timedelta(hours=3))
    container_lease.add_device_reservation(amount=1, machine_type=device_type, device_name=jetson_device.device_name)
    container_lease.submit()
    print("Lease created successfully.")
    ```

3. **Launch a CUDA-capable Container**:
    ```python
    from chi import container

    # Set the name for your container
    container_name = "gpu-inference-container".replace("_", "-")

    # Use an appropriate image with CUDA support (e.g., NVIDIA's JetPack or similar)
    cuda_image_ref = "nvidia/cuda:12.0-base-ubuntu22.04"  # Replace with the actual Docker image

    my_container = container.Container(
        name=container_name,
        image_ref=cuda_image_ref,
        reservation_id=container_lease.device_reservations[0]["id"],
        command=["sleep", "infinity"]
    )
    my_container.submit()
    print("Container launched successfully.")
    ```

4. **Verify CUDA Installation and Run Inference**:
   - Once the container is running, you can SSH into it or use Jupyter Notebook to run your inference code.
   
5. **Clean Up**:
    ```python
    # Delete the container when done
    my_container.delete()

    # Delete the lease to free up the device
    container_lease.delete()
    ```

This process ensures that you have a Jetson-class device reserved and a CUDA-capable environment set up for running GPU-accelerated inference.
