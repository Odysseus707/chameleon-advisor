To reserve a free Raspberry Pi 5 on CHI@Edge by machine type for 3 hours, you can follow these steps using Python and the `chi` library:

1. **Import necessary modules**:
   ```python
   import chi
   from chi import lease
   ```

2. **Select the Chameleon site**:
   ```python
   chi.use_site("CHI@Edge")
   ```

3. **Set your project name** (if required):
   ```python
   chi.set("project_name", "Chameleon")  # Replace with your actual project name if needed.
   ```

4. **Create a lease for the Raspberry Pi 5 device type**:
   ```python
   machine_type = "raspberrypi5-64"  # Assuming 'raspberrypi5-64' is the correct machine type for Raspberry Pi 5

   start, end = lease.lease_duration(hours=3)  # Duration of 3 hours

   lease_name = f"reservation-{machine_type}-{start}"

   reservations = []
   lease.add_device_reservation(reservations, count=1, machine_name=machine_type)

   container_lease = lease.create_lease(lease_name, reservations)
   lease_id = container_lease["id"]

   print(f"Created lease with name {lease_name} and uuid {lease_id}, waiting for it to start. This can take up to 60s.")
   lease.wait_for_active(lease_id)
   print("Done!")
   ```

This code will create a lease for one Raspberry Pi 5 device on CHI@Edge, reserving the device for 3 hours.

**Note**: Ensure that you replace `"Chameleon"` with your actual project name if required. Also, verify that `raspberrypi5-64` is indeed the correct machine type for Raspberry Pi 5 devices in CHI@Edge as the documentation provided does not specify this exact model and it might differ based on the latest updates from Chameleon Cloud.

If you encounter any issues or errors, please check the availability of the device type and ensure that your project has an active allocation to use CHI sites.
