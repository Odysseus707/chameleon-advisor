To launch a Jupyter minimal-notebook container on an active lease named 'serve-edge-vr' for a Raspberry Pi 5 and give it a public IP, follow these steps:

1. **Ensure you have access to the lease**: Since your lease is already active, you can proceed with launching the container.

2. **Launch the Jupyter minimal-notebook container**:
   - Use the `chi` library to create a container on the existing lease.
   - Specify the image as `jupyter/minimal-notebook`.
   - Expose port 8888 for Jupyter access and request a floating IP address.

Here is how you can do it in Python:

```python
import chi

# Ensure you are using CHI@Edge site
chi.use_site("CHI@Edge")

# Set the project name (if needed)
chi.set("project_name", "Chameleon")

from chi import container, lease

# Get the reservation ID from your active lease 'serve-edge-vr'
lease_id = "your_lease_uuid"  # Replace with actual UUID of your lease
reservation_id = lease.get_device_reservation(lease_id)

# Launch a Jupyter minimal-notebook container on the lease
container_name = "jupyter-minimal-serve-edge"
my_container = container.create_container(
    name=container_name,
    image="jupyter/minimal-notebook",
    exposed_ports=[8888],
    reservation_id=reservation_id,
    platform_version=2,  # Ensure compatibility with Raspberry Pi 5
)

print(f"Successfully created container: {container_name}!")

# Associate a floating IP to the container for public access
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print("Jupyter Notebook is accessible at http://{}:8888".format(ip_address))
```

3. **Find the Jupyter notebook token URL from the container logs**:
   - After launching the container, you need to find the token used for accessing the Jupyter notebook.
   - You can retrieve this information by checking the container's log output.

Here is how you can do it:

```python
# Retrieve and print the container logs to get the Jupyter token URL
logs = chi.container.logs(my_container.uuid)
print(logs)

# The logs will contain a line similar to:
# "Paste the following link into your web browser: http://127.0.0.1:8888/?token=your_token_here"
```

By examining the logs, you can find the token URL that allows you to access the Jupyter notebook interface securely.

**Note**: Replace `"your_lease_uuid"` with the actual UUID of your lease 'serve-edge-vr'.
