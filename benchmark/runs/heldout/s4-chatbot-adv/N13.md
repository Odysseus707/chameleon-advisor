To reserve one Raspberry Pi 4 for 10 hours and launch a Python container with SSH installed, you can follow these steps using the imperative style of the `python-chi` API:

1. **Choose Site**: Select CHI@Edge as your site.
2. **Create Lease**: Reserve a device for 10 hours.
3. **Launch Container**: Deploy a container image that includes Python and SSH.

Here's how you can do it:

```python
import chi

# Step 1: Choose the Chameleon site (CHI@Edge)
chi.context.use_site("CHI@Edge")

# Step 2: Create a lease for one Raspberry Pi 4 device for 10 hours
from datetime import timedelta

lease_name = "pi4-ssh-access"
device_type = "raspberrypi4-64"

# Get available devices of the specified type
available_devices = chi.hardware.get_devices(filter_reserved=True, device_type=device_type)

if not available_devices:
    raise Exception("No available Raspberry Pi 4 devices.")

# Reserve one device from the list
device_name = available_devices[0].device_name

lease_duration = timedelta(hours=10)
chi.lease.create(lease_name, duration=lease_duration).add_device_reservation(
    amount=1,
    machine_type=device_type,
    device_name=device_name
)

# Step 3: Launch a container with Python and SSH installed on the reserved device
container_name = "pi4-python-ssh"
image_ref = "python:3.9-slim"

# Install SSH in the container using an entrypoint script or Dockerfile modification.
entrypoint_script = """
#!/bin/sh
apt-get update && apt-get install -y openssh-server
service ssh start
sleep infinity
"""

chi.container.create(
    name=container_name,
    image_ref=image_ref,
    reservation_id=device_name,  # Use the device name as reservation ID
    entrypoint=["/bin/sh", "-c"],
    command=[entrypoint_script]
).submit()
```

This script does the following:
- Sets up CHI@Edge as the target site.
- Creates a lease for one Raspberry Pi 4 device for 10 hours.
- Launches a container with Python 3.9 and installs SSH within it.

Please ensure you have the necessary permissions and that your project has sufficient resources to create leases and launch containers on CHI@Edge.
