To get an interactive SSH shell on an edge device on CHI@Edge for about 2 hours, follow these steps:

1. **Login to CHI@Edge**: Use your Chameleon portal username and password to log in at https://chi.edge.chameleoncloud.org.
   
2. **Check Available Devices**: Navigate through the GUI or use Python-CHI to check available devices.

3. **Reserve a Device**:
   - **Raspberry Pi 4 (raspberrypi4-64)**: Best for general-purpose edge computing tasks, well-supported with community artifacts.
   - **Raspberry Pi Compute Module 4 (raspberrypi-cm4)**: Ideal if you need more customization options and are working on specific hardware configurations.
   - **Intel NUC**: Suitable for tasks requiring higher performance or specific Intel optimizations.

To reserve a device using Python-CHI, follow these steps:

```python
from chi import context, lease

# Choose the site and project
context.use_site("CHI@Edge")
context.choose_project()

# Create a lease
device_type = "raspberrypi4-64"  # or another type based on your needs
my_lease = lease.Lease(name="interactive_ssh", duration=lease.timedelta(hours=2))
available_devices = hardware.get_devices(filter_reserved=True, device_type=device_type)
if available_devices:
    my_device = available_devices[0]
    my_lease.add_device_reservation(devices=[my_device])
    my_lease.submit(idempotent=True)

# Once the lease is created and active, you can SSH into the container running on this device.
```

After reserving a device, you will need to launch a container with an SSH server if it's not already set up. You can then use the provided SSH access method to interactively connect to your edge device.

Remember that each Chameleon testbed site is independent, so resources and configurations are unique to CHI@Edge.
