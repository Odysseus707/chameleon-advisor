To launch an Ollama container on an active CHI@Edge lease with GPU support, expose only the Ollama API port, and give it a public IP address, follow these steps:

1. **Ensure you have the necessary environment set up**:
   - You need to be authenticated in your Chameleon project.
   - Ensure that you are using the `CHI@Edge` site.

2. **Launch the Ollama container with GPU support and expose only the required port**:
   - Use the `chi.container.create_container()` method to launch a new container on an existing lease.
   - Specify the image for the Ollama container, ensure that you request GPU resources, and specify the exposed ports.

3. **Associate a floating IP address with the container**:
   - After launching the container, associate a floating IP address so it can be accessed publicly.

Here is how to do this in Python using `chi`:

```python
import chi

# Ensure you are working on CHI@Edge and have selected your project.
chi.use_site("CHI@Edge")
chi.set("project_name", "YourProjectName")

from chi import container, lease

# Assuming 'my-llm-lease' is the active lease with a GPU-capable device
lease_id = "your_lease_uuid"  # Replace this with your actual lease UUID.

# Define the Ollama container image and expose only the required port (e.g., 8000 for Ollama API)
container_name = "ollama-container"
image_ref = "ghcr.io/ollama/ollama:latest"  # Replace with the correct Ollama Docker image
exposed_ports = [8000]  # Expose only port 8000

# Create and launch the container on the lease, requesting GPU support.
my_container = container.create_container(
    name=container_name,
    image=image_ref,
    exposed_ports=exposed_ports,
    reservation_id=lease.get_device_reservation(lease_id),
    device_profiles=["gpu"],  # Ensure you request a GPU profile
)

# Associate a floating IP address with the container to make it publicly accessible.
ip_address = chi.container.associate_floating_ip(my_container.uuid)
print(f"Container {container_name} is now available at: http://{ip_address}:8000")
```

**Note**: Replace `"YourProjectName"` and `"your_lease_uuid"` with your actual project name and lease UUID, respectively.

This script will launch the Ollama container on an existing lease named `my-llm-lease`, expose only port 8000 for the Ollama API, and associate a floating IP address to make it publicly accessible.
