1. **Authenticate to CHI@Edge**: Use Python-CHI or the Chameleon GUI to authenticate your session.

2. **Create a Lease for the Device**:
   - Identify the specific device with the camera attached (e.g., `iot-rpi4-picam`).
   - Create and submit a lease for that device using Python-CHI, specifying the duration of the lease.
   
3. **Launch an SSH-enabled Container**:
   - Use Python-CHI to launch a container on the reserved device with SSH enabled. You can use a pre-built image or create your own Dockerfile to ensure SSH is installed and configured.

4. **Accessing the Container via SSH**:
   - Once the container is running, you will need its IP address and port number for SSH access.
   - Use an SSH client (like `ssh` on Linux/Mac) to connect to the container using the provided credentials.
