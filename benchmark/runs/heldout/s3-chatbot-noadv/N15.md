To reserve a free Raspberry Pi 5 on CHI@Edge by machine type for 3 hours using the Chameleon Cloud documentation provided:

1. **Select the Site**: First, you need to select the `CHI@Edge` site where your reservation will be made.

2. **Create a Lease**: You'll create a lease that reserves one Raspberry Pi 5 device for 3 hours. The machine type for Raspberry Pi 5 should be specified in this step.

Here is how you can do it programmatically using the `chi` Python library:

```python
import chi

# Select CHI@Edge site
chi.use_site("CHI@Edge")

from datetime import timedelta
from chi import lease, hardware

# Get available devices of type Raspberry Pi 5 (replace 'raspberrypi5-64' with the correct machine name if different)
available_devices = hardware.get_devices(filter_reserved=True, device_type="raspberrypi5-64")
device_to_reserve = next((d for d in available_devices), None)

if device_to_reserve:
    # Create a lease
    my_lease = lease.Lease("my-rpi5-lease", duration=timedelta(hours=3))
    
    # Add the reservation to the lease
    my_lease.add_device_reservation(devices=[device_to_reserve])
    
    # Submit the lease
    my_lease.submit(idempotent=True)
else:
    print("No available Raspberry Pi 5 devices.")
```

This script will check for any free Raspberry Pi 5 device, create a lease for it, and reserve it for 3 hours. Make sure to replace `"raspberrypi5-64"` with the correct machine type if it differs from this example.

If you are using the GUI, follow these steps:

1. **Navigate to CHI@Edge**: Go to https://chi.edge.chameleoncloud.org.
2. **Create a Lease**:
   - Navigate to the "Project" section and then select "Reservations".
   - Click on "Launch Reservation".
   - Choose the machine type for Raspberry Pi 5 from the available options.
   - Set the duration of your lease to 3 hours.
   - Submit the reservation.

This will reserve a free Raspberry Pi 5 device for you for 3 hours.
