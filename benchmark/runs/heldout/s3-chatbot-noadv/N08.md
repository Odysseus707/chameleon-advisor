To launch a Jupyter minimal-notebook container on an active lease named 'serve-edge-vr' for a Raspberry Pi 5 device on CHI@Edge and give it a public IP address, follow these steps:

1. **Ensure you have the necessary environment set up**:
   - Make sure your Python environment is configured to use `chi` and that you are authenticated with Chameleon Cloud.

2. **Select the site and project**:
   ```python
   import chi

   # Select CHI@Edge as the testbed site.
   chi.use_site("CHI@Edge")

   # Set the project name (replace 'Chameleon' with your actual project name).
   chi.set("project_name", "Chameleon")
   ```

3. **Launch a container**:
   - Use the `chi.container` module to launch a Jupyter minimal-notebook container on an existing lease.
   
   ```python
   from chi import container

   # Set up the container parameters.
   container_name = "serve-edge-vr-jupyter"
   image_ref = "jupyter/minimal-notebook"  # Use the official Jupyter minimal-notebook Docker image.

   # Launch the container on an existing lease (replace 'your_lease_id' with your actual lease ID).
   my_container = container.create_container(
       name=container_name,
       image=image_ref,
       reservation_id="your_lease_id",  # Replace this with the actual lease ID.
       exposed_ports=[8888],  # Expose port 8888 for Jupyter Notebook.
       platform_version=2
   )
   ```

4. **Associate a floating IP address**:
   - To access your container from outside, you need to associate a public (floating) IP address with it.

   ```python
   ip_address = chi.container.associate_floating_ip(my_container.uuid)
   print(f"Container is accessible at: http://{ip_address}:8888")
   ```

5. **Find the Jupyter Notebook token URL from container logs**:
   - After launching the container, you need to find the token URL for accessing the Jupyter notebook.
   
   ```python
   # Fetch and print the container logs to locate the Jupyter token.
   logs = chi.container.logs(my_container.uuid)
   print(logs)

   # The token will be in the logs. It usually looks something like this:
   # http://localhost:8888/?token=abcd1234efgh5678ijkl90
   ```

By following these steps, you can launch a Jupyter minimal-notebook container on an active lease and access it via SSH or through the web interface using the token URL found in the logs.
