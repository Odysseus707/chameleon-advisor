To run GPU-accelerated inference on a Jetson-class device on CHI@Edge by reserving one and starting a CUDA-capable container, follow these steps:

1. **Login to CHI@Edge**:
   - Go to the Chameleon user portal at https://chameleoncloud.org.
   - Click on "Experiment" in the dropdown menu and select "CHI@Edge".
   - Use your federated login credentials (e.g., InCommon, Google account, or Globus ID) to log into CHI@Edge.

2. **Create a Lease**:
   - Once logged in, navigate to the appropriate section for creating leases.
   - Select a Jetson-class device type that supports GPU acceleration and create a lease for it. Ensure you have an active allocation and are part of a project with access rights.

3. **Start a CUDA-capable Container**:
   - Use Jupyter Notebook or another method to interact with CHI@Edge programmatically.
   - Create a container using a Dockerfile that includes the necessary CUDA dependencies and libraries for GPU-accelerated inference.
   - Ensure your container image is built with support for NVIDIA drivers and CUDA runtime.

Here's an example of how you might set up a lease and start a container in Jupyter Notebook:

```python
import chi

# Authenticate to CHI@Edge
chi.context.use_site("CHI@Edge")
chi.context.choose_project()

from chi import lease, container

# Create a lease for the Jetson device
lease_name = "gpu-inference-lease"
device_type = "jetson-nano"  # Replace with actual Jetson class device type
container_lease = lease.Lease(name=lease_name)
container_lease.add_device_reservation(amount=1, machine_type=device_type)
container_lease.submit()

# Start a CUDA-capable container on the leased device
image_ref = "nvidia/cuda:latest"  # Use an appropriate CUDA image
container_name = "gpu-inference-container"
my_container = container.Container(
    name=container_name,
    image_ref=image_ref,
    reservation_id=container_lease.device_reservations[0]["id"],
)
my_container.submit()
```

4. **Access the Container**:
   - Once your container is running, you can SSH into it for further configuration and experimentation as described in the supplementary context.

By following these steps, you will have a Jetson-class device reserved with a CUDA-capable container ready to perform GPU-accelerated inference tasks on CHI@Edge.
