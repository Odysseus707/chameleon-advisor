To run GPU-accelerated inference on a Jetson-class device on CHI@Edge, you would first need to reserve one and then start a CUDA-capable container on it. Here's a step-by-step guide based on the provided documentation:

Reserve a Jetson-class device: Use the CHI@Edge GUI or the chi command-line tool to create a lease for a Jetson-class device. You can specify the device type and the duration of the lease.

Launch a CUDA-capable container: Once the lease is active, you can launch a container on the reserved device. You will need a Docker image that supports CUDA and is compatible with the Jetson-class device. You can use an existing image or create your own using a Dockerfile.

Configure the container for GPU acceleration: Ensure that the container is configured to use the GPU for acceleration. This may involve installing the CUDA toolkit and drivers, and configuring the environment variables to use the GPU.

Run your inference workload: Once the container is running, you can run your inference workload using the GPU for acceleration. You can use tools like nvidia-smi to monitor the GPU usage and performance.

Here's some sample Python code using the chi library to reserve a device and launch a container:

import chi

# Set up the CHI@Edge site and project
chi.use_site("CHI@Edge")
chi.set("project_name", "My Project")

# Reserve a Jetson-class device
device_type = "jetson-nano"
lease_name = "my-lease"
lease = chi.lease.Lease(lease_name, duration=chi.lease.timedelta(hours=1))
lease.add_device_reservation(device_type=device_type)
lease.submit()

# Launch a CUDA-capable container
container_name = "my-container"
image_ref = "nvcr.io/nvidia/l4t-base:r32.6.1"
container = chi.container.Container(container_name, image_ref, reservation_id=lease.device_reservations[0]["id"])
container.submit()
