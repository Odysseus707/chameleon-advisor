To launch an Ollama container on your active CHI@Edge lease named 'my-llm-lease' with GPU support, exposing only the Ollama API port, and giving it a public IP, you can follow these steps:

Ensure you have an active lease named 'my-llm-lease' on a GPU-capable device.
Create a container with the Ollama image, specifying the GPU device profile and exposing the Ollama API port.
Associate a floating IP address with the container to give it a public IP.
Here's an example code snippet in Python using the chi library:

import chi

# Set the site and project
chi.use_site("CHI@Edge")
chi.set("project_name", "your_project_name")

# Get the lease ID
lease_id = chi.lease.get_lease_id("my-llm-lease")

# Create a container with the Ollama image and GPU support
container = chi.container.create_container(
    name="ollama-container",
    image="ollama-image",
    device_profiles=["gpu"],
    exposed_ports=[8080],  # Expose the Ollama API port
    reservation_id=lease_id,
)

# Associate a floating IP address with the container
floating_ip = chi.container.associate_floating_ip(container.uuid)

print(f"Container created with IP address: {floating_ip}")

Note that you'll need to replace your_project_name with your actual project name and ollama-image with the actual image name for the Ollama container. Additionally, you may need to modify the exposed_ports parameter to match the specific port requirements of your Ollama container.
