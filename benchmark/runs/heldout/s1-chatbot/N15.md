To reserve any free Raspberry Pi 5 on CHI@Edge by machine type for 3 hours, you can use the following Python code:

from chi import lease
from datetime import timedelta

machine_name = "raspberrypi5"
start, end = lease.lease_duration(days=0, hours=3)

reservations = []
lease.add_device_reservation(reservations, count=1, machine_name=machine_name)
my_lease = lease.create_lease(f"{machine_name}-lease", reservations, start=start, end=end)
lease_id = my_lease["id"]

print(f"created lease with name {my_lease['name']} and uuid {lease_id}, waiting for it to start. This can take up to 60s.")
lease.wait_for_active(lease_id)
print("Done!")

This code will create a lease for a Raspberry Pi 5 device for 3 hours. Please note that you need to have the necessary credentials and permissions to create a lease on CHI@Edge. Also, make sure to replace the machine_name variable with the correct machine type if needed.
